# ロボットコマンダー（bot-commander）絵の品質アップ 依頼書（Codex 向け）

この依頼書は、これだけ読めば作業できるように書いています。
対象のリポジトリは `D:\スマホゲーム工房` で、今の版は **v0.2.1**（キャッシュ v5、コミット `0aa4757`）です。
ゲームのフォルダは `bot-commander/` です。

## 1. ゴール

ゲーム内の絵を全部、一段きれいにします。

- 対象: ツギハギ号（スカベンジャー）、PONCO02、異星生物、ガラクタの山、脱出口のハッチ、地形タイル、エフェクト
- 今の **かわいいデフォルメ（SD）の作風は保ちます**。リアルにしない。頭が大きく、手足が短いままにします。
- 縦長のスマホ画面で、**小さく表示されても見分けがつく** ことを第一にします（大きさは 1-1）。
- 手描き風の SVG にします。暗い輪郭線＋セル塗り（影は1〜2段）。ダダサバイバー（`dada-survivor/js/art.js`）と同じ作り方です。

### 1-1. 画面に出る実際の大きさ（コードから）

**ワールドの大きさ**
- 1タイル（`TILE`）は 32 ワールドpx です（`js/sim/map.js`）。
- マップは 40×60 タイルで、1280×1920 ワールドpx になります。

**ズーム**（`js/render/renderer.js` の `cam.zoom`）
- 開始時は 1 です。上限は `2.4` です。
- 下限は `minZoom()` で、390×844 の画面なら約 0.40 です。
- 画面上の CSS px は、ワールドpx × zoom です。
- 実機の画素は、さらに × devicePixelRatio（上限2）です。

| もの | ワールドでの表示サイズ | zoom 0.4 | zoom 1（開始時） | zoom 2.4 |
|---|---|---|---|---|
| ツギハギ号 `scav` | 32px（`KIND_PX.scav`） | 約13px | 32px | 約77px |
| PONCO02 `ponco` | 34px | 約14px | 34px | 約82px |
| 異星生物 `alien` | 54px | 約22px | 54px | 約130px |
| 旧兵種 gunner/heavy | 34px（`UNIT_PX`） | 約14px | 34px | 約82px |
| 隊長の旗 `marker_*` | 18px | 約7px | 18px | 約43px |
| ガラクタの山 `salvage_*` | `TILE*1.9`＝約61px | 約24px | 61px | 約146px |
| 脱出口 `hatch` | `TILE*3`＝96px | 約38px | 96px | 約230px |
| 本陣 `hq_*` | `TILE*3.2`＝約102px | 約41px | 102px | 約246px |
| 地形タイル `tile_*` | 32px | 約13px | 32px | 約77px |

- ふつうに遊ぶときの zoom は 1〜1.4 くらいです。スクショの確認もこの範囲で撮ります。
- **一番大事なのは、zoom 1 で 32px のツギハギ号と 34px の PONCO02 の見分けがつくこと** です。
  - 大きな頭、目の光、色のかたまりで見分けられるようにします。細い線や小さな模様は、32px ではつぶれます。
- 部隊は4機がかたまって動きます。異星生物は2〜3体の群れです。重なったときにも見分けられるようにします。

## 2. 絵がある場所と、テクスチャになるまで

### 2-1. `bot-commander/js/render/art.js`（絵の中身。ここが主な作業場所）

**共通の部品**
- 輪郭の色は `O = '#121418'` です。
- 線の属性は `S`（太さ2.6）、`S2`（1.7）、`SW(w)` です。
- `wrap(body, vb='0 0 64 64')` で svg 要素に包みます。
- 丸い部品は `shadedCircle(id, …)`、四角い部品は `shadedBox(id, …)` を使います。
  - どちらも clipPath を使うセル影です。**id は1つの SVG の中で重ならないように** します。
- 色は `PALETTES.ally` / `PALETTES.enemy` にあります。

**絵を作る関数と、できる SVG**

| 関数 | 中身 | viewBox |
|---|---|---|
| `scav(commander)` | ツギハギ号 | 64 |
| `ponco(commander)` | PONCO02 | 64 |
| `alien(commander)` | 異星生物 | 64 |
| `salvagePile(v, empty)` | ガラクタの山（v は 0/1 の2種類。empty は空になった山） | 96 |
| `hatch()` | 脱出口 | 96 |
| `terrainSvg(kind, v)` | 地形。kind は plain / forest / mountain / water、v は 0/1 の2種類 | 64 |
| `gunner(p, cmd)` / `heavy(p, cmd)` / `hq(p)` / `commanderMarker(p)` | 旧モード（ミッションなし）の兵と本陣、隊長の旗 | — |

- 旧モードの絵は、今のミッションでは本陣（味方）と旗だけ使っています。でも**消さない**でください。

**`artSources()`**
- キーから SVG 文字列への一覧を返します。今は **30個** です。
- **このキー名は、描画側が決め打ちで使っています。名前を変えず、全部残します**（2-4）。
- キーの一覧:
  - 旧兵種: `gunner_ally` / `gunner_ally_cmd` / `heavy_ally` / `heavy_ally_cmd`、`gunner_enemy` / `gunner_enemy_cmd` / `heavy_enemy` / `heavy_enemy_cmd`
  - 旗と本陣: `marker_ally` / `marker_enemy`、`hq_ally` / `hq_enemy`
  - 地形: `tile_plain_0` / `tile_plain_1`、`tile_forest_0` / `tile_forest_1`、`tile_mountain_0` / `tile_mountain_1`、`tile_water_0` / `tile_water_1`
  - ミッションの機体: `scav_ally` / `scav_ally_cmd`、`ponco_ally` / `ponco_ally_cmd`、`alien_enemy` / `alien_enemy_cmd`
  - その他: `salvage_0` / `salvage_1` / `salvage_empty`、`hatch`

### 2-2. `bot-commander/js/render/textures.js`（SVG からテクスチャへ）

1. 起動時に一度だけ、SVG を data URI の Image にして decode します。
2. viewBox の長い辺が `px` になるように canvas に描きます。
3. `Texture.from(canvas)` でテクスチャにします。`scaleMode = 'linear'` です。

焼く大きさはキー名で決まります。

| キー | 焼く大きさ |
|---|---|
| `tile_*` | 64px |
| `hq_*`、`hatch`、`alien_*` | 192px |
| それ以外 | 128px |

- 新しいキーを足すときは、ここの大きさの決め方も合わせて直します。
- 焼く大きさは **最大 256px まで** にします。
- SVG は Image として描くので、次のことに注意します。
  - **外部の画像やフォントは読めません。**
  - **SVG の中の `<text>` は、ひらがなモードで変換されません**（5章）。絵の中に文字を入れません。
    - 例外として、PONCO02 の胸の「F」は文字ではなく、**図形（path）で描きます**。

### 2-3. `bot-commander/js/render/renderer.js`（並べ方・アンカー・動き）

**地形**
- 全タイル（2400枚）を一度だけ Sprite で並べます。大きさは `width = height = TILE` です。
- 2種類の絵は `(tx*7 + ty*13) % 3 === 0` のマスで `_1`、それ以外で `_0` を使います。
- **タイルの絵は、隣どうしで継ぎ目が出ないように** します（上下左右の端を、どれとつながってもなじむ色にする）。

**機体**（`unitView`）
- 体の Sprite は `anchor (0.5, 0.88)` です。viewBox 64 なら y≈56 が足元（立っている点）になります。
- 大きさは `KIND_PX[kind]`（なければ `UNIT_PX = 34`）の正方形です。
- **絵は右向きで描きます。** 左へ動くときは、描画側が `scale.x` を反転します。
- 隊長の旗は `anchor (0.3, 1)` で 18px、位置は `(4, -px + 2)` です。
- HP バーは足元の下（y = +4）です。幅は異星生物が 38px、それ以外が 26px です。
- 異星生物の気づきゲージと「！」は、隊長の `y - 66` に描きます。**体の高さを大きく変えるときは、ここも合わせます。**

**ガラクタの山**
- `anchor (0.5, 0.8)`、大きさ `TILE * 1.9` です。
- 空になると、テクスチャを `salvage_empty` に差し替えます。
- 残りの量に合わせて縮みます（`0.62 + 0.38 * 残り/最大`）。1つ取るたびに、ぷにっとつぶれます。

**脱出口**: `anchor (0.5, 0.66)`、大きさ `TILE * 3` です。

**本陣**: `anchor (0.5, 0.82)`、大きさ `TILE * 3.2` です。

**エフェクト**（`drawFx` / `drawMission` / `drawPops`）
- Pixi の Graphics と Text で描いています。テクスチャではありません。
- 弾の線、着弾、爆発（boom）、届けた輪（deliver）、掘り出し物の星（find）があります。
- 回収中の火花、脱出口の緑の輪、気づきゲージ、「！」もここです。
- 浮かぶ文字「+1」と「★ 名前！ +3」は Pixi Text です（canvas の fillText なので、ひらがなモードが効きます）。

**霧**: ぼかした RenderTexture です。**触らなくてよい** です。

### 2-4. 変えてはいけないもの

- **`bot-commander/js/sim/` は一切触りません。** シミュレーションは純粋（DOM・Pixi・乱数なし）で、決まった時間刻みで動き、同じ条件なら同じ結果になります。
  - テスト `structure.test.mjs` が、sim が描画を import していないことを調べます。
- **テクスチャのキー名**（2-1 の30個）。消さない、名前を変えない。足すのはかまいません。
- **表示サイズとアンカー**（`KIND_PX`、`UNIT_PX`、`TILE` に対する倍率、各アンカー）。
  - 当たり判定やタップの判定（`input.js` の `reach`）は位置で決まります。見た目を合わせるため、変えるなら理由を書いて少しだけにします。
  - **足元が anchor の位置に来る** ことは必ず守ります。
- **動きの仕組み**（描画側が sim の状態を読むだけで作っている動き）。
  - 歩くと上下に揺れる（`body.y = -bob`、`u.moving` から）。
  - 向きの反転（`u.facing`）。
  - 被弾したときの赤い点滅（`body.tint`）。
  - 隊長の絵への差し替え（`_cmd` のキー）。
  - 空の山への差し替え、山がつぶれる動き、脱出口の輪。
  - 歩きのコマ（2コマなど）を足すのはかまいません。**ただし renderer の中で、sim の値（`u.moving`、`u.facing`、`sim.time`、`u.id`）を読むだけにします。sim には書き込みません。**
- `window.__botCommander`（スクショ用の入口）と、DOM の UI（`js/index.js`、`css/bot-commander.css`）。
  - UI の見た目を少し整えるのはかまいません。でも今回の主役は、ゲームの中の絵です。

## 3. 絵の方向（設定画と、決まった設定から）

参考画像は `bot-commander/docs/ref/scavenger_concept_01.jpg` です。ユーザーが描いた設定画で、ツギハギ号・世界の雰囲気・異星生物が描かれています。
ユーザーの手元には、FREEDOM WORKS などメーカーごとの設定シートもあります。必要ならユーザーに頼んでください。
設定画はリアル寄りです。ゲームでは **形と色と光の感じだけを借りて、SD にデフォルメ** します。

### 3-1. ツギハギ号（スカベンジャー。戦えない回収係）

- 主人公が有り合わせの部品で組んだ機体です。
- **暗い色の、リベットの打たれた丸い頭が、全身の高さの約60%** を占めます。
- **大きくて丸い、青く光る目が2つ** あります。目が一番の見分けどころです。光のにじみを少しつけます。
- 細いアンテナが2本、むき出しのケーブル、小さな体と短い手足です。
- 古びた金属に、継ぎはぎの板やテープ、ちぐはぐな部品が付いています。でも汚くしすぎず、かわいく見せます。
- **これから個体ごとの違いを出します**（今回は作らなくてよいが、作りやすくしておく）。
  - コア（中身の AI）側で変わるもの: 色、目の光の色、紋章。
  - 体側で変わるもの: アンテナ、腕の道具、脚、後付けの家庭用品の部品（なべ、スプーン、電球など）。
  - なので `scav()` は、`{ glow, antenna, armTool, legs, addon }` のような**引数で部品を差し替えられる作り** にしておくとよいです。今のキーには既定の組み合わせを入れます。
- 隊長の印は、頭の上の小さなランプです（今と同じ）。

### 3-2. PONCO02（戦闘用。FREEDOM WORKS 製）

- **白・青・赤の三色** で、丸くて親しみやすい形です。
- **暗いバイザーの中に、シアンの目が2つ** 光ります。
- **胸に「F」のロゴ**（FREEDOM WORKS）。図形で描きます。
- 腕に短い銃を持ちます。右向きで、銃が前（右）に来ます。
- ツギハギ号と並んでも、**白い体と三色で、すぐ見分けがつく** ようにします。
- 隊長の印は、頭の金色のとさかです（今と同じ）。

### 3-3. 異星生物（巡回する敵）

- **動物と機械が融合した生体メカ** です。少し不気味にします。ただし子どもも遊ぶので、怖すぎ・グロすぎにはしません。
- 有機的な曲線、肉と金属が混ざった体です（肉の膨らみに、金属の板やチューブが埋まっている）。
- **不揃いに光る琥珀色の目**。数も大きさもばらばらにします。
- **虫やカニのような、とげのある脚** があります。
- 生命力が強いことが伝わるようにします（脈打つような模様、光る傷口や器官など）。
- 味方より大きく（54px）、群れでいても1体ずつ数えられる輪郭にします。

### 3-4. 世界（地形・ガラクタの山・脱出口）

- **滅んだ廃墟に、クラゲのように光る異星の植物が生い茂っている** 世界です。全体の光は **琥珀色**（設定画を参照）。
- 地形タイル（plain / forest / mountain / water）は、今の色の区別を保ちます。
  - 平地: 明るめ。
  - 森: 歩くと遅い。暗めの茂みと、光るクラゲ植物。
  - 山: 通るとかなり遅い。岩とがれき。
  - 水: 通れない。暗い水面。
  - 遊ぶうえで、**4種類が一目で区別できる** ことが一番大事です。
  - 機体より目立たないよう、彩度とコントラストを抑えます。
- ガラクタの山: 機械の残骸、パイプ、歯車、古い家電などです。資材があると分かる、少し光る部品を混ぜます。空の山は、低く暗くします。
- 脱出口のハッチ: 黄色と黒の警告色の縁、赤いランプです（今と同じ方向）。

### 3-5. エフェクト

- 光のエフェクトは、味方が青やシアン、異星生物が琥珀やオレンジにして、陣営の色を分けます。
- 回収は、黄色い火花と「+1」です。掘り出し物は、星がはじける演出です。
- 爆発は、丸く膨らんで消える作風にします。
- どれも Graphics で描く短い演出です。重くしないでください（4-2）。

## 4. 進め方と、できあがりの確認

### 4-1. おすすめの順番

1. **ツギハギ号と PONCO02** を描き直します。zoom 1（32〜34px）でのスクショを見ながら調整します。
2. **異星生物** を描き直します。
3. **地形タイル** を描き直します。継ぎ目と、4種類の見分けを確認します。
4. **ガラクタの山（3種類）と脱出口**。
5. **エフェクト** の色と形を整えます（任意）。
6. 旧兵種（gunner / heavy / hq / marker）は、余力があれば作風を揃えます。

各段階で `node --test bot-commander/tests/*.test.mjs` を実行し、スクショで確認します。

### 4-2. できあがりの確認

**スクショ**（390×844、devicePixelRatio 2、ハブから起動）
- 道具: `bot-commander/tools/mission-shots.mjs`
- 使い方（リポジトリのルートで）:
  1. `python -m http.server 8766 --bind 127.0.0.1` を起動します。
  2. `node bot-commander/tools/mission-shots.mjs <出力フォルダ>` を実行します。
- PC で動かすときは、環境変数を設定します。
  - `PW`: playwright-core の場所
  - `CHROME`: chrome.exe の場所
  - `URL`: ページの場所（既定は `http://127.0.0.1:8766/`）
- 撮れるもの: 開始、回収中、掘り出し物、追跡中、勝ち、負けの画面。
- 見るところ:
  - zoom 1〜1.4 で、ツギハギ号・PONCO02・異星生物の3種類が、色と形だけで見分けられる。
  - 隊長の印が分かる。
  - 霧の中でも、味方の目の光が見える。
  - 背景（地形）より機体が目立つ。
  - 山の残りの見た目と、空の山が分かる。
  - zoom 0.4（引いた画面）で、部隊のかたまりが見分けられる。

**速さ**
- スマホで 60fps を保ちます。
- テクスチャの数は、今の30個から大きく増やしません（目安 50個まで）。
- 焼く大きさは 256px まで。毎フレーム SVG を焼き直したりしません（焼くのは起動時の一度だけ）。
- Graphics のエフェクトは、1フレームで描く数を増やしすぎないようにします。
- 起動時に焼く時間も、長くならないようにします（目安: 今の2倍以内）。

**ルール**
- テストが全部合格する（今は27件）。
- 版の番号を上げる（5章）。
- 変更は `bot-commander/` の中だけにする。

### 4-3. 避けること

- **SVG のフィルター**（`feGaussianBlur`、`feDropShadow` など）を多用しない。
  - iOS Safari で、SVG を Image として描くときの見え方が不安定で、焼くのも遅くなります。
  - 光は、半透明の円を重ねて表します。
- SVG の中に `<text>` や外部の画像・フォントを入れない。
- 細すぎる線（表示で 1px 以下になるもの）や、細かい模様に頼った見分け方をしない。
- 1つの SVG の中で、clipPath や gradient の id が重なる。
- アンカーと足元のずれ（足が地面から浮く、沈む）。
- リアルすぎる作風、怖すぎ・グロすぎな異星生物。
- `js/sim/` の変更。ゲームのバランス（数値）の変更。
- 他のゲームのフォルダや、共有ファイル（`index.html`、`sw.js`、`common/` など）の変更。

## 5. スタジオのルール（AGENTS.md。必ず守る）

- **編集するのは `bot-commander/` の中だけ** です。
- **版の番号は全部いっしょに上げます。**
  - `bot-commander/sw-assets.js` の `version`。今は `'v5'` なので、次は `'v6'`。
  - 同じファイルの `gameVersion`。今は `'0.2.1'` なので、例えば `'0.3.0'`。
  - ファイルを増やしたり減らしたりしたら、同じファイルの `files` も直します。
  - `bot-commander/` の中の **すべての `?v=`** を同じ番号にします（`?v=5` なら全部 `?v=6` に）。CSS の `?v=` は `js/index.js` にあります。
  - 例外: `tests/sim.test.mjs` の `?v=1` は前からこのままです。触らなくてかまいません。
  - テスト `structure.test.mjs` は、同じモジュールを違う `?v=` で読んでいないかと、`sw-assets.js` の中身を調べます。
- **テスト**: `node --test bot-commander/tests/*.test.mjs` が全部合格すること。
- **Git**
  - `git add bot-commander/` だけを使います。**`git add -A` と `git add .` は禁止** です。他のゲームの作業中の変更を巻き込むためです。
  - 改行は **LF** のままにします。Windows で CRLF にしないでください（エディタと git の autocrlf に注意）。
- **ひらがなモード**
  - ハブには、むずかしい漢字をひらがなで見せる「ひらがなモード」があります（`common/js/kana-mode.js`）。
  - これは DOM の文字と、canvas の fillText（Pixi Text）だけを変えます。**SVG の中に描いた文字は変換されません。** だから絵の中に文字を入れません。
  - ひらがなモードのテストは `common/js` だけを調べます。このゲームの文字は、表示のときに変換されます。
