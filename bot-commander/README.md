## v0.2.0〜 ミッション「資材集め・巡回・脱出」（試作。v0.2.1 で制限時間をなくした）
- 自軍（v0.4.0-dev）: **ツギハギ号×4**（戦えないスカベンジャー。資材を集めるのが速い）＋ **PONCO02×8**（戦えるが、異星生物はしぶとい）＋ 少年・少女。
- **ガラクタの山（回収ポイント）**: 機体をその近く（黄色い輪の中）で止めると、資材を集める。山の下のバーが残り。空になると集まらない。PONCO02 も集められるが遅い。
- **脱出口**（黄色と黒のハッチ、緑の輪）: 資材を運んでいる機体が輪に入ると、その機体の分を届ける。上のバー（緑＝届けた、黄色の縞＝運搬中）が目標に届けば **脱出成功**。
- **異星生物の巡回**: 決まった道を回る。見えると頭の上の気づきゲージが上がり、満タン（赤い ！）で追いかけてくる。森の中の機体は近づかれないと見つからない。見失ってしばらくすると、あきらめて巡回路へ戻る。撃たれるとすぐ追ってくる。攻撃されないと少しずつ再生する。
- ツギハギ号と人間は、移動命令中は撃ち合いで止まらずに逃げる。「急行」で動かした機体も撃たずに走る。運んでいる資材は、やられた機体の分だけ失う。
- **負け**: ロボが全滅し、動ける人間もいないとき（または少年が捕まったまま）。**制限時間はない**（のんびり集めてよい。右上の小さな数字はただの経過時間）。
- **回収のお楽しみ**: 1つ集めるたびに「+1」が出て、山がぷにっと縮む。ときどき「めずらしい部品」などの掘り出し物（★、資材+3）が見つかる（`FIND` で調整。抽選は seed 付き乱数なので再現できる）。結果画面の「もう一度」で最初から。
- 調整のつまみ: `js/sim/mission.js`（ALERT の気づき・追跡・再生、回収の距離、FIND の掘り出し物、目標、ポイントの位置と量、巡回路）と `js/sim/sim.js` の `KINDS`（HP・攻撃・速さ・視界・回収の速さ）。
- スクショ: `node bot-commander/tools/mission-shots.mjs [出力フォルダ]`（ハブ込み、開始・1機選択・種類選択・枠選択・命令・回収中・追跡・捕獲・巣へ運ぶ途中・巣に着いた・結果）。

## 操作（v0.4.0）
- **ロボをタップ**＝その1機だけ選ぶ（選んでいる1機をもう一度タップで外す）。**地面をタップ**＝選んだ機体がそこへ（数機なら1マスずつばらけて並ぶ）。**見えている敵をタップ**＝狙う
- **ロボを長押し**＝同じ種類を全部選ぶ。**地面を長押ししてなぞる**＝枠の中をまとめて選ぶ
- 上の **全員／ツギハギ／PONCO／人** ボタン＝その種類をまとめて選んでカメラを寄せる。下の **①②③**＝組（タップで呼び出し、空ならいまの選択を覚える、長押しで上書き）
- 選んでいる間は下に命令バー: **戦闘移動⇔急行**（地面タップの動き方）・**止まる**・**その場⇔迎撃**（構え）・**撤退**（本陣へ撃たずに走る）・**✕**（選択を外す）
- ドラッグ＝画面の移動、2本指＝ズーム（PCはホイール）。⏸＝一時停止（止めたまま命令できる）。右上「☰ メニュー」＝一時停止して、速さ（1x／2x）や「工房へ戻る」（確認付き）
