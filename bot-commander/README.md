- **ロボの名前**（Codex）: 名前のない味方ロボ（自分の・AI の仲間）に「一般名称（42 語）＋型番（I/O を除く英字 2 文字-1〜99）」の名前。例「スピードスターAZ-7」。試合の中で同じ名前は出ない。名前は seed とミッションから専用の乱数で決まり（sim.rng は使わない）、リプレイでも同じ。人・物語のキャラ（ロウ・ミント・ネジ）・発射台・敵は今までどおり。名前は表示だけ（sim の label は変えないので、物語の判定・武器庫の保存はそのまま）。トースト・「○○：敵を発見！」・選択のヒント・成績とランキング・MVP に出る。長い一般名称は小さく、型番はいつも全部見せる。`js/names/robot-names.js`・`tests/robot-names.test.mjs`。

## 操作（v0.4.0）
- **ロボをタップ**＝その1機だけ選ぶ（選んでいる1機をもう一度タップで外す）。**地面をタップ**＝選んだ機体がそこへ（数機なら1マスずつばらけて並ぶ）。**見えている敵をタップ**＝狙う
- **ロボを長押し**＝同じ種類を全部選ぶ。**地面を長押ししてなぞる**＝枠の中をまとめて選ぶ
- 上の **全員／ツギハギ／PONCO／人** ボタン＝その種類をまとめて選んでカメラを寄せる。下の **①②③**＝組（タップで呼び出し、空ならいまの選択を覚える、長押しで上書き）
- 選んでいる間は下に命令バー: **戦闘移動⇔急行**（地面タップの動き方）・**止まる**・**その場⇔迎撃**（構え）・**撤退**（本陣へ撃たずに走る）・**✕**（選択を外す）
- ドラッグ＝画面の移動、2本指＝ズーム（PCはホイール）。⏸＝一時停止（止めたまま命令できる）。右上「☰ メニュー」＝一時停止して、速さ（1x／2x）や「工房へ戻る」（確認付き）
