# ゾンビストライク（zombie-tps） v0.12.0

かたごし カメラの シューティング（TPS）。ブロックの まちで ゾンビを うって ウェーブを のりこえよう！

- ゾンビに あたると **みどりの しぶき**（つぶ＋じめんの しみ、すぐ きえる）。たおすと ポン！と きえる。
- さいしょの ぶきは **アサルトライフル**（30はつ・フルオート）。ハンドガン（たま むげん）・ショットガンも つかえる。
- あたまに あたると ヘッドショット（ダメージ アップ＋ボーナス）。
- **ロケットランチャー**（4ばん）: 1はつずつ・よびだん 3（さいだい 6）。**ウェーブの ほじゅうは なし**、ゾンビが ときどき おとす ひかる **ロケットだんの はこ** を さわると ひろえる（20びょうで きえる・さいごは ちかちか）。ばくはつで たおすと ゾンビは **ブロックに くだけて とびちる**（ちは でない）。まとめて たおすと スローモーション＋ボーナス。
- ショットガンを ちかくで うつと ゾンビが ふっとぶ。ライフルは すこし のけぞる。
- **ウェーブごとに ひる → ゆうやけ → よる → ひる …** と じかんが かわる（そら・ゆうひ・つき・きり・がいとう が なめらかに かわる）。v0.6.1 から いつも くらくて こわい ふんいき（むらさきの ゆうぐれ・あかい ゆうやけ・みどりの よる、こい きり、つきと かみなり、とおくで もえる まち）。タイトルでは スタートの じかん（☁️ ひるから / 🌙 よるから）を えらぶ。v0.7.1: よるの あと「ひるに なった」で みためも ちゃんと ひるに もどる（くもりの はいいろの そら・とおくまで みえる・ほしと つきと ライトは きえる。まちは もえていて うすぐらい まま）。よるは じゅうの ライトが じどうで つく（せっていで オフにも できる）。
- **3ウェーブごとに ボスゾンビ**: おおきくて かたい。HP バーつき。りょううでを あげて ためてから ドスン！（あかい わ・ジャンプで よけられる）、あかい みちが でたら とっしん。たおすと ロケットだんを かならず 2こ おとす。
- **のぼれるのは はやい ゾンビ（オレンジの ふく）だけ**: くるま・はこ・ひくい かべに のると、ほかの ゾンビは まわりに あつまって てを のばす。はやい ゾンビは まいウェーブ かならず くるし、たかい ところに いすわると（4.5びょう）はやい ゾンビが おいかけて くる。でかい ゾンビと ボスは くるまを たたいて おとしてくる。だから **あんぜんな ばしょは ない**。
- **おそわれてる おじさん**: 2〜3ウェーブに 1かい（ボスの ウェーブは なし）、はげた やさしい おじさんが ゾンビに かこまれて「たすけて！」。ふきだしと HP バー、がめんの そとなら やじるしで ばしょが わかる。まわりの ゾンビを ぜんぶ たおすと「ありがとう！」で **ふく** を くれて、すぐ きがえる（「あたらしい ふくを もらった！」）。おじさんが やられそうに なると「ひえ〜っ！」と にげて いなくなる（また こんど）。
- **ふく（みためだけ・つよさは おなじ）**: ふつう・めいさいふく・にんじゃ・かいとう・うちゅうふく・ゴールド・ロボット。もらった ふくは セーブされ、タイトルの「👕 きがえ」で えらべる（もっていない ふくは ？）。
- **そうび（ランダム ドロップ）**: ヘルメット・ベスト・くつ・うでわ の 4つ。レアど は ふつう／レア／すごいレア／でんせつ（ひかりの いろで わかる）。のうりょく は ぼうぎょ・さいだいHP・はやさ・リロード で、ごうけいに じょうげん（ぼうぎょ 30%・HP +50・はやさ 15%・リロード 25%）。ふつうの ゾンビは たまに、おおきい ゾンビは よく、ボスは かならず すごいレア いじょう、おじさんも レア いじょうを くれる。ひろうと いまの そうびと くらべる カード（そうび／しまう／すてる、9びょうで じどうで しまう）。かばんは 20こ まで、タイトルの「🛡 そうび」で つけかえ。いろは キャラの もようとして みえる。
- **6つの マップ（v0.5.0・まえより ひろい 84〜92m）**: 🏙 まち（こわれた ビルと ひろい みち）・🛒 ショッピングモール（くるまが いっぱいの ちゅうしゃじょう）・⛺ ぐんの きち（テント・みはりだい・コンテナ）・🌷 びょういん（しろい たてものと にわ・ふんすい）・🌲 もりの キャンプじょう（き・テント・こや・いけ）・⚓ みなと（コンテナの まよいみち と クレーン）。タイトルで えらぶか「🔀 おまかせ」で じゅんばんに かわる。どの マップでも おじさん・そうびの ドロップ・のぼりの きまりは おなじ。ひろい マップでも まちくたびれない ように、ゾンビは ちょうど いい きょりの ゲートから でて、とおい ゾンビは すこし いそぐ。
- **けいさつロボ（v0.7.0）**: マップの どこかに しろと こんの ロボが ねむっている（あおい ランプと ほしの マークで ひかって いる・スタートの ばしょ には いない）。さわると「けいさつロボが なかまに なった！」。プレイヤーの うしろ ひだりに ついてきて、うしろや よこから くる ゾンビを ライフルで うって くれる。ロボにも HP が あり（かいふく しない）、ゾンビに たたかれて こわれるまで いっしょ。こわれると ブロックに なって バラバラ（ちは でない）。かいだんも のぼり、はなれすぎたり ひっかかったら みえない ところで ちかくに ワープ。

- **おじさんが ながく がんばる（v0.7.0）**: プレイヤーから 9〜18m の ちかくに でる。ゾンビは 5〜7m はなれた ところから くる・いちどに たたけるのは 2たいまで（ほかは まわりで まつ）・こうげきは とても よわく きく → すくなくとも やく 50びょう いきのびる（テストで チェック）。あたまの うえの HP バーと「たすけて！」の やじるしで ばしょが わかる。

## そうさ
| | スマホ（よこむき） | パソコン |
|---|---|---|
| いどう | ひだりがわを ゆびで ドラッグ | WASD / やじるし |
| ねらう | みぎがわを ドラッグ | マウス（クリックで ロック） |
| うつ | 「うつ」ボタン（おしたまま ドラッグで ねらえる） | ひだりクリック |
| ズーム | 「ねらう」ボタン | みぎクリック |
| リロード / ジャンプ | ボタン | R / スペース |
| ぶき | うえの 1〜5 | 1〜5・Q・ホイール |
| ポーズ | Ⅱ | ESC / P |
