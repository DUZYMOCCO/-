# 🐜 カラー・アント（Color Ants）

> **「外側から順に削れ！出撃スロットとお助けアイテムを駆使してドット絵を食べつくすパズルゲーム」**

## 🎮 遊び方＆ルール

1. **外側（露出ピクセル）からしか食べられない**
   - 上下左右のいずれかが「盤面外」「背景」「既に食べられたマス」であるピクセルのみが標的になります。
   - 内側のピクセル（スイカの果肉の奥や種など）は、周りの皮や表面を剥がすまで食べられません。
2. **出撃スロット（トレイ）＆ 3つの巣穴**
   - 下の5列の先頭タイルをタップすると、トレイの空きスロット（初期5枠、アイテムで6枠）に入ります。
   - 地面にある3つの巣穴からアリが分かれて出撃し、現在露出しているピクセルをかじります！
   - ピクセルをかじるごとにタイルの数字が減り、全員帰還するとスロット枠が空きます。
   - 待機中（まだ外側に露出していない）のスロットは、タップすると元の列へ戻せます。
3. **手詰まり（STUCK）とレスキュー**
   - スロットがすべて埋まり、かつどのスロットの色も外側に露出していないと手詰まりになります。
   - 手詰まり時も「🧲 そうじアイテムで脱出」「↺ 1手もどす」「🔄 やり直す」から選んで復活できます。
4. **子供向けお助けアイテム（ブースター）**
   - **↺ もどす**：直前にスロットに入れた待機中タイルを列へ戻します。
   - **➕ 枠+1**：スロット枠を5枠 → 6枠に増やして余裕を持たせます。
   - **🔀 シャッフル**：列のタイルを並び替えてチャンスを作ります。
   - **🧲 そうじ**：外側に露出しているマスを一気に最大25個回収します！
5. **ステージギミック：鍵と南京錠（🔒・🗝️）**
   - レベル2以降、一部のタイルに南京錠（🔒）がかかります。
   - カギタイル（🗝️）をタップしてスロットに入れると、ロックが解除されて使えるようになります！
6. **便利機能**
   - 右上「🔄」でいつでも即時やり直し。
   - 右上「▶▶」で ×2 倍速切り替え。

絵は 64×64 の高精細ドット絵（すいか・カップケーキ・ひよこ・いちご・にじ・きのこ）。

## 🧩 構成

```text
color-ants/
  sw-assets.js      Service Worker キャッシュ定義 (v6 / 2.3.0)
  css/color-ants.css
  js/
    index.js        画面・スロットトレイ・タイル列・ブースター・ゲームループ
    pictures.js     64×64 ドット絵データ（背景 bg の除外とパレット）
    puzzle.js       外側層優先の小口タイル生成＆鍵・南京錠ギミック
    colony.js       アリの行動・外側露出判定・スロット管理・3つ巣穴・マグネット
    renderer.js     Canvas描画（額縁・絵・アリ・3つの巣穴・星パーティクル）
  tests/rules.test.mjs
```
