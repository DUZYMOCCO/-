# 🐜 カラー・アント（Color Ants）

> **「数字タイルをタップして、アリの行列でドット絵を食べつくせ！」**

## 🎮 遊び方

1. 画面下の **数字タイル**（5列）の一番上をタップすると、その数のアリが巣穴から出発します。
2. アリは **タイルと同じ色のピクセル** を1つくわえて巣穴へ運び、絵がだんだん消えていきます。
3. 全部のタイルを使って絵を食べきるとクリア！次のレベルの絵へ進みます。
   - 奥のタイルは「？」。手前に来ると色と数字がわかります。
   - 右上の **▶▶** で ×2 倍速。

絵は 32×32 のドット絵（すいか・カップケーキ・ひよこ・いちご・にじ・きのこ）。クリア画面で完成した絵を眺められます。
各色のタイルの数字の合計はその色のピクセル数と一致するので、必ず食べきれます。

## 🧩 構成

```text
color-ants/
  sw-assets.js      Service Worker キャッシュ定義
  css/color-ants.css
  js/
    index.js        画面・タイルUI・ゲームループ
    pictures.js     32×32 ドット絵の生成（図形ヘルパー＋パレット）
    puzzle.js       タイル生成（色ごとのピクセル数を数字タイルに分割）
    colony.js       アリの行動シミュレーション（DOM非依存）
    renderer.js     Canvas描画（額縁・巣穴・アリ・かけら）
  tests/rules.test.mjs
```
