# 🐜 カラー・アント（Color Ants）

> **「数字タイルをタップして、アリの行列でドット絵を食べつくせ！」**

## 🎮 遊び方

1. 画面下の **数字タイル**（5列）の一番上をタップすると、その色のアリが巣穴から **1匹ずつ** 出発します。
   - 出発に合わせてタイルの数字が減り、色の帯が縮んでいきます。全員出発するとタイルが消えて列が進みます。
   - 別の列のタイルを同時にタップすると、行列が何本も伸びます。
2. アリはタイルと同じ色のピクセルを1つかじってくわえ、巣穴へ運びます（行きと帰りは2車線）。
   - 絵はかじられた場所から消え、巣穴に届くたびに画面上の「運んだ ○ / ○」が増えます。
3. 全部運びきるとクリア！完成した絵を眺めて、次のレベルの絵へ進みます。
   - 奥のタイルは「？」。手前に来ると色と数字がわかります。
   - 右上の **▶▶** で ×2 倍速。

絵は 64×64 のドット絵（すいか・カップケーキ・ひよこ・いちご・にじ・きのこ）。
各色のタイルの数字の合計はその色のピクセル数と一致するので、必ず食べきれます。

## 🧩 構成

```text
color-ants/
  sw-assets.js      Service Worker キャッシュ定義
  css/color-ants.css
  js/
    index.js        画面・タイルUI・ゲームループ
    pictures.js     64×64 ドット絵の生成（32分割座標の図形ヘルパー＋パレット）
    puzzle.js       タイル生成（色ごとのピクセル数を数字タイルに分割）
    colony.js       アリの行動シミュレーション（DOM非依存）
    renderer.js     Canvas描画（額縁・絵はキャッシュ、アリ・巣穴・かけら）
  tests/rules.test.mjs
```
