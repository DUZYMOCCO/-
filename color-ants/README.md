# 🐜 カラー・アント（Color Ants）

> **「外側から順に削れ！出撃スロットを上手く回してドット絵を食べつくすパズルゲーム」**

## 🎮 遊び方＆ルール

1. **外側（露出ピクセル）からしか食べられない**
   - 上下左右のいずれかが「盤面外」「背景」「既に食べられたマス」であるピクセルのみが標的になります。
   - 内側のピクセル（スイカの果肉の奥や種など）は、周りの皮や表面を剥がすまで食べられません。
2. **5つの出撃スロット（トレイ）**
   - 下の5列の先頭タイルをタップすると、トレイの空きスロット（最大5枠）に入ります。
   - スロット内のタイルから、現在露出しているピクセルへ向かってアリが出撃！
   - ピクセルをかじるごとにタイルの数字が減り、全員帰還するとスロット枠が空きます。
   - 待機中（まだ1匹も出撃できない＝外側に露出していない）のスロットは、タップすると元の列へ戻せます。
3. **手詰まり（STUCK）に注意！**
   - 5つのスロットがすべて埋まり、かつどのスロットの色も外側に露出していないと手詰まりになります。
   - 外側に露出している色を見極めて、手前にある色から順にスロットへ送りましょう。
   - 手詰まり時は「1手もどす」または「やり直す」が選べます。
4. **小口タイル＆奥のタイル**
   - 1タイルの数字は 12〜35 前後の手頃なサイズに分割。
   - 各列の手前4段が表示され、奥のタイルは「？」。手前に進むと色と数字がわかります。
   - タイルの数字の合計は絵のピクセル総数と一致します。
5. **便利機能**
   - 右上「🔄」でいつでも即時やり直し。
   - 右上「▶▶」で ×2 倍速切り替え。

絵は 64×64 の高精細ドット絵（すいか・カップケーキ・ひよこ・いちご・にじ・きのこ）。

## 🧩 構成

```text
color-ants/
  sw-assets.js      Service Worker キャッシュ定義 (v5 / 2.2.0)
  css/color-ants.css
  js/
    index.js        画面・スロットトレイ・タイル列・ゲームループ
    pictures.js     64×64 ドット絵データ（背景 bg の除外とパレット）
    puzzle.js       外側層優先の小口タイル生成（BFS距離に応じた配分）
    colony.js       アリの行動・外側露出判定・スロット管理・詰み判定
    renderer.js     Canvas描画（額縁・絵・アリ・巣穴・かけら）
  tests/rules.test.mjs
```
