# 🐜 カラー・アント（Color Ants）

> **「外側から順に削れ！出撃スロットとお助けアイテムを駆使してドット絵を食べつくすパズルゲーム」**

## 🎮 遊び方＆ルール

1. **外郭からしか食べられない**
   - 外部から上下左右でつながっている空間に面したピクセルだけが標的です。絵の内部に閉じ込められた背景・空洞は、外側とは扱いません。
   - アリは別色を横切らず、空いた通路を歩いて外郭へ向かい、同じ通路で帰ります。
   - 内側のピクセル（スイカの果肉の奥や種など）は、周りの皮や表面を剥がすまで食べられません。
2. **出撃スロット（トレイ）＆ 3つの巣穴**
   - 下の5列の先頭タイルをタップすると、トレイの空きスロットに入ります。1〜6面は4枠、7面以降は3枠。枠+1は1面に1回だけ使えます。
   - 地面にある3つの巣穴からアリが分かれて出撃し、現在露出しているピクセルをかじります！
   - ピクセルをかじるごとにタイルの数字が減り、全員帰還するとスロット枠が空きます。
   - 待機中のスロットをタップすると「もどす」を1回消費して元の列へ戻せます。まだ1匹も出撃していないタイルだけが対象です。
3. **手詰まり（STUCK）とレスキュー**
   - スロットがすべて埋まり、かつどのスロットの色も外側に露出していないと手詰まりになります。
   - 手詰まり画面から残っている「そうじ」「もどす」「枠追加」を使えます。「やり直す」で再挑戦、「あきらめる（工房へ）」で退出できます。あきらめてもステージ番号は進みません。
4. **回数制のお助けアイテム（ブースター）**
   - **↺ もどす**：最後に入れた未出撃の待機タイルを列へ戻します。1〜6面は2回、7面以降は1回。待機枠の直接タップと共通の残数です。
   - **➕ 枠+1**：出撃枠を1つ増やします。1面につき1回。
   - **🔀 シャッフル**：列のタイルを並び替えます。1面につき1回。
   - **🧲 そうじ**：外郭のマスを最大25個回収します。1面につき1回。
   - アイコン右上の数字が残り回数です。やり直し・次の面で補充されます。
5. **ステージギミック：鍵と南京錠（🔒・🗝️）**
   - レベル2以降、一部のタイルに南京錠（🔒）がかかります。
   - カギタイル（🗝️）をタップしてスロットに入れると、ロックが解除されて使えるようになります！
6. **便利機能**
   - 右上「↻」でいつでも即時やり直し。
   - 右上「▶▶」で ×2 倍速切り替え。

絵は64×64のピクセルアート18種類。18面ごとに絵柄を繰り返し、配置はステージ番号ごとに変わります。

## 2.7.0 ステージ追加・上級構成・柔らかい食事音（2026-10-18）

- 絵柄を6→18種類へ拡張。7〜12面はドーナツ、トリプルアイス、ペンギン、さくら、こぎつね、ロケット。13〜18面は宝箱、ふくろう、蝶、キャンディ迷宮、クリスタル、お城。
- 13面から「上級」。3枠を維持し、内側の色が続く列を深くし、見えるタイルを先頭だけに、鍵・ロックを3組にする。
- 25面から「超上級」。内側の色は最大5枚続き、鍵・ロックは4組。正しい順番の解法は残す。
- 食べる打撃音を、短く丸い低めの専用音へ変更。音量を抑え、最短0.18秒間隔に制限。通常のミュート・効果音音量に従い、退出・再開時に残る食事音を止める。
- 手詰まり画面に「あきらめる（工房へ）」を追加。ループと食事音を止め、進行をクリア扱いにせず工房へ戻る。
- 20件のテスト成功。1〜36面をブラウザーでも道具なしで全回収し、上級の手詰まり・音の再生とミュート・あきらめ後の同一面への再入場を確認。

## 2.6.0 難易度調整（2026-10-16）

- 出撃枠を4枠、7面目以降は3枠へ縮小。
- 内側の色を先に見せる列を最大3列、4面目以降は最大4列へ増加。同色の待機候補を2枚、7面目以降は3枚まで続け、無計画に押すと枠を使い切る配置に変更。
- 4面目以降は奥の2段を「？」にして、見通せる情報を減らす。
- お助けと待機枠の返却を回数制へ変更。手詰まり画面にも残数を表示。
- 16件のテスト成功。通常の列タップだけで1面・7面の実際の手詰まりを再現し、返却回数の枯渇も確認。
- 18ステージの解法を通常・倍速で検証。ブラウザーでも1〜12面を各4枠/3枠・道具なしで全回収できることを確認。

## 2.5.0 外郭ルールとパズル配置の修正（2026-10-15）

- 外部へつながる空間を調べ、閉じた内部空洞や斜めの隙間から食べ始めることを禁止。
- アリの往復を通路に沿う経路へ変更。まだ食べられない色の出撃枠は、外郭が開くまで待機し、開いたら自動で再出撃。
- 平均的な深さによる並び順を廃止。外郭から回収できる色領域を順に削る手順を作り、必要なタイルが列の奥へ埋まらない配置に変更。
- 早めに見える内側の色も残す。正しい順番の解法を持つ配置であり、すべての選択を安全にするものではない。
- 鍵は対応するロックより前に取得可能。シャッフルは解法の順序を保ちながら列を振り直す。
- そうじの回収数を複数の出撃枠・待機列へ正確に反映し、余った数字による停止を防止。
- 15件のテスト、18ステージ×通常/倍速の解法検証、およびブラウザーで全6種を5枠・道具なしで完走確認。

## 2.4.0 の見た目の更新（2026-10-15）

- 木のピクニックテーブル風の背景・額縁、立体的な色タイルと道具ボタンに統一。

## 🧩 構成

```text
color-ants/
  sw-assets.js      Service Worker キャッシュ定義 (v10 / 2.7.0)
  css/color-ants.css
  js/
    index.js        画面・スロットトレイ・タイル列・ブースター・ゲームループ
    pictures.js     64×64 ドット絵データ（背景 bg の除外とパレット）
    puzzle.js       解法のある外郭順の小口タイル生成＆鍵・南京錠ギミック
    perimeter.js    外部とつながる空間・外郭・往復経路の共通判定
    colony.js       アリの行動・外側露出判定・スロット管理・3つ巣穴・マグネット
    renderer.js     Canvas描画（額縁・絵・アリ・3つの巣穴・星パーティクル）
    soft-audio.js   小音量の食事PCM・間隔制限・共有ミュートとの連携
  tests/rules.test.mjs
  tools/playtest.mjs  ローカルChromeで表示・主要操作を検証
  docs/CURRENT_WORK.md
```

## 🧪 テスト

```bash
node --test color-ants/tests/*.test.mjs
```

ローカルサーバー起動後、Playwright と Chrome が使える環境で:

```bash
node color-ants/tools/playtest.mjs
```

食事音のプレビューを再出力する場合は `node color-ants/tools/export-audio-preview.mjs`。

既定の接続先は `http://127.0.0.1:8000`。別のURLは `COLOR_ANTS_ORIGIN` 環境変数で指定する。ブラウザー検証は保存データを隔離した一時コンテキストで実行する。
