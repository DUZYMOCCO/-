# 🐜 カラー・アント（Color Ants）

> **「色をたべつくす、わらわら蟻軍団！」**  
> スマホの広告でおなじみの、同じ色のアリがカラフルな絵をガリガリ食べ尽くしていく爽快・中毒系クリッカーゲーム。

---

## 🎮 遊び方

1. **自律行動するアリたち**:
   - 巣穴から湧き出たアリたちが、自分と同じ色のピクセルを見つけてモグモグ食べます。
   - ピクセルを削るたびにコインを獲得！
2. **画面タップで超加速（Frenzy Boost）**:
   - 画面をタップ連打すると、アリたちが猛烈ダッシュ＆爆速咀嚼！
3. **アップグレードで軍団強化**:
   - 🐜 **アリの数**: 出撃上限アップ（最大60匹）
   - ⚡ **いどう速度**: 足が速くなって現場へ急行
   - 🍽️ **あごの力**: 1口で削るダメージ量アップ
   - 👑 **ジャイアント**: 周囲のピクセルもまとめて丸呑みする巨大アリが出現！
   - 🎨 **新種アリ解放**: 緑・黄・青・紫・そして全色を食べる「にじいろアリ」を順次アンロック！
4. **全ピクセル完食でステージクリア**:
   - りんご、ひよこ、すいか、カップケーキ、うちゅうせん、にじのスターなど多彩なステージが登場。
