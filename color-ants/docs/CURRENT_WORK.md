## 2026-10-18 / 2.8.0 / cache v12

依頼: 見た目ではアリが行けそうな場所なのに、出撃せず待機になる。

### 原因と修正

- 外郭へ経路がある同じ食べ物色を出撃できない不整合は、探索した範囲では見つからなかった。一方、ひよこの `yel3` と `wing` などのほぼ同じ陰影が別の食べ物キーだったため、見た目では同色に見える場所を食べられない状態を再現できた。
- 全18種類の絵へ明示的な色グループを追加。`paintKey` と `hex` は元の絵の陰影、`key` は食べ物の色として分ける。近いRGB値から自動でまとめず、素材や陰影に応じて定義する。ピクセル数と絵の塗り色は保持。
- 待機表示も、以前は「まだ1匹も出撃していない」だけで判定していた。出撃可能な直前状態を待機と表示する一方、部分的に出撃後、本当に道が塞がった枠は出撃中のままだった。
- `Colony.slotState()` と外郭の色別未予約/予約数を導入し、実際の出撃・手詰まり判定・枠の表示を同じ外郭情報へ統一。「準備」「順番待ち」「外郭待ち」「回収中」を区別する。
- 枠のクリックは最新の未出撃条件で判定。表示更新で道具の残数や返却条件が変わることを防ぐ。
- 外部に4方向でつながる空間のみを通るルール、閉じた空洞・斜めの隙間を通さないルール、難度ごとの枠数・道具回数、チョピチョピ音は継続。保存されたステージ番号を初期化しない。
- ゲーム内参照を v12、`sw-assets.js` を v12 / 2.8.0へ更新。共有ファイル・他ゲームは編集しない。

## 2026-10-15 / 2.5.0 / cache v8

ユーザーの修正指示: アリが自分の色へ直接進む状態を直し、外郭から削っていく順番と5枠のやりくりをパズルの中心にする。

### 修正

- `perimeter.js` を追加。盤面を一周できる余白から、4方向で外部とつながる空間を探索。閉じた背景・内部空洞・斜め接続は外部と見なさない。
- `colony.js` の露出判定、標的予約、手詰まり、そうじを同じ外郭判定に統一。標的へ一直線に進まず、空いている通路をたどって外郭へ進み、来た経路を戻る。画面サイズ変更時もアリの盤面内位置を保つ。
- `puzzle.js` は外郭から回収できる同色領域を順に取り除く手順からタイルを生成。必要なタイルが、未来の色の後ろに埋まらないように列へ配置する。
- 内側の色を早めに見せる選択肢を最大2列へ配置。正しい順番なら道具なしで進めるが、先に内側の色を抱えすぎると枠を圧迫する。ゲーム中に色を無視して救済回収する仕組みは加えていない。
- 鍵とロックを対応付け、解法中で鍵が先になるように配置。シャッフルも必要な順序を壊さず列を振り直す。
- そうじの回収数は、同色の複数枠と列の残数へ正確に割り当てる。消えた鍵タイルも対応ロックを解除する。
- 画面下の案内を「外郭の色から食べよう・内側の色は待機」に更新。描画するアリの大きさ・横ずれを盤面内ではマス幅へ収める。
- ゲームのみ v2.5.0 / cache v8。新モジュールをキャッシュ一覧に追加。共有ファイルは変更していない。
