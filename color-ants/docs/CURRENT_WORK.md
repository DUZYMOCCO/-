# カラー・アント 現在の作業

## 2026-10-15 / 2.4.0 / cache v7

依頼: 提示されたカジュアルなアリとピクセルアートのゲーム画面を参考に、カラーアントの品質を改善する。

### 変更内容

- 木のテーブル、立体的なタイル、淡い色の道具、木製フレームで画面を統一。
- すいかの形とパレットを描き直し。全6種に共通のピクセル陰影、アリの触角とハイライト、巣穴の縁、背景の葉と点線を追加。
- 回収率、絵の名前、トレイ使用数を表示。道具を最下部へ移動。
- 奥の「？」タイルが共通CSSの `.hidden` で非表示になる問題を、ゲーム固有の `.mystery` に変更して解決。
- 小型の縦画面では操作部分を圧縮し、横画面は盤面と操作を左右に配置。Canvas密度を最大DPR 3に制限。
- 枠・ピクセル陰影・背景はオフスクリーンCanvasへキャッシュ。回収済みのマスのみ消す仕組みを継続。
- 色タイルと待機枠をキーボードでも操作可能なボタンとして扱う。回収率と通知に読み上げ情報を追加。
- `sw-assets.js` の版とゲーム内の変更モジュール参照を更新。

変更は `color-ants/` 内のみ。他ゲームと工房の共有ファイルは対象外。保存キー `color_ants_v2` は継続し、ステージ番号を保持。

### 検証

- `node --test color-ants/tests/*.test.mjs`: 9件成功。
- JavaScript構文検査と `git diff --check -- color-ants/`。
- `node color-ants/tools/playtest.mjs`: ローカルChrome / DPR 2、ページエラー・HTTPエラーなし。
- 390×844、320×568、375×667、1280×900、844×390。操作部分の画面内への収まり、額縁と盤面、4段のタイルを確認。
- 全6種の絵を撮影・目視確認。出撃・帰還、回収率、倍速、6枠、そうじ、シャッフル、再開、待機枠返却、もどす、工房復帰を検証。
- 手詰まり救済とクリア→次の絵は状態を用意してUI遷移を検証。全ステージの自然プレイによるクリアを保証する検証ではない。
- モーション軽減設定でCSSのアニメーション・遷移を停止。通知はJSのタイマーでも消える。
