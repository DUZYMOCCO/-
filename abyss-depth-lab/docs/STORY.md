## 2. 世界観・バックストーリー

- **2xxx年（生物の異常進化）**: 人間以外の全ての生物が異常に進化を開始し、海への適応へと向かい始めた。原因は不明。原因がわからないまま、かつてない生態系が海に生まれた。
- **数十年後（太陽の異常膨張）**: それが当たり前になった頃、太陽が異常膨張を起こし、地球の表面は灼熱の星となった。この太陽の異常膨張には未知の「外部要因」が絡んでおり、超高性能 AI である ponco MarkII の計算すら超える速度で壊滅的に進行していた。
- **生き残った存在**:
  - 太陽の異常を察知して海底基地へと逃れた人々、木星圏・火星方面へ太陽から離れた人々、そして新たに生まれた海洋生物だけが生き残った。
  - しかし、圧倒的な崩壊の波は地球を飲み込んだ後、さらに外側へ広がって火星にまで到達し、火星もまた死の星となった。火星から脱出した避難民は木星の氷の衛星エウロパに身を寄せている。
  - なお、エリーがブラックホールに突入した時点ですでに地球の地表はおろか海すらも崩壊・蒸発が始まっていた（ponco MarkII はブラックホールを安全に抜ける計算と EMP 対策に手一杯であり、地表や太陽系の状況を調べる余裕がなかったため、彼ら自身も気づいていない）。
  - また、地球のマントルの先（3,960 マイル地点）にブラックホールが存在し、木星内部の海へと繋がっていたこともまた「人為的要因」によるものである。
- **環境設定（70℃の灼熱と海・酸素）**:
  - 灼熱の気温は 70℃ 程度。人間が耐えられるほどではないが、海の水がすべて蒸発するほどではないため海は維持されており、地上に出る余地がない。
  - 70℃ であっても地球から酸素そのものが無くなるわけではない。
  - 地表の植物の大半は消滅したが、かつて地上にいたものの進化して海に適応した植物が存在する。深海の暗闇の中で自ら光って酸素を生成する植物群の景色が広がっている。

### 2.5. 極限環境（マントル領域〜境界）の生態系・生物の宝庫

- **深度マイルと環境の変化**:
  - **0〜10 マイル（生活圏・通常の深海）**: 太陽膨張の影響を受ける表層〜海底基地があるエリア。
  - **10〜50 マイル（地熱の入り口・大深度海溝）**: 本来の地球なら地殻（岩盤）がある深さ。地熱で海水温が急上昇し始め（100℃〜300℃超）、初期スカベンジャー潜水艇にとって最初の壁となる。
  - **50〜500 マイル（上部マントル境界・物理適応の限界ライン）**: 超臨界水と超高圧のエリア。
- **生体メビウスシステム獲得を境とした「生物の体格と敵対性（修羅 vs 楽園）」の劇的な変化**:
  - **上層〜上部マントル境界（生体メビウスシステム未獲得＝修羅の領域）**: 分厚い外骨格や筋肉など「物理装甲」だけで水圧と熱に耐える必要があるため、深く潜るほど生物は巨大・重厚化（深海巨大症の極限進化）する。太陽膨張による環境悪化と個体数減少・エネルギー不足から、限られた資源や獲物を巡って激しく食い合う敵対的な「修羅の世界」。
  - **マントル領域以降（生体メビウスシステム獲得済み＝生物の楽園）**: 体内の電磁循環・相転移バリアによって水圧と地熱そのものを無限のエネルギー源に変換できるようになったため、巨大な装甲が不要になり「大きさに縛られない自由なフォルム（極小の群生発光魚から繊細なクラゲ状生物、流体的な生命体まで多様）」へと進化。エネルギーが満ち溢れており、敵対性が薄く穏やかで神秘的な「生物の楽園（宝庫）」となっている。
- **極限環境に適応した生物たちの特徴**:
  - **共通原理：生体メビウスシステム（電磁流体生命圏）**: マントル領域〜境界に生きるすべての生物・植物は体内に「生体超電導ネットワークと電磁循環構造（メビウスシステムの原型）」を内蔵しており、超高圧・超高温のエネルギーを循環させて生存している。
  - **生体電磁フィールドを纏う生物**: 体表のバイオ超電導組織に生体電流を流し、反磁性・電磁バリアを展開して泳ぐ。ponco MarkII の「メビウス水圧循環機関」開発・強化のヒントや超電導生体パーツの供給源。
  - **熱を蓄えて生きる超臨界・相転移生物**: 生体蓄熱器官に地熱を溜め込み、表面は断熱膜（ライデンフロスト効果応用）で覆われる。「真空断熱バリア」「高密度蓄熱コア」の実装につながる。
  - **熱輻射・放射線を吸収して発光・酸素生成する深淵植物群**: 赤外線や微弱放射線をエネルギー源として青白く・黄金色に輝き酸素を生み出す。
- **直下ブラックホールによる空間歪曲と「澄み切った超深層海」の成立**:
  - 地球中心（3,960 マイル）にある人為的ブラックホールが空間を引き伸ばし、重力相殺と熱吸収を行うことで、適度な密度とクリアな視界を持つ超深層海が維持されている。
- **水圧と温度のベルカーブ構造**:
  - 上層〜上部マントル（〜500 マイル）までは急上昇するが、深部マントル（500〜3,920 マイル）では水圧は頭打ち（プラトー化）し、温度はピークを越えて穏やかに冷却。3,920〜3,960 マイルの宇宙境界直前では重力の逆転と宇宙の極低温により水圧の急減と急激な冷却が起きる。
- **境界を回遊する真空適応型生物（3,920〜3,960 マイル付近）**: 体内の水分を熱で蒸気噴射したり磁気器官をブラックホール磁場と干渉させたりして真空の宇宙空間も遊泳する。

## 4. ストーリー・プロットの流れ

### 1. 日常と出発のきっかけ
- スカベンジャーとして日々資源探しをしていたエリーは、数年前に消えた父の愛機「スティングレー号」および「ponco Mark I」からの信号を受信する。その信号は「地球の崩壊の警告」と「避難経路の誘導」を兼ねていた。エリーは ponco MarkII・Gem と共に深海へ出発する。

### 2. 深層への降下と強化
- 降下の各段階で、スティングレー号と Mark I が残した物理的な痕跡（軽量化・機構換装のためパージされた外装パーツ、深部マントルでの仮設ドック溶接跡・残留エネルギー等）を発見し、父たちが自らの意志で深淵へ進んだことを確信しながら追跡する（ブラックホール手前には意図的なビーコンや助けは置かれていない）。
- **理論値と観測事実のギャップ**: ponco MarkII は超臨界流体で視界ゼロ・無限に上がる水圧と熱を想定して潜るが、実際には「岩盤がない」「視界がクリアすぎる」「水圧や熱の増加が途中で止まっている」ことに直面し段階的に戸惑い・戦慄する。エリーの「要するにどういうこと？」に対し、「本当なら熱い霧で何も見えないはずなのに、プールみたいに水が澄んでいる」といった直感的な例えで掛け合いを展開する。
- 上部マントル境界で生体メビウスシステムを持つ先遣生物と遭遇し、回収した生体素材をもとに ponco MarkII の設計＋Gem の溶接重工作で初期型「メビウス水圧循環機関」を実装して最初の壁を突破。さらにマントル領域「生物の楽園」で「真空断熱バリア」「高密度蓄熱コア」を拡張しながら深度 3,920 マイルへ到達する。

### 2.5. 潜水艇の技術設定：メビウス水圧循環機関
- 生体メビウスシステムをバイオミメティクスで工学実装。外部の水圧を正面から受け止めず、メビウスの輪のようにねじれて循環する水圧流を作り動力源として循環させながら外圧を押し返すフィールドを維持。
- 超臨界水・超高熱に対しては「真空断熱バリア」と「高密度蓄熱コア（相転移ヒートシンク）」で保護。蓄積された熱は後の宇宙空間での貴重なエネルギー源となる。

### 2.6. 潜水艇の船体構造・内部設定（全長約 20m・2 層構造）
- **基本サイズ**: 全長約 20m（艦首コックピット約 4m／中央部約 10m／艦尾機関室約 6m）、全幅・全高約 6.5m の 2 階建て構造。「移動する家（秘密基地）」としての居住性と狭い海溝での機動力を両立。父の「スティングレー号」も同規格。
- **4 つの主要区画**:
  1. **コックピット・観測デッキ（艦首・上下吹き抜け）**: 曲面強化ガラス大型キャノピー、ponco MarkII のホログラム解析コンソール、BH 突入時用の物理固定ダンパー・アナログ計器バイパス。
  2. **リビング・キッチン＆船内菜園ユニット（中央上層・天井高約 2.3m）**: 深淵発光植物を育てる水耕・電磁栽培ユニット（天然照明・酸素生成・CO2 浄化・食材収穫・コレクション要素）、Gem のキッチンと食卓、エリーの寝台・私物スペース。
  3. **ワークショップ・格納庫（中央下層・天井高約 2.6m）**: 重装甲の Gem が作業できる工作エリア。溶接機材、アームクレーン、生物組織・鉱石解析タンク、ponco のナノマシン制御ステーション。
  4. **機関室：メビウス・コア＆蓄熱ルーム（艦尾）**: メビウス水圧循環機関（超電導コイル群）、高密度蓄熱コア、および外部海水や木星内部流体から水・酸素・栄養素を抽出・無毒化する「外部流体精製プラント」。

### 2.7. 潜水艇の 3 モード変更システム・外観進化とビジュアル方針
- **3 モード変更システム（愛機 1 隻の物理変形）**:
  - 変形時間: 約 2.5〜3 秒の物理変形プロセス（ロック解除 → パーツスライド＆ノズル展開 → 最終ロック＆新フィールド展開）。変形中も移動・基本攻撃・回避が可能。
  - **機動モード（スピード／巡航・青白いスリット発光）**: 外装フィン後方折り畳み・流線形化。高速潜航・大対流層駆け抜け・離脱特化。
  - **パワーモード（武装／掘削突破・赤橙色のスリット発光）**: 艦首・側面装甲展開、破砕エミッター＆高出力スラスター露出。戦闘・障害物/逆流突破特化。
  - **バリアモード（防御／断熱・電磁遮蔽・黄金色・エメラルド色のスリット発光）**: 超電導コイル全周展開、多層電磁シールド＆真空断熱層最大化。熱水・マントル境界・電磁ストーム遮蔽特化。
- **2 軸外観進化（ストーリー進行度 × 機体強化度）**:
  - **進行度軸（全 4 段階）**: ①初期スカベンジャー艇（無骨なイエロー〜アイボリー工業ボディ・溶接跡） → ②メビウス機関実装型（白銀・パール調バイオ装甲＋可変ウイング） → ③深部マントル・超臨界適応型（放熱フィン＋多重リング・流線形化） → ④木星内部海・最終進化型（白銀×濃紺の洗練された流線形フォルムで父の『スティングレー号』と並び立つ完成形）。
  - **強化度軸（3 モード連動パーツ進化）**: 機動（可変ウイング＆推進ノズル）、パワー（艦首アーマー＆武装エミッター）、バリア（船体リングコイル＆放熱フィン）。
- **「絶景」を主役にする控えめなライティング・エフェクト方針**: ネオンのようにビカビカ光らせず、装甲の継ぎ目やコイル縁の極細スリット・淡い明滅にとどめ、シールドも被弾・接近時のみ淡く波紋が広がる半透明・屈折表現とする。

### 3. 3,920 マイル地点での異変 〜 3,960 マイル宇宙・ブラックホール突入
- 3,920 マイルで ponco MarkII の理論が完全脱落（「ありえない、もう地球の中心点を過ぎて重力が逆転するはず、しかもどんなに潜っても水圧も強くならないし下方は明るくなっているように見える」）。
- 3,960 マイルの境界を突破すると真っ暗な宇宙空間と、遥か先に**美しく描かれたブラックホール**が出現。
- 水圧喪失でメビウス機関が無力化するが、離脱不能と判断した ponco MarkII が突入安定化へ全リソースを切り替え：
  - **蓄熱コア熱電発電＋バラスト水蒸気スラスター**で姿勢制御
  - **順行（プログレード）測地線突入**で特異点を避け向こう側へ抜ける軌道へ
  - **磁気ペンローズ過程／超放射**で BH 回転エネルギーを奪取し磁気シールド再起動（青方偏移放射線遮蔽）
  - **EMP 事前予測と生存プロトコル**: アナログ生命維持バイパス＋犠牲ヒューズ構築、磁気シールド防護を「①エリー → ②Gem → ③自分（後回し）」で配分し、Gem へ手動バルブ処置と胸部カプセル解放を託す。復帰用ナノマシンには「①メビウスコイル再接続 → ②Gem 修復 → ③ponco 本体最低限再接続」のハードコード手順を刻む。

### 4. 4,000 マイルの先〜海底 4 万マイル（木星内部海）
- EMP ブラックアウト後、Gem がエリーを守り抜き ponco の胸部カプセルを解放して応急復旧。
- 4,000 マイルの先で目を覚ますと、赤道半径約 43,441 マイルの木星内部海（液体水素・液体金属水素の超深層海）が広がっている。機関室の外部流体精製プラントと木星適応プランクトン・クラゲによりサバイバルが成立。
- 地球側約 3,960 マイル＋木星側約 36,000 マイル＝総計 4 万マイルの海底航路を経て木星最深部へ到達（その先の結末は熟考中）。

## 5. ゲームデザイン・Three.js 3D 技術設計方針

- **開発基盤**: ブラウザ上で動作する **Three.js（WebGL / WebGPU）** による 3D オープンワールド構成。
- **潜航スピード向上とスケール拡大**: 機関強化に伴い巡航・潜航スピードが飛躍的に向上し、後半（木星内部海など）ほど巨大縦穴・大対流層のスケールを拡大。
- **オープンワールド生態系 AI・生物の 4 分類**:
  1. **無害・環境生物**: 群生・回遊型で絶景の彩り・採集対象。
  2. **縄張り防衛型**: 境界外では無害だが、侵入すると発光パターン変化等で威嚇し離れない場合のみ迎撃。
  3. **巡回・索敵捕食者**: 視覚・音・電磁波で索敵。出力調整や遮蔽物によるステルス回避が可能。
  4. **巨大回遊・環境そのもの型**: 全長数百m〜km 級の超巨大生物。大対流を泳ぎ水流を起こす動く絶景。
  - **風景に溶け込むサイン**: UI の赤い枠線などは使わず、発光植物の光の届く範囲・生物の模様の脈動・水流や気泡の変化など自然な視覚サインで危険域や状態を伝える。
- **Three.js 特化の超軽量アーキテクチャ（60fps 維持・負荷極限削減）**:
  - **ドローコール削減＆GPU オフロード**: 群生魚・深淵植物・粒子は `THREE.InstancedMesh`、異なる形状の静的パーツは `THREE.BatchedMesh` へ統合（目標ドローコール 100〜500 以下）。揺れ・泳ぎはカスタムシェーダー（`onBeforeCompile` 等）による GPU 頂点アニメーション。過剰な `PointLight` を避け、環境光＋`emissive`＋控えめなブルーム＋深度別 `FogExp2` で絶景と遠方カリングを両立。
  - **Web Worker 分離＆GC 回避＆フローティング・オリジン**: 生態系 AI の索敵・空間ハッシュは Web Worker へ分離、オブジェクトプールと使い回しベクトルで GC スパイク回避、40,000 マイルの座標精度誤差は自機を原点付近に留めるフローティング・オリジン方式で解消。
  - **アセット圧縮＆スパイク防止＆厳格破棄**: KTX2（Basis Universal）テクスチャ・Draco/Meshopt 圧縮 GLB、`renderer.compileAsync()` 事前非同期コンパイル、チャンク破棄時の `dispose()` 徹底、代表シーンでの定点計測。
