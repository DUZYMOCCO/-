## 2. ストーリーラインに沿ったワールド＆マップ設計の基準

必読資料（すべて `abyss-depth-lab/docs/` に統合済み）:
- 物語・世界観の正本: `docs/STORY.md`（原文: `docs/story-reference/4.md`）
- フィールド・マップ構想: `docs/DEEP_FIELD_PLAN.md`
- 描画基盤設計・計測: `docs/PHASE0_ARCHITECTURE.md`, `docs/PHASE1_REPORT.md`

### 世界の縦構造（『海底4万マイル』・下に広がるピラミッド構造）
主方向は右ではなく **下**。潜るほど左右に探索範囲と分岐・降下口が広がる（クリア強制・リセットなしのシームレス探索）。

1. **序盤（実装済みベース）**:
   - **沈没都市の外縁**（`y = 0..2600`, 遺跡エアロック・徒歩探索・前哨基地 `OUTPOST`）
   - **海溝と第2前哨基地「深棚」**（`y = 2600..4100`, `trench-rules.js`, `FLOOR_Y=2600`, `WORLD_BOTTOM=4100`）
2. **次の構築ターゲット（第1拡張フェーズ：深棚の下の分岐とバイオーム表現）**:
   - 深棚のさらに下へ、**「狭い洞窟の直下降ルート」** と **「熱水・火山帯の横回りルート」** の 2 ルートを分岐させ、下層の **明るい合流広間（クラゲ帯／海草林）** で繋ぐ（深棚への自力帰還ルートを必ず確保）。
   - **水の色・見通し・局所光のバイオーム分離**（深度と明るさを直結させない）：
     - 沈没都市外縁：深い青緑と古代石造アーチ
     - 狭い洞窟：暗く閉じた岩窟と局所光（照明弾・艇ライトが映える）
     - 熱水・火山帯：黒い玄武岩と噴出口、局所的な琥珀・赤錆の光と揺らぎ
     - 海草林／クラゲ広間：澄んだ青緑や淡い青紫の間接光、奥行きの抜け
   - 境界横断時は環境光・水色・霧を滑らかに補間遷移させ、フレーム時間スパイクを起こさない。
   - **実地形（`solids`）と透過マップ（`map-rules.js` / `dive-map.js`）と Depth Stacking 背景の整合**：地図には実在地形と発見済み拠点のみを描画し、未到達層・ネタバレは伏せる。
3. **中長期のストーリー到達域（段階構築）**:
   - **マントル領域（超臨界水・極限生態系の楽園）**: 熱輻射・放射線を吸収して青白〜黄金色に光り酸素を生む深淵植物群（蓄熱コア／真空断熱バリアの舞台）
   - **深度 3,920〜3,960 マイル境界**: 水圧上昇停止・下方発光・宇宙空間と美しいブラックホール（重力レンズ歪みシェーダー検証対象）
   - **4,000 マイル〜木星内部海**: 地球側 3,960 マイル＋木星側 36,000 マイルの壮大な異質海（反射・散乱・屈折の変化）
   - **ネタバレ防止規則**: 序盤のUI・地図・導入ではブラックホール・木星・4万マイル・3,920/3,960マイルの種明かしを出さず、父の生存も断定しない。

## 4. 壊れやすい箇所・実装上の注意

- `game.js` の 2D コンテキストは `alpha: true`。`depthActive` 時は透過クリアし、導入・基地・徒歩探索（`suspendDepth`）時のみ WebGL2 を休止して従来描画に戻す。
- ワイド画面（iPhone 横持ち `874×402` 等）の 16:9 境界段差を防ぐため、`drawLighting` の左右端ソフトフェードと Canvas2D 側二重 `vignette` の抑止を維持すること。
- `depth-bridge.js` は現在「無限横スクロール＋多段棚」の汎用生成。**ストーリー沿いの固定ランドマーク・バイオーム区画（洞窟・熱水帯・合流広間・マントル等）へ進化させる際、座標系を `trench-rules.js` / `map-rules.js` と共通の純粋ワールド定義モジュール（例: `js/world-biomes.js`）に分離**すると、描画・衝突・マップ・Hermes 側の敵配置が完全に噛み合う。
- アセットを増減したら必ず `sw-assets.js` の `files` / `version` / `gameVersion` と、更新 JS/CSS の `?v=` を同時に上げる。

## 5. 次のセッションの優先タスク

1. **ストーリー準拠ワールド定義＆バイオーム設計（純粋モジュール化）**:
   - `trench-rules.js` の先（深棚の下）の **ワールド座標・バイオーム領域（沈没都市外縁／海溝・深棚／狭洞窟ルート／熱水・火山帯／合流広間）** を純粋データ・関数として定義し、`depth-bridge.js`（WebGL2 環境・水色・ライティング遷移）・`game.js`（実地形衝突）・`map-rules.js` / `dive-map.js`（透過マップ）の 3 つが同一座標系を参照する基盤を作る。
2. **バイオーム別・多層環境アート素材の拡充**:
   - 熱水・火山帯（黒玄武岩噴出口・琥珀発光鉱脈・熱水ゆらぎ）、狭洞窟（鍾乳石/岩窟アーチ）、合流広間（巨大海藻・青紫クラゲ帯）の透過＋ノーマル＋発光マップ素材を作成し、`depth-bridge.js` のバイオームブレンドに組み込む。
3. **Depth Stacking 描画最適化＆演出深化（Phase 2）**:
   - バイオーム境界の環境光・水色・霧の滑らかな連続遷移、巨大生物通過時の遮蔽ゴッドレイ強調、魚群・同素材のインスタンシング描画（Draw Calls 圧縮）。
