## 2026-11-25 / v3.2.0 — 旧来 Canvas2D 地形・ギザギザ背景描写の完全撤去＆実地形の WebGL2 高精細アート一本化

- **やったこと**:
  - **旧来 Canvas2D 地形描写の完全撤去（`js/trench.js`, `js/game.js`）**: ボス撃破後（海溝開放後）に WebGL2 背景の上へ被さっていた旧 v1.15.0 のギザギザ多角形視差背景（`drawBackLayers` / `renderForeground` / `drawBedrock` / `renderDrift`）・単色矩形岩盤（`drawRockRect`）・旧ベクター丸岩（`drawRock`）・単色ベタ塗り海底を、`depthActive` 時（通常プレイ）から完全撤去。`trench.js` は入口ビーコン・下向き誘導灯・熱水グロー・暗幕穴抜き・ラベルのみに整理。
  - **実地形の WebGL2 Depth Stacking 一本化（`js/depth-bridge.js`）**: 操作層と同一視差（`z = 0.0`）の専用レイヤー `terrain_0` を追加し、`trench.solids`（壁・岩棚・仕切り岩盤）・`trench.vents`（熱水チムニー）・`G.rocks`（岩障害物）・海底ラインをすべてバイオーム別高精細アート（`cliff_overhang`, `cliff_spire`, `volcanic_vent`, `cave_stalactite`, `flora_polyps_boulder`）＋ノーマルマップ立体照光＋遮蔽シャドウ対応で描画。
  - **キャッシュ・版上げ**: `sw-assets.js` を `v5` / `3.2.0`、`package.json` を `3.2.0`、`index.js` / `game.js` の `?v=` を更新。
- **なぜ**: 旧 Canvas2D 時代のベクター多角形・単色矩形が現行 WebGL2 多層レンダリングの見た目を損ない、ボス撃破後の海溝で浮いて見えていたため、描画アーキテクチャを WebGL2 へ完全統一するため。
- **検証結果**:
  - `node --test abyss-depth-lab/tests/*.test.mjs` 全 34 件通過。
  - Playwright 横持ち `874×402`（DPR 2, WebGL2 有効）で狭洞窟・熱水火山帯・合流広間を再キャプチャ目視確認。旧ギザギザ多角形・単色矩形が完全に消滅し、ヘッドライトによる実地形岩肌のノーマルマップ照光と背景の自然な融合、エラー 0 を確認。
- **残したこと**: 実地形タイリングの Draw Call 圧縮（インスタンシング化）、Hermes 側バイオーム別敵キャラ配置。

## 2026-11-25 / v3.1.0 — ストーリー準拠ワールド構造（深棚下2分岐＋合流広間）＆バイオーム多層環境アート構築

- **やったこと**:
  - **純粋ワールド＆バイオーム定義 (`js/world-biomes.js`) 新設**: 沈没都市外縁・海溝/深棚・狭洞窟・熱水/火山帯・合流広間（海草林/クラゲ帯）の 5 バイオームを定義。深度と明るさを直結させず、SDF ベースの `smoothstep` 補間（`sampleBiomeAt`）で水色・環境光・散乱色・濁り・暗幕倍率をゼロスパイクで連続遷移させる基盤を構築。
  - **深棚下 2 分岐＋合流広間の実地形 (`js/trench-rules.js`, `js/trench.js`)**: 深棚（`y=4100`）の下に、左「狭洞窟・直下降ルート（`y=4100..5650`）」と右「熱水・火山帯 横回りルート（`y=3540..5650`）」を分岐させ、下層の「合流広間（`y=5650..6900`, `WORLD_BOTTOM=6900`）」で繋ぐピラミッド構造を実装。両ルートとも十分な通過幅で深棚への自力帰還を保証。
  - **バイオーム別・多層環境アート素材生成＆WebGL2統合**: `volcanic_vent`（黒玄武岩チムニー＋琥珀亀裂・N/Eマップ）、`cave_stalactite`（鍾乳石アーチ・Nマップ）、`hall_giant_kelp`（巨大発光海草・N/Eマップ）を生成・デマット切り出しし、`manifest.json`・`shaders.js`・`renderer-webgl2.js`・`depth-bridge.js` に統合。また `depthActive` 時は海溝開口と不透明背景抜きをスキップして WebGL2 15層背景と衝突岩盤を完全融合させた。
  - **透過マップ＆共通アートスタイルガイド**: `map-rules.js` / `dive-map.js` に深棚下の実地形・海域トーン・発見地点 3 種（`cave-route`, `volcanic-vent`, `confluence-hall`）を追加し、凡例とズームボタンの重なりも解消。さらに環境×敵のアートスタイル擦り合わせ基準 [`docs/ART_STYLE_GUIDE.md`](ART_STYLE_GUIDE.md) を策定。
  - **キャッシュ・版更新**: `sw-assets.js` を `v4` / `3.1.0`（106 ファイル登録）、`package.json` を `3.1.0` へ更新。
- **なぜ**: ストーリーライン（『海底4万マイル』・下に広がるピラミッド構造）に沿った最初の深層分岐とバイオーム別の水色・明るさ表現を実装し、今後の Hermes（敵制作）・Gemini（物語）と共通座標系・共通アート基準で安全に並行開発できるようにするため。
- **検証結果**:
  - `node --test abyss-depth-lab/tests/*.test.mjs` 全 34 件通過（新規 `tests/world-biomes.test.mjs` 4 件含む：ピラミッド構造・自力帰還クリアランス・バイオーム連続補間・ネタバレ語句非含有・素材実在）。
  - `sw-assets.js` 全 106 ファイル実在確認 OK。
  - Playwright 横持ち `874×402`（DPR 2, WebGL2 有効）で狭洞窟・熱水火山帯・合流広間・透過マップ全体をキャプチャ目視確認。コンソール/ページ/HTTP エラー 0、15 層描画 OD `1.8x〜2.1x`。
- **残したこと**: 魚群・同素材のインスタンシング描画最適化、Hermes 側のバイオーム別敵キャラ配置、次層「マントル領域」の構築。
