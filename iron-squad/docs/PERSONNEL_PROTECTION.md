# 兵士の保護ロック（v6.11.4 / cache v254）

2026-10-14実装。兵士名簿の展開欄、個人記録の固定ヘッダーの「🔓 保護する」で設定。「🔒 保護中」を押すと解除。

- 直属/本隊/予備兵の放逐を防ぐ。名簿の放逐ボタンは無効化し、名前に鍵を表示。`dismissSoldier()`でも確認ダイアログ・金銭/装備精算より前に保護を判定。
- 保護兵は新しい遠征の全難度（哨戒/危険/死線/魔境）で派遣対象外。既定選択・残っていた選択から除外し、選択欄を無効化して「保護中」を表示。
- 選択数と派遣可否は未保護の兵士で判断する。古いID一覧や直接の派遣呼出しでも保護兵を登録しない。明示的な0名選択は全員扱いへ戻さず、派遣を拒否。
- 遠征途中での保護は次回派遣から適用。進行中の参加者判定/自動帰還/報酬から兵士を取り除かない。通常戦闘・編成・装備には影響しない。
- 任意の真偽値 `personnelLocked` を兵士に保存。未設定は未保護、trueだけが保護。既存の`persistentUnit()`と読込経路を利用し、保存形式の版や既存セーブを変更しない。
- 通常保存/地点保存、予備兵の繰上げ、兵種・能力の再計算で維持。地点へ戻ると保護状態も保存時点に戻る。独立勇者/死亡者への切替操作は受け付けない。
- 設定の保存失敗時は元の保護状態へ戻して通知。解除の失敗で保護が消えることもない。
