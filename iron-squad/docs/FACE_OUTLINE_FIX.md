# キャラ作成の輪郭と顎（v5.5.3 / ゲームキャッシュ v193）

2026-10-11。「顔の形が残る／四角い顔しか出ない時がある」という報告を調査。

## 原因と修正

`appearance-features.js` の普通以外の顎は、輪郭によらず同じ頬の制御点と平たい顎先を使用していた。丸顔・面長・細い輪郭を選んでも、顎を変えると幅だけが違う四角い顔へ近づく。尖った顎も先端の曲線が平たく、尖りが見えにくかった。

頬の曲率・頬骨位置を輪郭別にし、顎の変更は下顔面へ接続する。面長の長さ、丸顔の丸み、細い輪郭の頬を各顎でも保持。尖った顎は先細り、四角い顎だけは平たい顎先にする。普通以外の顎を選ばない旧来の顔は維持する。

「りんかく」と「あご」の選択は独立したまま。輪郭を選び直して顎を勝手にリセットする処理は追加していない。名前・髪・目・鼻・飾り・保存された選択を再抽選しない。能力・資金・乱数・保存形式の変更なし。既存の人物にも保存済みの組み合わせで描画修正を適用。

## 検証

- 新規 `face-outline-combinations.test.mjs` は男女・近景/遠景・全5種の特殊顎で、丸顔/角顔/細い輪郭の頬の違い、面長の長さ、尖った顎の先細り、正規化後の選択保持を実画素で確認。修正前ソースをプロセス内で差し替えると、最初の丸顔の頬の検査で失敗することも確認。
- 尖った顎の「頬下部の幅÷顔中央の幅」は、修正前の丸顔0.937/角顔0.941から、修正後0.824/0.978へ。以前は同じ側面形状に近かった。
- Chrome 375×780/DPR2。男女とも四角い顎のまま明示的な輪郭5種類を選び、顔・全身の画像がそれぞれ5種類になる。輪郭と顎を連続切替して元へ戻すと、両プレビューの画素が完全一致する。実際の隊長へ適用して `saveGame()` 後、「身だしなみ」で再表示した画像も一致。能力・資金不変、横はみ出しなし、ページ例外0。
- 「ふつう」は以前の顔の輪郭を使うため、特殊顎との組み合わせでは明示的な面長（男）や丸顔（女）と同じになる場合がある。これは保存された顔を保つ既定値の扱い。
- 全体テストは98件中97件通過。失敗は `hq-invasion-balance.test.mjs` の「初期装備の同時死傷率70%以上」。顔の修正前ソースを使用しても同じ箇所で失敗し、固定seed5本の戦闘結果も同一。今回の顔描画では修正していない。
- 構文18ファイル、変更した顔の配信ファイルとキャッシュ定義4本のHTTPバイト一致、`git diff --check` が通過。テストが書き換えた過去のプレビュー2枚は実行前のバイトへ復元。
