# 新しい敵の見た目を作る（Gemini向け指示書・見た目だけ）

## ねらい
- 敵の種類が少なすぎる。バイオーム（方角）・昼夜・魔王城の近くで、顔ぶれが変わるようにしたい。
- **この作業は「絵を描く関数」と「見本画像」だけ。** 出現・強さ・行動・ゲームへの組み込みは別の作業でやる。

## 触ってよいもの・だめなもの
- 作ってよい: `iron-squad/js/enemy-art.js`（新規）、`iron-squad/tools/preview-enemy-roster.mjs`（新規）、`iron-squad/tests/enemy-art.test.mjs`（新規）、見本画像 `iron-squad/docs/validation/enemy-art-roster/`。
- **触ってはだめ**: ほかのすべてのファイル（`index.js`、`visuals.js`、`world.js`、`sw-assets.js`、既存のテストなど）。読むのは自由。
- `git add -A` / `git add .` 禁止。コミット・プッシュしない。

## 既存の描き方に合わせる（必読）
- `iron-squad/js/visuals.js` の `drawFieldMob`（706行付近）と、そこから呼ばれる各敵の描画（`drawBrute`、`drawDemon`、オーク、ワイバーン、骸骨兵、影狼など）を読み、**同じ画風**（太めの輪郭、少ない色数、くすんだ色、トゥーン調）にそろえる。
- 描画関数は `draw(c, m, now)` の形。原点は敵の足元の中心。`m.radius` に合わせて大きさを決める。
- 必ず対応すること:
  - 被弾の白い点滅（`m.hitPulse > 0`）。
  - 向き（`m.facingAngle` などで左右反転。既存と同じ方法）。
  - 歩くときの上下の揺れ（`now` を使う。既存と同じくらいの大きさ）。
  - 1体あたりの描画は軽く（パスの数を既存の敵と同じくらいに。画像ファイルは使わない）。
- 出力: `export const ENEMY_ART = { 種類id: draw関数, ... }` と、`export function drawEnemyArt(c, m, now)`（`ENEMY_ART[m.type]` があれば描いて `true`、なければ `false`）。

## 見本画像（必須）
- `tools/preview-enemy-roster.mjs` を作り、22種を一覧で描いた画像を出す（Playwright。既存の `tools/preview-*.mjs` の書き方を流用）。
  - 1種ごとに: 通常、被弾の点滅中、左向き。3つ並べて、下に名前。
  - 昼の明るさと、夜の暗さ（既存の夜の重ね方があればそれ）の2枚。
  - 390px幅の画面で実際の大きさに近い縮尺の画像も1枚（ゲーム内で見分けがつくか確かめるため）。
- 画像は `docs/validation/enemy-art-roster/` に置く。

## 結果
- **作成したファイル**:
  - `iron-squad/js/enemy-art.js`:
    - `ENEMY_ROSTER`: 22種すべての識別子（`id`）、日本語名（`name`）、出現地域（`region`）、基準半径（`radius`）、見た目特徴（`desc`）を定義した名簿テーブル。
    - 個別描画関数（全22種）: 足元原点 `(0, 0)`、輪郭線付きトゥーン調、`m.hitPulse > 0` での白・明色点滅、`Math.cos(m.facingAngle) < 0` による `scale(-1, 1)` 左右反転、`now` による歩行・浮遊・羽ばたき・炎の揺らめきアニメーションを完全実装。
    - `ENEMY_ART`: `id` と描画関数のマッピングテーブル。
    - `drawEnemyArt(c, m, now)`: `ENEMY_ART[m.type]` があれば描画して `true`、なければ `false` を返すエントリーポイント。
  - `iron-squad/tools/preview-enemy-roster.mjs`:
    - Playwright を用い、ブラウザ Canvas 上で 22 種を描画して高解像度 PNG を出力するツール。
  - `iron-squad/tests/enemy-art.test.mjs`:
    - 全22種のメタデータ完全性、辞書登録、未知の種別ガード、モック Canvas での全種「通常」「被弾」「左向き」「左向き＋被弾」の描画テスト（`c.save()` / `c.restore()` の完全バランス・モブオブジェクトの非破壊性の検証を含む）。
- **見本画像の場所**:
  - `iron-squad/docs/validation/enemy-art-roster/roster-day.png`: 昼間環境での全体名簿（各敵カードに通常・被弾点滅・左向きの3態と識別情報を掲載）。
  - `iron-squad/docs/validation/enemy-art-roster/roster-night.png`: 夜間環境での全体名簿（暗闇に浮かび上がる光る目・青白い鬼火・魔導の紫光・猟犬の炎・被弾白光の視認性を確認）。
  - `iron-squad/docs/validation/enemy-art-roster/roster-scale-390.png`: スマートフォン実機解像度（390px幅）における `scale = 1.0`（等倍実寸）でのバイオーム別レイアウト・見分けやすさ検証見本。
- **22種の描画の工夫と留意点（難しかった種類など）**:
  - **既存敵との差別化**:
    - `bandit_rider`（盗賊騎兵）: 歩兵と混同しないよう小柄な馬に乗せ、馬の4足歩行ボブと騎乗者の槍の構えを表現。
    - `plains_bull`（荒野の大牛）: 野猪（ボア）と見分けがつくよう、首回りの毛皮と前方へ湾曲した太い角、前傾の突進姿勢で重量感を付与。
    - `bog_slime`（沼スライム）: 街道・平原の通常スライム（明るい緑）と異なり、濁った深緑・毒の泡粒・暗い泡の気泡テクスチャで湿地帯らしさを強調。
    - `snow_wolf`（雪狼）: 通常の黒狼（`wolf`）と異なり、冷涼な白青銀の毛並みと先端の吐く白い息エフェクトを配置。
    - `sand_worm`（砂塵ワーム）: 円錐状の環節構造と地面の砂煙、口元の牙で「地面から半身を出した虫」の不気味さを表現。
    - `rock_troll`（岩トロル）: 通常のオーク（緑肌）と区別するため、角張った岩肌と苔のくすみ色、片手にぶら下げた巨大な岩塊棍棒で巨大感を演出。
    - `harpy`（ハーピー）: 腕が翼になった形状と細い鳥足、上下の羽ばたき浮遊で既存のワイバーン（ドラゴン型）とは異なる人型有翼モンスターとして差別化。
  - **魔王城近郊の統一感**:
    - `imp`, `demon_lancer`, `demon_mage`, `hellhound` の4種は、既存の魔王軍（`drawDemon`）と同じく黒・深紫・暗赤・真紅の瞳でカラーパレットを統一。地獄の猟犬は背と尾にアニメーションする炎の毛並みを付与。
  - **軽量性とパフォーマンス**:
    - すべて標準の Canvas 2D パスプリミティブ（`shape`, `line`, `ellipse`, `arc`）のみで構成し、画像の読み込みや重い合成処理を行わず、数十体が密集しても高フレームレートを維持できる設計。
