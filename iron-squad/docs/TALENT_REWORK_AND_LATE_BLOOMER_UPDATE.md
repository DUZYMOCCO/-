## 実装結果

| 項目 | 新しい仕様 |
|---|---|
| 天才の抽選 | `roll < 0.00033`（0.033%、約3,000人に1人） |
| 天才の基礎補正 | HP×2.00、ATK×2.20、速度+40、会心+40% |
| 天才の能力成長係数 | 全レベル2.40 |
| 大器晩成の条件 | INFERIORかつ死線生還回数>0、または死線技能を1つ以上所持 |
| 大器晩成の成長 | Lv1〜30:0.85、Lv31:0.92、Lv35:1.20、Lv40以上:1.55 |
| 生還グリット1回 | 最大HP+5%、ATK+4%、DEF+3% |
| 生還グリット8回 | 最大HP+40%、ATK+32%、DEF+24%（上限8回） |

`unit-attributes.js` の `talentGrowth()` をレベル成長・鍛錬成長・筋力計算・筋肉術士の判定に共通利用。大器晩成は、その時点のレベルと死線経験から係数を算出し、Lv40以降も1.55で固定する。死線を越えていないへっぽこは高レベルでも0.85。グリットだけでは大器晩成にならない。

`talent-labels.js` は従来の才能キー指定も受け付け、兵士を渡す場合は生還歴に応じて「🍂大器晩成」を返す。名簿・検索・個人記録・ランキング・兵士選択・雇用表示に反映。内部の才能キーはINFERIORのままなので、へっぽこ向け遠征報酬・価格・既存の昇格費用規則は維持。かな表示はゲーム側辞書に「たいきばんせい」を追加し、漢字/かな切替に対応。

グリットは毎回、保存された取得数から割合を再構築する。最大HP/DEFは素の再計算値から、ATKは属性補正後の値から割合を適用し、整数へ切り捨てる。固定HP+10/ATK+2/DEF+1と、再計算のたびに行われていたHP+2を撤廃。負傷兵を再計算し続けてもHPは増えず、ダウン中はHP0を維持する。

## セーブと既存仕様

- 保存済みの素質、先天能力、鍛錬回数、死線回数/技能、グリット取得数を保持。再計算で新しい係数を適用するため、才能変更やランダムな再抽選、取得数の再付与は行わない。
- 既存の天才にも新しい基礎倍率・成長係数を適用。普通のへっぽこ、有望・英才、凡庸の狭い素質幅/実戦成長、雇用費、天才で止まる自動募集は従来どおり。
- v6.8.4の死線技能の兵種適合・既存セーブ補正・商人3分類、v6.8.3のMP文字/術士用品、v6.8.1の救助/技能CT、v6.7.1の倍率/境界/魔王/弾薬キャッシュを保持。隊長/勇者の行動AIや敵の数値は変更なし（才能自体の補正は共有の規則で適用）。
