# 商人で自部隊の兵士に装備を購入（v6.8.2 / cache v244）

2026-10-13。「商人から装備を買うときに自分の部隊の誰かに買って装備させるメニュー」を実装。

## 使い方

1. 商人を開く。
2. 「誰に装備を買いますか？」で隊長、または自部隊の兵士を選ぶ。
3. 選んだ人の現装備との比較・必要筋力を確認し、「購入してこの兵士に装備」を押す。

購入先には直属兵と定員あふれの同行兵を表示。本隊・予備兵・死亡した兵士は含めない。ダウン中の兵士への装備購入は可能（復活はしない）。最初は隊長を選択し、購入やタブ変更、店内のセーブ/ロードをしても選択を維持する。

代金は隊長の所持金から支払う。兵士の財布・国庫・兵士の自費購入集計には触れない。購入した装備は選んだ兵士が即装備し、通常購入で外した装備は隊長のバッグへ返す。通常購入では強化値を自動で引き継がず、自費強化もしない。

既存の「強化引継で購入」も、選んだ人の同部位・同武器種を基準に表示する。このボタンだけは表示どおり旧装備を消費し、強化値を引き継ぐ。隊長への購入と、隊長が装備できない品をバッグへ買う既存動作も維持。

## 購入の保証

- 7部位すべてに対応。武器の参照と弾薬容量キャッシュも更新。
- 装備できない兵士への購入ボタンは無効。購入直前にも筋力・対象の所属/生存・商人・残金を再確認する。
- 対象が不在になっても隊長へ勝手に購入先を変更しない。古いボタンの再クリックでも次の商品や別の購入先へ誤購入しない。
- 一点もの・売り切れ・価格・品揃えの更新・明示的な強化引継・保存は既存の仕組みを使う。
- 買った後も店内に残り、購入先・分類・スクロール・サービス欄を保持する。
