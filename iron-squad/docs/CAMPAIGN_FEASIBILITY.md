測定版 **v6.6.1 / v239**。ユーザー「本陣侵攻のバランスと魔王城への道のり。最奥は100万倍くらいで、今の強化でも倒せるか」を受けた現状調査。ゲームの敵倍率・味方性能は変更していない。

## 2. 本陣侵攻：育成で越えられるが、序列に逆転

48人の同じ本隊を基準に、装備段階ごとに通常軍と最初の本格軍を各4seedで自動迎撃。隊長は本陣から離れて戦闘に参加しない。実際の軍の生成、3方向/南東からの進軍、技能、回復、かばう、搬送、復活、ダメージ、育成を使用。隊長が初期能力の比較表。

|部隊段階|通常軍の撃退|本格軍の撃退|通常軍の最大同時ダウン・平均|本格軍の最大同時ダウン・平均|
|---|---:|---:|---:|---:|
|新兵・T1初期装備|0/4|0/4|48/48|48/48|
|Lv8・T5＋3|3/4|4/4|32/48|約18/48|
|Lv14・T9＋0|4/4|4/4|約35/48|約11/48|
|Lv18・T10＋8|4/4|4/4|0/48|約1/48|
|Lv40・伝説職・T20＋10|4/4|4/4|0/48|0/48|

ダウンは死亡とは別。勝っても多数の負傷者を出す場合がある。通常は70秒、本格は125秒で撤退するため、撤退は撃退成功に数えていない。

自然な給与と自動整備だけで2期/10期を経過させた比較も各4回。通常の初回侵攻は全4回で本隊制圧（15〜28秒、最大同時ダウン48人）。本格軍も全4回で時間切れ撤退、最大同時ダウン48人。戦闘経験・手動調達がない放置の初期軍はまだ厳しい。

Lv18/T10＋8は通常軍を平均約13秒、本格軍を約38秒で撃退。装備の強化を完成させれば対抗できる。

### 逆転の仕組み

- 通常軍は攻撃係数56。本格軍の一般兵は1.8×10。この試験の初期隊長で通常軍の実ATKは1,747、本格軍は参照状態/兵種により約493〜1,210。HPも通常軍の一般兵12,960、本格軍11,880というケースがある。
- 通常軍は3方向から分散してくる。本格軍は南東に集中するため、範囲技能と敵同士の衝突が効きやすい。配置による難易度差はコードと実測からの推定で、配置だけを交換する試験はしていない。
- 通常軍の攻撃上限は隊長のHP/DEFにも依存する。隊長を育成して本陣から離しておく追加比較では、敵ATKが2,621〜4,333へ上がった。Lv14/T9部隊の通常軍撃退は3/4へ低下。Lv18/T10＋8とLv40伝説職は4/4のまま。
- 本格軍の初回参照値はHP220/ATK48/DEF50まで。その後も限定された増加なので、育成軍が際限なく追随される仕組みではない。

侵攻60回の全体測定には、両軍の比較40回、自然整備8回、育成隊長での通常軍12回を含む。

## 3. 魔王本人と城内全体を分けた24回

通常兵の6人編成：重装の鎚、軽装の剣/槍、遠隔の火砲、衛生職、魔法使い。全員凡庸・均衡の適性、中立武器特性。伝説職、所定のレベル/装備、30/60/100期の生存分を仮に設定した到達時の戦力試験で、自然育成や装備入手を完了した証明ではない。装備は実際の筋力条件を満たすものだけを使用。隊長も相当装備のクラス3で、手動/自動攻撃を止めた状態の支援。

第25期（距離係数の作戦期補正が最大）。ボスだけを取り出した場合と、実際の28雑魚＋6精鋭＋魔王を配置した場合を各4回。通常の移動、射撃/弾切れ、魔法/MP、技能、防御、回復、かばう、蘇生を使う。全体試験は最初の交戦から180秒まで、隊長の手動移動・回避・強撃なし。

|到達時の仮の戦力|魔王単体|魔王単体の討伐時間・平均|城内全体制圧|最初の兵士ダウン・平均|
|---|---:|---:|---:|---:|
|Lv40・T20＋10・伝説職|4/4勝利|約1.21秒|0/4|約0.74秒|
|Lv60・T24＋20・伝説職|4/4勝利|約0.90秒|0/4|約1.18秒|
|Lv100・T28＋50・伝説職|4/4勝利|約0.80秒|0/4|約2.65秒|

城内全体の総HPは約272億。Lv100/T28＋50という非常に楽観的な編成でも、4回中1回は6人全員ダウン、他3回も隊長ダウンなどで制圧に届かなかった。AI自動戦闘の結果であり、熟練プレイヤーの回避・釣り出し・長期戦・部隊数増加などの全戦術を否定するものではない。

魔王単体は最初のアビスメテオ（3.2秒）より前に倒れる。この段階の部隊を想定した最終ボスのHPとしては低い。

## 4. 自律勇者の道のり：3回とも城の手前で全滅

実際の天啓から6人の勇者パーティを生成。成長20倍・専用T24装備・実際の地形経路/移動/敵生成/戦闘/蘇生を使用。隊長はフィールドの本陣にいて救援せず、一般兵や他の敵出現を除外。第10期固定、最長30分の有利な条件で測った。

|seed|最大到達距離|全滅まで|到達時のLv|城への入場|
|---|---:|---:|---:|---:|
|202610130|約479m|約8.8分|27|なし|
|202610131|約485m|約9.0分|26|なし|
|202610132|約481m|約9.7分|29|なし|

魔王城の入口は約594m。3回とも480mの倍率段差付近で止まった。全員の武器強化は＋0のまま。

勇者は `hero-party.js` の別AIで攻撃し、通常兵の更新では早期returnする。今回の剣/槍/鎚/斧の自動技能も、通常兵の物理基礎倍率2.2も使っていない。聖剣ATKの強化は反映されているが、通常兵と同じ強化を一式受けた戦闘経路ではない。可視/別空間での攻撃・敵AIにも差があるため、将来の共通化時は両方の検証が必要。

## 5. 数学上の無限強化と実用的な道のり

強化段と生存成長は無制限なので、絶対に討伐不能とは断定できない。ただしレベル必要EXPは指数増加する。通常兵の累計必要EXPはLv40で約4.35億、Lv60で約1.45兆、Lv100で約1.60×10^19。勇者は獲得EXP20倍だが、レベルが育っても武器＋0のままでは装備DEFが敵の倍率に追いつかない。

T28の1部位を0から＋50へ強化する累計費用は約29.2万G、＋1,000は約2.72億G、＋10,000は約607.7億G。＋1,000の装備攻撃倍率は251倍。際限ない周回や極端な強化を到達条件の代わりにはできない。

## 調整の優先順位（案・ゲームには未反映）

1. **道中の距離補正を1本の連続した曲線へまとめる。** 80/220/480mの急激な段差と、基礎距離係数×危険リングの重ね掛けを解消し、想定する到達戦力で倍率を決める。
2. **城内雑魚・精鋭・魔王を同じ戦力表で設計する。** 雑魚より魔王が強く、魔王戦で技能を何度か見られるHP/攻撃力にする。魔王のHPだけ先に増やさず、雑魚・到達時の実効DPS・MP/弾薬を含めて同時に測る。
3. **勇者の攻撃処理と育成を通常兵の仕組みに接続する。** 武器技能、装備強化、上位職、補給/蘇生を道中の拠点と連動させる。成長20倍だけに依存しない。
4. **本陣侵攻は現在の育成による突破を維持し、通常軍と本格軍の序列を整える。** 本格軍の配置・指揮官・技能を活かし、隊長の強化だけで留守番の敵ATKが上がる仕組みも見直す。

本陣をさらに厳しくする一括敵強化より、まず魔王城までの道を成立させる調整を優先する。

## 検証と再現

- 解析ツール：`tools/simulate-campaign-feasibility.mjs`、`--part stats|hq|castle|hero`。HQ60回＋城24回＋勇者3回＝87回、全群のゲームJSハッシュ一致/開始終了不変。ユーザーの保存スロットを読み書きしていない。
- データ：[campaign-feasibility-20261013](previews/campaign-feasibility-20261013)。ゲームのバージョンと本番数値は変更なし。
- 勝利判定は実際の敵HPと撃破数で確認。城試験の最初の集計は入口の退場判定と可変配列の参照による不正な勝利を検出して破棄。入口位置と撃破対象の固定参照を修正し、24回を再測定した。掲載したデータは修正後の結果のみ。
- 凡庸の統一編成、手動操作なし、有限の戦闘時間という限界がある。極端な育成値を直接設定した試験は、入手費用や育成時間を達成したことを意味しない。
