# 普通兵の近接スキルと剣・槍の調整（v6.6.0 / v238）

2026-10-13。ユーザー「その不整合は直すべき」「剣が不遇」「槍は安全な距離で突けるので若干の強化」を受けて、本番のゲームコードへ反映した。

重装・軽装系統の通常兵と上位職が、装備中の武器に応じて技能を自動発動する。既存の職業技能も使う。隊長は従来の手動強撃を使う。忍者、魔法使い、衛生職、遠隔職、独立した勇者パーティのAIは今回の自動技能の対象外。

## 実装した技能

倍率は兵士の通常物理攻撃の基礎値（ATK×2.2、覇王隊長の部隊補正を含む）に対する値。防御・会心・適正距離・魔法追撃・吹き飛び・成長は実際の戦闘経路を通る。

|武器|自動技能|基礎CT|効果|
|---|---|---:|---|
|剣|ダブルスラッシュ|6秒|2倍の斬撃を2回。2撃目は0.18秒後。1撃目で敵を倒したら近くの別の敵を選べる|
|槍|ファンスラスト|8秒|2.4倍の前方扇状突き。半角約29度、射程約1.67m。小さい押し戻しと短い硬直|
|鎚|クラッシュブロー|9秒|3.2倍の単体重撃。強い吹き飛ばし、通常敵を1秒硬直（ボス半減、巨頭無効）|
|斧|スピンアタック|8.2秒|2.6倍で周囲1.2mを全周攻撃。回転姿勢を描画。吹き飛ばしと0.6秒硬直|

初回の待ち時間は基礎CTの半分。以後は武器熟練に応じたCT短縮を適用。通常攻撃とは独立したCT。筋力不足の装備では発動せず、壁越しには命中しない。倒れたとき・武器交換・場所移動で剣の遅延攻撃を取り消す。撃破で敵配列が縮んでも次の敵を飛ばさないよう対象を固定して処理する。

## 剣と槍

- 剣：装備ATK係数1.0→1.8。隊長の基礎攻撃間隔0.40→0.32秒。兵士の通常攻撃CT係数0.80→0.55。武器リーチの半分付近を保ち、敵の中心まで潜り込む動作を修正。
- 槍：装備ATK係数1.5→1.6（約6.7%増）。兵士の通常射程を武器リーチの55%→82%へ。武器リーチの74%付近で立ち止まり、近すぎる場合は下がる。中立特性の通常槍なら約1.07mの間合い。
- 所持済みの通常剣・槍も読み込み時に1回だけ再計算。id、品質、強化段、固有特性を保持し、読み直しで倍率を重ねない。勇者専用装備とティアを持たない特殊データはこの再計算から除外。
- 兵士詳細の武器マスタリー欄に、現在の技能名・自動発動・基礎CTを表示。

## 再計測

Lv14/T9、品質1、強化0、中立特性、重装STR58／軽装STR53。180秒、dt=0.05秒、各8seed。単体・密集5体・列5体、固定敵と接近する敵で、重装/軽装合計48条件384回。実際のAI、技能、命中、防御、魔法追撃、吹き飛び、衝突を使用。成長は固定し、敵DEF100／HP1兆とした。
