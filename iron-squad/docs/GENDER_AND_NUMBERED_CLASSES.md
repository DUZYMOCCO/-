# 全兵種の男女・クラス番号・ボブ修正（v5.1.0 / ゲームキャッシュ v185）

2026-10-11。対象は Iron Squad のみ。前のv5.0.3の仕上げ差分とClaudeが取り込んだ内容を保持した。

## 男女と体格

全基本兵種・昇格した兵種・忍者・獣人・勇者パーティが、同じ性別判定を使用する。新規生成の男女確率は職種によらず50%ずつ。衛生職だけ女性65%、他の職種35%という偏りを廃止。性別による能力・成長・装備・昇格の制約は追加しない。

保存された性別を優先し、未設定の旧兵士は保存済みの見た目の性別、名前、最後にIDによる決定的な判定で補う。兵種を女性／男性の根拠にしない。再開時に性別を保存し、昇格で名前・性別・髪を引き直さない。名簿・雇用候補・個人詳細に男／女を表示する。

**筋力で体格を変える対象は、筋肉魔法師と筋肉衛生士だけ。** 既存の魔法・衛生系統の素の筋力条件をそのまま使用し、男女に同じ体格倍率を適用する。重装・軽装・弓・忍者・物理型獣人は筋力255でも従来の体格。装備、臨時バフ、表示用の筋力だけで太らせない。戦場・遠方・ダウン・肖像が同じ個人能力を読む。

## クラス番号

基本職は従来どおり職種名。昇格した職は「重装歩兵 クラス1」「衛生術師 クラス2」「隊長 クラス3」のように職種＋番号で統一。「聖女」などの性別を連想する昇格名を表示しない。男女とも同じクラス・費用・衣装・能力。

`class-up-rules.js` の `classTierLabel` と `numberedClassName` が任意の番号に対応する。定義の `baseClassId` と数値 `classTier` から名称を作り、追加段階をクラス4、5…と表示できる。隊長の次段階は配列位置ではなく段階番号から探す。隊長の昇格費用も共通の `CLASS_UP_COSTS` を使用。

保存・戦闘が参照する既存ID（PALADIN、SAINT、WARLORD等）は互換用に維持し、兵士には派生した職種系統とクラス番号も保存する。既存のスキル条件・倍率・昇格費用・礼装の豪華さは保持。新しい段階を実際に追加するときは、そのクラス定義・費用・描画・技能を別途用意する。

## ボブ

後ろ髪の中央が顎の下を横切って首を覆っていた。側面の毛束を残し、首の中央を空けた形へ変更。隊長の作成／身だしなみ、戦場、遠方、肖像へ共通で反映した。

## 確認

- 全89テスト合格。5系統×男女のクラス1〜3への実昇格と同じ費用、顔・髪・名前の保持、セーブ再開、隊長の男女両方の昇格を確認。
