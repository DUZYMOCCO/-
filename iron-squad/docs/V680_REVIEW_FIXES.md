## 1. 交戦中の重装が、弓兵より先に救助に選ばれる
- 場所：`js/casualty-rules.js` の `buildTransportRescueAssign`（今の 649行目付近）。
- 今の動き：近くに救助できる軽装がいないと、交戦中の重装も候補に入る。並び順が「LIGHT 0 → HEAVY 1 → その他 2」なので、近くに弓兵など軽装以外の兵士がいても、**交戦中の重装が先に選ばれて前線を離れる**。
- 意図：交戦中の重装は「ほかに誰もいないときの最後の手段」。
- 直し方：
  - 並び順を「軽装 0 → 交戦していない重装 1 → その他（弓兵など、衛生職は今どおり除外）2 → 交戦中の重装 3」にする。同じ順位の中は今どおり距離が近い順。
  - 交戦中の重装を候補から外す条件を「軽装がいる」から「重装以外の候補がいる」に広げる。
  - 交戦の判定（半径240px）は今のまま。`transportInCombat` は1回の選定で、重装1人につき1回だけ計算する（患者ごとに計算し直さない）。
- テストを足す：交戦中の重装と弓兵だけが近くにいる → 弓兵が選ばれる。交戦中の重装しかいない → 重装が選ばれる。

## 2. 近接4技能の待ち時間が、装備の攻撃速度で伸び縮みする（頼んでいない変更）
- 場所：`js/soldier-melee-skills.js` の `soldierMeleeReload`。
- 今の式：`cooldown × 熟練 × 速さ係数 ÷ max(.55, unit.atkSpeed) ÷ 死線の加速`。
- 問題：`unit.atkSpeed` で割る部分は指示書にない。護符や小手で攻撃速度が上がると技能の待ち時間が数分の一まで縮む。逆に鎚・斧・火砲のように攻撃速度がマイナスの武器では、最大約1.8倍に伸びる。重装も含めた全兵士の釣り合いが、測っていない形で変わっている。
- 直し方：`÷ max(.55, unit.atkSpeed)` を外す。技能の待ち時間は「基礎CT × 熟練 × 速さ係数 ÷ 死線の加速（ファントムステップ）」だけにする。通常攻撃の間隔は今のまま（装備の攻撃速度が効く）。
- テストを直す：装備の攻撃速度を変えても技能の待ち時間が変わらないこと。速さ係数と熟練では今どおり縮むこと。
