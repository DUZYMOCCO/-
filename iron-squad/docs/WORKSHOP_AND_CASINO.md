# 工房供給・素材製作・カジノ（v5.4.0 / ゲームキャッシュ v189）

> **v5.5.1の更新**：工房の解放ティアは購入の選択肢。兵士の新規調達・換装・強化は各本人のGから支払い、国庫の共通予算で一括調達しない。詳細：[PERSONAL_EQUIPMENT_BUDGETS.md](PERSONAL_EQUIPMENT_BUDGETS.md)。


**v5.7.0の入口変更（2026-10-11）：** 工房・組合・カジノを本陣内の建物に配置。入口へ近づき、専用画面で利用して本陣へ戻る。工房は北西、組合は北東、カジノは南東。営業条件（本陣発展Lv1 / Lv2 / Lv4）と取引の内容・保存は継続。国家メニューは施設の所在と営業状況を案内する。現在の検証は [playtest-hq-facilities.mjs](../tools/playtest-hq-facilities.mjs) と [CURRENT_WORK.md](CURRENT_WORK.md) を参照。以下は供給・製作・ゲームの規則を記録した実装履歴。

## 装備を拾うより、工房で整える流れ

| 完成装備の入手機会 | v5.4.0 |
| --- | --- |
| 通常敵 | 本陣付近3.5%、遠方は最大5% |
| 精鋭 | 18% |
| 通常ボス | 50% |
| 超巨大ボス | 60%の抽選を2回（従来の3品確定から減少） |
| 脇道の宝箱・砦 | 25% |
| ボス後の最奥宝箱 | 報酬の各包みで65% |

従来の複数品確定の特殊敵、砦、防衛報酬、小隊遠征にも抽選を適用。宝箱の包みには素材が必ず入り、完成装備は追加報酬になる。素材や装備のティアは既存の距離・敵種・宝箱種の分布を使用する。最奥の神話素材帯は保持。

工房の基礎製造ティアは本陣の発展から決まる。軍備研究でそれ以上のティアを開発済みなら維持する。既存セーブの研究や観測履歴は消さない。

| 本陣発展Lv | 基礎ティア | 工房Lv |
| --- | --- | --- |
| 0 | T1 | 1 |
| 1 | T5 | 2 |
| 2 | T9 | 3 |
| 3 | T13 | 4 |
| 4 | T17 | 5 |
| 5 | T21 | 6 |

研究で各素材帯の4世代を改良する。神話帯の観測後はT25〜28・工房Lv7まで進める。軍の不足補給・換装も、この製造ティアを使用する。v5.5.1以降の購入は各兵士の所持Gの範囲。国庫は給与・研究・発展の予算を負担し、給与・手当2.5期分と最低6,000Gの留保を維持する。

プレイヤーは工房で解放済みの任意ティア、9武器種または6防具部位を選び、Gで制式品を購入できる。完成品はバッグへ届け、所持装備と強化を保持する。価格は標準調達費の1.4倍切り上げ。従来の1期1回・2割引の隊長武器強化も利用できる。

## 素材と製作限定品

- 素材10種：堅木材、青銅片、鉄鉱石、精鋼片、ミスリル鉱、竜鱗、神話鉱、布革、魔力粉、魔力コア。
- 通常敵の素材ドロップは40%。精鋭・ボス・特殊報酬敵は素材を必ず落とす。ボス・超巨大ボス・最奥の財宝から魔力コアも入手できる。
- 地面の素材は結んだ袋と中の木材／鉱石で表示。装備の宝箱と描き分ける。隊長の1.8m吸い寄せ、0.44mで回収、地面で60秒の寿命は従来のまま。兵士は接触回収のみで、素材は同じ素材庫へ送る。
- 素材庫は10個の数量を保存し、装備のバッグに素材アイテムを増やさない。地面での連続回収は既存の10秒オートセーブ・終了時保存を使用し、素材ごとの全体セーブを避ける。宝箱は開封の取引全体をその場で保存する。
- 製作限定品は9武器種と6防具の全15レシピ。品質120%と部位ごとの専用効果を持つ。通常の敵ドロップ、商人、制式支給の抽選には出ない。
- 必要素材と製作費を表示。所持金・素材・町・解放ティアを再確認してから製作。完成品は保護付きでバッグへ届け、自動売却・自動納入の対象にしない。手動で装備・譲渡・保護解除して売却できる。
- 製作費は標準調達費の3倍。例：T1「無隙の匠剣」は堅木材10・魔力粉3・156G。品質120%と会心+6%。
- 武器は会心+6%、杖類は魔攻+10%も追加。盾はHP+10%と盾防+8%、兜はHP+20%、鎧はHP+18%と防御+10%、籠手は攻速+8%、脚具は移動+8、装飾は攻速+8%と再生+2。
- 専用効果は基礎能力を再計算してから適用し、強化・装備・再読込で重複しない。斧・ハンマーの武器ATK10倍と、剣の速撃は保持。

保存先は `materials` と装備の `craftOnly` / `craftRecipeId`。旧セーブには空の素材庫を補う。新しい遠征は素材庫をリセットし、継承兵が持つ製作装備は既存の装備継承に従う。

## ポーカーとスロット・増額できる掛け金

ダイス勝負を撤去。ポーカー、スロットをそれぞれ1期に1回遊べる。掛け金は100G以上の整数を直接入力でき、＋100G・2倍・10倍でも増やせる。ゲーム上の固定上限は設けず、開始時の所持金とJavaScriptの安全な整数計算範囲を確認する。

ポーカーは52枚から5枚を配り、残すカードを保持して一度だけ交換する。5枚全部を保持して確定も可能。開始時に掛け金を支払い、手の掛け金は固定する。次の掛け金設定を途中で変えても、進行中の手の配当は変わらない。カード・交換用の山札・保持・掛け金・精算済み状態を保存する。

| ポーカーの役 | 受取額 / 掛け金 |
| --- | --- |
| ロイヤルフラッシュ | 250倍 |
| ストレートフラッシュ | 50倍 |
| フォーカード | 25倍 |
| フルハウス | 9倍 |
| フラッシュ | 6倍 |
| ストレート | 4倍 |
| スリーカード | 3倍 |
| ツーペア | 2倍 |
| J以上のワンペア | 1倍 |
| 役なし・低いワンペア | 0 |

AはA・2・3・4・5のストレートにも使用。スロットは3リールで、チェリー・レモン・ベル・クローバー・ダイヤ・セブンが3つそろうと8・12・25・40・80・200倍、チェリー2つは1倍。各絵柄の重みは28・24・18・14・10・6。

掛け金の引落・配当受取・今期の利用記録は一度の処理で保存し、連打や再読込で重複精算しない。保存先は `nation.casino`。旧カジノの利用期も引き継ぐが、ダイスの記録は表示しない。継承して新遠征を始めると掛け金設定だけを残し、進行中の手・結果・前遠征の利用期はリセットする。
