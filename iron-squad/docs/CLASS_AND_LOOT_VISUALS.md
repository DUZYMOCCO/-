# 上位職の礼装・ドロップ・宝箱（v4.2.27 / SW v177）

2026-10-11。ユーザーの「上位職を豪華に」「魔法石と弾薬が何かわかる姿に」「近づいたドロップを吸い寄せ」「宝箱をティアごとに豪華に」に対応。追加指定に従い、吸い寄せの対象は隊長だけ。

## 見た目

- 重装・軽装・弓・衛生・魔法・隊長の上位3段階、計18職に専用礼装。金銀の肩飾り、胸章、宝石、刺繍、幅と丈の違うマント、二重裾、冠・羽・魔導の頭飾りを段階に応じて増やした。
- 重装は守護冠と装甲、軽装は片マントと刃形の飾り、弓は羽と葉形の裾、衛生は祭服と翼形の肩飾り、魔法は魔導襟と紋章、隊長は帝冠と二重マント。T28防具を着けても外周と頭の装飾が残る。
- 全身・遠距離・ダウン・休息・農作業・兵士肖像へ反映。顔と体格は同じ人物のものを維持。隊長は現在の昇格段階を参照し、頭上も覇王／帝皇／神話帝を表示する。
- 魔法石は面のある3本の結晶束。弾薬は蓋を開けた補給箱に矢と薬莢、金具・持ち手を付けた。覚醒宝珠は金色の球、神話宝玉は青白い多面宝玉として区別できる。
- 地上宝箱は実装済みの7素材×4製造段、T1〜T28で構造を変える。木板、帯金具、金属外装、角の補強、象嵌と宝石、竜鱗・爪脚、神話の冠と台座へ進む。製造段も鋲・補強・彫刻で差を付ける。ボス報酬には紋章を加える。
- 最奥の至宝箱にも同じ描画を使用。中身は複数Tierの抽選なので、外観は既存抽選の代表Tierを使う。描画で乱数を消費しない。封印・開封の状態も描き分ける。

## 吸い寄せ

- 隊長から180内部単位（1.8m）以内の地上ドロップが隊長へ動く。従来の回収距離44内部単位（0.44m）へ入ったら通常の受取処理を実行。速度は距離に応じて変え、隊長を通り越さない。
- 装備・ボス報酬・覚醒宝珠・神話宝玉・魔法石・弾薬が対象。吸い寄せ中は隊長が優先し、途中で兵士が回収しない。
- 兵士には吸い寄せを追加しない。隊長から離れた通常品は従来どおり接触して回収・配備する。兵士はボス報酬と宝珠を回収しない。
- ダウン・死亡中の隊長には吸い寄せも回収も発生しない。メニューで停止中は動かない。現在の場面だけを更新し、ダンジョンから野外の品を吸い込まない。地上ドロップの寿命60秒は継続する。

## 検証

- 回収・装備・場面分離・補給・勇者の5テスト、かな表示・壁通過・職別戦闘の3テスト、外観・体格・Canvas・休息・農作業の7テストが合格。
- 新しい吸い寄せは実updateで全6種類、境界の内外、途中の移動、隊長優先、二重受取防止、停止、野外リストの分離を確認。
- 同じ人物・同じ装備で、全系統の上位3段階が実ブラウザCanvasで異なる画像になることを確認。Native CanvasでもT28防具と7描画状態の107比較を実施。
- 宝箱28Tierすべての描画差、補給品と開封／封印等の11状態を確認。乱数なし、描画入力不変、Canvasの状態復元も確認。
- Chromeの375×667と844×666で描画を確認。実際のポインター入力、魔法石・弾薬・装備の吸い寄せと回収、最奥箱の開錠と5品の受取を確認。ページ例外なし。
- 工房の2ゲーム表示、SW177への新モジュール格納、オフラインでの新遠征起動と伝説職の隊長描画を確認。
- 礼装の静的な2レイヤーを18職で共有し、最大1.48MiBに制限。遠距離は簡略描画。iPhone実機の見え方・FPSは未確認。
