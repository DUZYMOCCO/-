# 死線スキルの兵種適合・商人の3分類（v6.8.4 / cache v246）

2026-10-13。提供写真の軽装兵が持つミラクルグレイスは、回復・蘇生AIを持たないため効果がなかった。2か所の覚醒処理が全技能から抽選し、優先技能も基礎職しか判定していなかった。

## 死線覚醒

`deathline-rules.js` に候補・優先技能・既存技能補正を集約。ウェーブ終了時と救助生還時の覚醒が同じ規則を使う。覚醒条件・40%の生還時抽選・重複なし/最大4技能の上限は維持。

| 系統（昇格・派生職も含む） | 優先技能 | 共通4技能に加える候補 |
|---|---|---|
| 重装 | アイアンウォール | ブラッドレイジ |
| 軽装 | ファントムステップ | ブラッドレイジ |
| 射手 | デッドアイ | ブラッドレイジ、デッドアイ |
| 衛生 | ミラクルグレイス | ミラクルグレイス |
| 魔法使い | ファントムステップ | なし |

共通4技能はサバイバルソウル、アイアンウォール、ファントムステップ、ラストグリット。魔法/浄化弾には物理会心が乗らないため、衛生/魔法使いはブラッドレイジ・デッドアイを抽選しない。衛生以外はミラクルグレイスを抽選しない。

既存セーブの兵士・予備兵を能力再計算時に補正。有効な取得技能を先に保持し、適合しない技能のみ、未取得の適合技能へ固定順で置換する。技能数・重複なし・残りHP割合・ダウン状態を保持し、再計算や保存/再読込で再抽選しない。写真の軽装兵の組み合わせは「ファントムステップ＋ミラクルグレイス」から「ファントムステップ＋サバイバルソウル」になる。隊長・独立勇者は補正対象外。

追加調査でデッドアイの射程+30%が保持されるだけでAIに使われていないことを確認。装弾中の弓/クロスボウ/火砲について、武器射程、兵種射程との比較、立ち止まる間合い、射撃を省略しない距離、飛翔距離に反映。弾切れの短剣/銃身殴り、隊長、独立勇者の射程は維持。昇格職の既存 `rangeMultBonus` を新しく有効化する変更は含めず、死線スキル分だけを使う。

## 商人の初期メニュー

最初は「回復」「取引」「セーブ」の大きなボタンを縦に並べる。商品の比較や長い交易説明は取引に進んだ後で表示する。

- 回復：隊長の150G全回復、部隊回復薬5,000G、蘇生薬30,000G、本陣の無料回復薬補充。価格・再使用待ち・携帯上限は維持。
- 取引：隊長/自部隊への購入先選択、武器/防具・装飾/術士用品、装備比較、任意の強化引継。隊長の所持金から購入して装備する既存処理を維持。
- セーブ：現在地を地点セーブ、地点セーブの読込、記録情報。補給用ボタン・薬の説明は回復側へ整理。

サブ画面の戻るは3分類へ戻る。初期画面の閉じるでフィールドに復帰。カテゴリごとにスクロールとフォーカスを保持し、カテゴリ間で購入先・装備タブを保持。取引・回復後は同じ画面、地点セーブ読込後もセーブ画面に留まり、戦闘を停止する。閉じた/別カテゴリに移動した取引の古いボタンは無効。
