# v6.10.0 メニュー整理・画面の階層点検

2026-10-14 / cache v249

## 実装

メニューの先頭に「ファストトラベル」を置き、地図と移動先一覧を別表示にした。移動先を開いたときは地図を描画せず、本陣・発見済み救護所・制圧済み拠点・発見済みダンジョンだけを表示する。地図はトップから独立して開ける。メニューから開いて戻ると戦闘停止を維持し、移動成功時はメニューも閉じて戦場へ戻る。ダンジョン内・隊長の搬送中の制限は既存処理を使う。

国家の初期表示は4分類だけ。分類を開くと同じ分類内の項目を横のボタンで切り替える。項目への切替に新たな中間画面や折りたたみは挟まない。

| 大分類 | 項目 |
|---|---|
| 財政・開発 | 国庫・寄付 / 収支報告 / 本陣開発 / 施設 |
| 領土・交易 | 地域 / 技術 / 建設 / 街道巡回 |
| 軍備・防衛 | 軍備 / 共有装備 / 本陣防衛 |
| 軍令・遠征 | 軍令 / 小隊遠征 |

項目画面の「国家へ」またはEscapeで4分類へ、その画面で「戻る」またはEscapeでメニューへ戻る。「閉じる」は戦場へ戻る。操作後の再描画でも現在の項目を維持する。UIの選択状態はセーブ項目に追加しない。

寄付・国庫投資・個人の軍資金による投資・軍備方針・重点事業・共有品納入・遠征選択・派遣・召還の処理は既存のものを使う。本陣加入前の国庫/方針操作の無効化は維持する。遠征の危険度/兵士選択だけを再描画した際にも未加入者の派遣が有効にならないようにした。

## 削除・短縮した画面の文

- 国家・部隊の冒頭にある「この画面に何を集約しているか」の長い紹介。
- 財政/軍備/領土の収入算定、装備の自動調達、給与積立、補充順の仕様説明。軍備の支出元と支給枠、現在の費用・実績は表示する。
- 魔力消費/瞑想/魔法石自動配分の長い共通説明。昼夜の固定周期やメニューで時計が止まる説明。
- 本陣侵攻の周期・人数・戦力下限上限の説明。次の侵攻期、到着までの秒数、敵の残数、現在の結果は表示する。
- 補給画面の回復薬/蘇生薬/弾薬/魔力/保管上限をまとめた仕様文。現在の補給条件・数・利用可否、地点読込の巻き戻し注意は残す。
- 遠征の重複紹介、部隊の役割の重複紹介、所持品件数の説明文、兵士詳細の能力成長式・回復EXP換算の説明。
- 周辺施設の操作場所を説明する一般文と、戦況画面の長い地図凡例。全体地図には短い凡例を残す。

救助が必要な人数と搬送先、施設の位置/解禁条件、叙勲の必要経験、寄付の75%/25%配分、装備の筋力条件・性能、強化引継で旧装備が消える注意、軍令の達成方法/報酬、遠征の報酬/被ダメージ倍率は操作判断に必要なので残す。仕様書や引き継ぎ資料は削除しない。

## 入れ子と導線の点検

| 対象 | 見つかった問題 | 今回の結果 / 残す理由 |
|---|---|---|
| 国家 | 全財政・開発・軍備・交易・防衛・遠征が1枚に並ぶ | 4分類・13項目に分割。初期表示から内容欄を除外 |
| 領土・交易 | 国家の長いページ内に4個のdetails | 項目切替へ変更。地域/技術/建設/巡回は各々独立表示 |
| 国家の収支・共有装備 | 分類と折りたたみが重なる | 独立した項目として直接表示。共有品の小さな内部スクロールも解除 |
| ファストトラベル | メニュー→戦況→地図、その下の移動先までスクロール | メニューの先頭から1操作で移動先。地図は別表示 |
| 戦況のルール集 | 折りたたみの中に複数の長い仕様説明 | ルール集を撤去し、現在の時刻・整備状況・要救助だけに整理 |
| 小隊遠征 | 危険度と3小隊のさらに下でメンバーを開く | 独立項目化。各小隊の兵士選択は1つの開閉を残す（24人の一覧を常時3つ出さないため） |
| 部隊→雇用 | 候補を閉じた後の画面に再度候補を開くボタン | 「雇用」タブの初回クリックでは候補が直接開くことを確認。閉じた後の再開ボタンだけを維持 |
| 部隊→バッグ→隊長装備/売却 | バッグ内に2種類の折りたたみ | 残る改善候補。売却の選択・総額・保護品除外を通常装備と混同しないよう現行操作を維持 |
| 名簿→兵士展開→装備→譲渡画面 | 装備変更まで段階が多い | 残る改善候補。今回の対象は国家と移動。兵士/部位/候補の3つの選択は保持 |
| 戦況→隊長記録/ログ/前回報告/音 | 複数の開閉項目がある | 階層は各1つ。隊長ステータス・戦闘ログには直接開く既存ボタンあり。前回の作戦結果と長期戦闘報告は内容が異なる |
| 鍛冶工房→素材 / カジノ→配当 | 内部に開閉項目がある | 各1つ。費用・不足材料・配当は行動判断に必要なため維持 |
| 商人 | 回復/取引/セーブから目的別に入る | v6.8.4の3分類を維持。購入先と装備タブも保持 |
