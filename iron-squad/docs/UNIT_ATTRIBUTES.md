# 兵士の個体能力と雇用 — v3.1.2 / SW v129

> 能力・個体・雇用・武器条件・体格はv4.0.0へ継承。給与と国家経済の現行仕様は [V4_NATIONAL_ECONOMY.md](V4_NATIONAL_ECONOMY.md)。

## 主人公のステータスと魔法（v4.0.6）

- 司令部の戦況から「隊長ステータス」を開く。12項目には5基礎能力と装備込みの魔法攻撃、MPを含め、回避には実際の確率も併記。
- `isPlayerCaster` は隊長フラグと装備中の杖・ワンドで判定。隊長の `weaponStyle` は装備再計算で更新する。兵種は変更せず、魔法使いのAIや瞑想停止を適用しない。
- `MAGIC_AFFINITIES` の4属性を共用。通常の消費、威力、範囲、状態効果を兵士と共通の着弾処理にまとめ、隊長のダメージ所有者／討伐功績を保持。魔法防御へダメージを掛け、成功したMP消費から魔力を育てる。
- `PLAYER_MAGIC_RULES` に最大MP100、射程260内部単位、魔法強撃36MP／8秒／1.8倍威力／1.5倍範囲を集約。通常CTは属性のCT÷隊長の攻撃速度。MP不足では不発だが移動は制限しない。通常CTと強撃CTの扱いは既存の隊長操作に従う。
- 補給・回復薬・共有魔法石を共用。防衛戦の本陣では自動全快を行わず自然回復。魔法武器を外しても残量と属性を保存し、再装備だけではMPを戻さない。現行保存形式4へ `player.mana` / `player.magicAffinity` を追加、欠落時は初回魔法装備で100MP／炎を補完。
- 魔法攻撃は隊長の基礎成長と装備の魔法攻撃、筋力用攻撃の一部、魔力係数、階級・覚醒・熟練・救出補正を使う。5基礎能力の255上限と、装備強化で性能が伸び続ける設計を保持。

## 決定した範囲

- 筋力・魔力・魔法防御・速さ・回避の基礎能力5項目は255が上限。
- HP・攻撃力・防御力・魔法攻撃力・回復力・実移動速度は別の計算結果。255では制限しない。
- 装備の強化段数は従来どおり上限なし。基礎能力は装備込みの性能に掛かる係数なので、装備が育っても個人差が残る。
- v3.1.2で給与・整備手当・ランカー手当と国家の歳入を成長に連動させた。装備の強化費は無限成長を保つ。詳細は [PAYROLL_FINANCE.md](PAYROLL_FINANCE.md)。
- 素質、行動の累計、能力の計算、武器条件、雇用画面を別モジュールに分けた。追加能力・職業・武器を後から拡張できる。

## 能力と実際の効果

|基礎能力|効果|行動による成長|
|---|---|---|
|筋力|装備込みの物理攻撃への倍率。搬送人数も変化|命中した物理近接で1、遠隔で0.35の練習値。杖・ワンドの殴りは0|
|魔力|装備込みの魔法攻撃・回復への倍率。魔法防御にも寄与|術に実際に使ったMP÷18の練習値。自然回復では育たない|
|魔法防御|魔法・属性ダメージに掛かる軽減係数|実際に受けた魔法・属性ダメージで練習値が増える|
|速さ|装備込みの移動速度への倍率。回避にも寄与|地形処理後の実移動距離。静止と地図間移動は対象外|
|回避|物理・魔法・属性攻撃の回避確率|回避成功で練習値が1増える。ダメージ床は回避しない|

筋力・魔力の倍率は、その兵種系列の標準能力を1倍として計算する。例：重装兵の標準筋力25は1倍、筋力50は2倍。装備の攻撃が1,000なら寄与は1,000／2,000、10,000なら10,000／20,000になる。装備の成長で差が消える加算方式にしない。

移動倍率は `0.8 + 0.2 × 速さ / 兵種系列の標準の速さ`。魔法防御の軽減係数は `100 / (100 + 魔法防御 × 1.2)`。物理防御と魔法防御は別々に適用する。

回避の基礎能力は0～255、画面には実回避確率も併記する。能力から得る確率は `回避 × 0.36 + 7.2 × (回避 / 255)^4`。才能・職業・死線の既存回避ボーナスは、残りの確率枠へこの値を掛ける。既存ボーナスを足しただけで早期に99%へ張り付くことを避け、能力255では99%に到達する。

搬送人数は `1 + floor(筋力 / 40)`、最大6人。隊長、一般兵、行商護衛、門衛も同じ計算。

## 上限付近の成長

生まれつきの能力＋Lv成長＋行動成長から、まだ制限していない成長量Pを計算する。行動成長自体も平方根で緩やかになる。

- Pが100以下：そのまま。
- Pが100より大きい：`100 + 155 × (1 - exp(-(P - 100) / 155))`。
- 整数能力は四捨五入、回避は小数1桁へ丸め、255で制限する。十分に育てれば255へ実際に到達できる。

上限で累計履歴を捨てない。再計算・装備変更・保存再開によって育成履歴が増えたり抽選し直されたりしない。HP・装備性能にこの制限は適用しない。

## 職をまたぐ個体（開発用の説明）

これらの特別行動や条件はゲーム内で説明・命名しない。能力と装備と戦場での行動から気づけるようにする。

- 衛生術師・魔法使いの通常の初期筋力は最大14。筋力のLv成長は標準の2.5に対し0.005。
- 新規抽選の0.2%で例外的な筋力を持つ術者が出る。天才判定とは別の抽選。固定種の衛生術師10,000人では、筋力が魔力を上回る例は17人だった。
- 剣は必要筋力18＋素材系列ごと4、槍24＋6、鎚32＋10。杖・ワンド・遠隔武器に筋力条件はない。Tierの製造4世代では条件を跳ね上げない。
- 自力の筋力が18以上ある術者は、剣・槍・鎚を使用中にLvの筋力成長差を武器使用補正で埋める。杖・ワンドへ戻すとこの補正も外れる。新しく持つ武器を仮装備した能力で条件を確認する。
- この自力の筋力18以上を満たす術者だけ、人物画像・雇用候補・戦場の近景／遠景／負傷姿の肩幅・胴・腕がたくましくなる。魔法使いと衛生術師の全昇格系列に適用。武器や一時強化に依存せず、能力履歴から再現する。顔の個性・頭の大きさ・戦闘値・武器リーチは保持。[体格の比較見本](previews/caster-physiques.png)。
- 近接の実火力が魔法攻撃の1.4倍を上回る術者は近接戦を選ぶ。魔法使いは殴った後、MP6で筋力と魔法攻撃に応じた魔法を追加する。MP0でも物理攻撃はできる。
- 筋力型の衛生術師は、近接交戦時にMP8で筋力を20%増加（最低3）、8秒間・再使用16秒。強化中も255上限を守る。重複せず、時間切れで戻る。治療・救助が優先。
- 戦士・弓兵は、魔力30以上かつ標準比の魔力が筋力の1.4倍より高ければ魔法を武器に乗せる。剣・槍・鎚の命中後、または弓矢の射出時にMP6を使う。矢は魔法威力を弾に保持し、命中時に物理と魔法を別々の防御で計算。通常弾薬を使い、石には魔法を乗せない。
- 術者は本来のMP容量、該当する戦士・弓兵は60MP。魔石・自然回復・補給地点で回復する。魔力の練習にも反映する。

杖・ワンドは別の武器形式。物理の攻撃値は控えめ、魔法攻撃の焦点性能を持つ。実描画・武器熟練も8形式へ対応。[武器の描画見本](previews/caster-weapons.png)。

## 雇用と観察

- 重装・軽装・弓兵・衛生術師・魔法使いを選び、候補を1人ずつ見る。次の候補は無料。
- 能力、回復・魔法攻撃、速度、搬送人数、成長素質、初期武器と必要筋力、費用、顔を確認できる。
- 自動募集は1.2秒間隔。天才が出たらその人を保持して停止する。手動更新、雇用、画面退出、非表示、ゲーム終了でも止める。
- 雇用時は表示していた本人を使う。能力・顔を再抽選しない。候補と職種と確認人数は保存し、自動募集は再開時に停止したまま。
- 兵士詳細に5能力と行動履歴、ランキングに筋力・魔力・魔法防御・速さ・回避率を追加（合計13部門）。回避率部門は才能等も含めた実確率を比較する。

## 保存と検証

保存形式は現行の `RULES_VERSION=4` を保持。既存の現行遠征は、兵士IDから安定した個体能力を補完する。現行保存を能力追加のために消去しない。通常兵・予備兵・隊長・候補・行商護衛・門衛の素質と履歴を保存する。一時的な自己強化は保存再開で持ち越さない。

- v3.1.0でtests配下36本通過。最後の表示・効果音修正に関連する5本も再確認。v3.1.2の体格変更は関連9本を通過し、条件・全昇格系列・武器／一時強化の独立・能力履歴からの保存再現・人物／近景／遠景／負傷の描画・同じ頭の画像・8方向の武器と手位置を確認。
- 実命中による成長、全攻撃種の回避、魔法防御、移動距離、静止・地図間移動の除外、希少な術者、剣・槍・鎚、隠れた魔法と自己強化の期限、全能力255、強化+10,000と倍率差を検証。
- 雇用の職種・1人表示・無料更新・自動更新・天才停止・本人の雇用・保存再開・退出停止を検証。
- 実ブラウザ：新規開始、保存再開、職種変更、無料更新、自動募集の進行と停止、13ランキング、390×844と844×390の画面を確認。雇用ボタンは44px以上。
- 固定条件の本格侵攻：標準進行は最大31名ダウン、討死0、勝利。育成防衛は損失0・勝利。兵士と護衛を外した基本隊長単独はHP0。個体能力・救護で結果が変化したので、固定乱数の討死人数を必須条件にしない。討死・出血死自体は輸送救護のテストで固定する。敵倍率の調整は今回していない。
- iPhone実機のFPS・指操作と、実プレイで上限へ近づくまでの長期成長速度は未確認。難易度の壊滅頻度は、以前の方針どおり別途検討。
