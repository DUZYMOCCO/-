# 🛡️ 重装歩兵（タンク）特化システム実装計画書

> **対象ゲーム**: Iron Squad (`iron-squad/`)  
> **作成日**: 2026-10-13  
> **目的**: 乱戦時に「ただ硬いだけの人（置物）」になっていた重装歩兵（HEAVY系統）に明確なタンクの役割（ヘイト誘導・身代わり・足止め）を与え、味方を守りながら被弾鍛錬で自ら育つ戦線の要として機能させる。

---

## 1. 背景と課題

v6.4.3 にて「被弾鍛錬の絶対値化・上限撤廃」および「重装歩兵のみ被弾防御（DEF）成長」が導入され、重装歩兵は受けたダメージに応じて無限に硬くなる成長基盤を得た。  
しかし実戦（特に乱戦時や遠距離敵の出現時）では以下の問題が発生していた：
1. **敵AIが単純な最短距離で狙うため、脆い後衛（術士・弓兵）や隊長が素通りで狙われる**。
2. **敵をせき止める足止め（CC）やボディブロックが存在せず、重装の横を敵がすり抜ける**。
3. **後衛への流れ弾や範囲攻撃をかばう手段がなく、重装が硬くても周囲が先に壊滅する**。

これらを解消するため、**【威圧感（ヘイト誘導）】**・**【守護・身代わり（かばう）】**・**【足止め（動く城壁）】** の3本柱を実装する。

---

## 2. システム詳細仕様

### 柱1: 威圧感・ヘイト誘導（見かけ上の距離ボーナス）
重装歩兵は体躯が大きく威圧的であるため、敵の索敵において実距離よりもはるかに近くにいるように認識される。

- **対象**: `attributeFamily(unit) === 'HEAVY'` かつ健在な兵士（`!unit.isDown && !unit.dead && (unit.hp || 0) > 0`）。
  - ※隊長は対象外（隊長自身が狙われやすくなると即死リスクが高まるため、兵士のタンクにヘイトを吸わせる）。
- **評価距離の計算**:
  - 敵のターゲット選択時、各味方とのユークリッド距離の2乗 `dsq` を比較する際、対象が重装歩兵であれば評価距離を **×0.5（`dsq` では ×0.25）** とする。
  ```javascript
  const isHeavyTank = s !== this.player && attributeFamily(s) === 'HEAVY' && !s.isDown && !s.dead;
  const evalDistSq = isHeavyTank ? dsq * 0.25 : dsq;
  ```
- **適用箇所**:
  - `iron-squad/js/index.js`:
    - 通常敵のターゲット選定ループ（`aliveSquad` 走査箇所、近接および空間インデックスフォールバック）
    - レイドモブのターゲット選定ループ（`raidDefenders` 走査箇所）
  - `iron-squad/js/enemy-ranged.js`:
    - 遠距離敵のターゲット選定ロジック（`chooseTarget` または該当ターゲット選定部）
- **注意点**:
  - 移動ステップ（`step`）や攻撃射程（`reach`）の判定には、当然ながら**本物の実距離（`Math.hypot`）**を使用すること。

---

### 柱2: 守護・身代わり（かばう / Guardian Cover）
重装歩兵の近くにいる味方が被弾した際、重装歩兵がそのダメージを肩代わりし、さらにその肩代わりダメージで重装自身の被弾鍛錬を進める。

- **発動条件**:
  - 被弾者 `target` が重装歩兵以外（隊長、術士 `MEDIC`/`MAGE`、弓兵 `ARCHER`、軽装兵 `LIGHT`）。
  - 被弾者から半径 **`COVER_RADIUS = 75px`** 以内に、健在な味方重装歩兵が存在する。
  - 重装歩兵のHPが一定以上残っていること（`guardian.hp > guardian.maxHp * 0.20`。身代わりによる即死・共倒れ防止）。
  - 条件を満たす重装歩兵が複数いる場合は、最も近い1名が「守護者（Guardian）」となる。
- **ダメージ分割ルール**:
  - 本来の被弾者へのダメージを **50% 軽減**（`targetDmg = Math.round(dmg * 0.5)`）。
  - 軽減された 50% 分を「身代わりダメージ」として守護者が受ける（`coverDmg = dmg - targetDmg`）。
  - 守護者の HP を `coverDmg` 分減算する（`guardian.hp -= coverDmg`）。
  - 致命傷防止: `coverDmg` によって守護者のHPが0以下になる場合は `guardian.hp = 1` で踏みとどまり、ダウンはさせない。
- **被弾鍛錬（成長）への完全連動**:
  - 守護者が実際に失った HP（`guardianLostHp = Math.min(coverDmg, guardianBeforeHp)`）に対し、既存の `applyHitGrowth(guardian, guardianLostHp, true)` を呼び出す！
  - これにより、**「後衛を守った分だけ重装の最大HPとDEFが恒久成長する」** という極めて気持ちの良い育成サイクルが成立する。
- **演出**:
  - 被弾者の頭上に小さなダメージテキスト: `🛡️身代わり! -${coverDmg}`（色: `#38bdf8`）。
  - 守護者の頭上に `🛡️ガード -${coverDmg}` または青い火花エフェクト。

---

### 柱3: 足止め・せき止め（CC / 動く城壁）
敵のすり抜けを防止し、前線で敵の足を止める。

#### 3-A. 重圧オーラ（すり抜け阻止・擬似ボディブロック）
- **仕様**:
  - 健在な重装歩兵の周囲半径 **`HEAVY_AURA_RADIUS = 48px`** にいる敵は、重装の肉体と大盾に阻まれ、**移動速度が 40% 低下（速度 ×0.60）** する。
  - 毎フレームの敵移動処理（`index.js` の `m.x += ...` 直前）で、近くに健在な重装歩兵がいれば `heavySlow = 0.60` を適用。
  - 魔法の鈍足（`magicSlowTimer`）とも重複可能（ただし最低下限は通常速度の 25%）。
- **効果**:
  - 重装歩兵の脇をすり抜けて後衛に向かおうとする敵が足止めされ、重装の前に敵がせき止められる。

#### 3-B. 大盾・重武器による重撃スタン
- **仕様**:
  - 重装歩兵が大盾（`shield` 装備中）または重武器（槌 `hammer`、斧 `axe`）で敵を攻撃した際、**35% の確率で敵に 0.8秒の気絶（スタン）** を付与する。
  - スタン中の敵は移動・攻撃が停止（既存の `m.magicStunTimer = Math.max(m.magicStunTimer || 0, 0.8)` を活用）。
  - スタン発生時、敵の頭上に `💫スタン!`（色: `#fef08a`）を表示。
  - ※超巨頭ボス（`isColossal`）はスタン無効、通常ボス（`isBoss`）は持続時間半減（0.4秒）。

## 4. テスト検証項目 (`iron-squad/tests/heavy-tank-specialization.test.mjs`)

以下の項目を検証する自動テストを新規作成すること：
1. **索敵優先度（距離ボーナス）**:
   - 重装歩兵（距離160px）と術士（距離100px）がいる場合、敵が重装歩兵をターゲットに選定すること（見かけ距離 160×0.5 = 80px < 100px）。
   - 重装歩兵がダウンした場合はボーナスが消失し、健在な術士を狙うこと。
2. **守護・身代わり（かばう）**:
   - 重装歩兵から 50px 離れた術士が 100 ダメージを受けた際、術士が 50、重装が 50 ダメージを受けること。
   - 重装歩兵のHPが 15% 以下の瀕死状態では身代わりが発動しないこと。
   - 重装歩兵が肩代わりしたダメージで `hitGrowthHp` および `hitGrowthDef` が正しく加算されること。
3. **重圧オーラ（減速）**:
   - 重装歩兵から 40px 以内にいる敵のステップ移動量が 0.60 倍に減速されること。
4. **重撃スタン**:
   - 重装歩兵の攻撃により敵の `magicStunTimer` が設定され、行動が停止すること。
   - ボスへの耐性（時間短縮または無効）が正しく機能すること。
