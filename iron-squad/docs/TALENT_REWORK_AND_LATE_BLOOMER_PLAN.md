# Iron Squad 実装計画書：神童の天才 ＆ 死線覚醒「大器晩成」へっぽこ

## 1. 背景と目的

- **へっぽこグリットの陳腐化解消**:
  従来の「へっぽこグリット（遠征生存ボーナス）」は最大8回生還しても固定値（HP+80, ATK+16, DEF+8）しか増えず、中盤・終盤のインフレ環境では実質ゼロに等しい雀の涙となっていた。これを割合（パーセンテージ）化して生涯腐らないボーナスにする。
- **「大器晩成」のドラマの実現**:
  「足手まといの劣等生。だが生き延びれば化けるかも…？」というフレーバーにもかかわらず、従来のへっぽこは死線を越えても素の成長率が 0.85 のまま据え置きだった。死線を越えたへっぽこが、Lv30までは耐え忍び、Lv31以降から爆発的に才能を開花させる「真の大器晩成」カーブを実装する。
- **3,000人に1人の「絶対的天才（GENIUS）」**:
  覚醒へっぽこが強くなる一方で、神童である「天才」が簡単に追いつかれないよう、出現確率を従来の 0.25%（1/400）から **0.033%（1/3,000）** へ大幅に絞り込み、補正値（成長率・基礎ステータス）を神話級の怪物へと超絶強化する。
- **悪徳傭兵団長プレイの成立**:
  「60Gで安く買い叩いたへっぽこ新兵を死地（前線・遠征）へ送り込み、死線を越えて生き残った者だけを大器晩成のエリートへ育て上げる」というダークファンタジー的リアリズムとプレイスタイルを確立する。

---

## 2. 仕様詳細

### ① 天才（GENIUS）の希少化と超絶強化
- **対象**: `iron-squad/js/index.js`（`rollScoutTalent`, `TALENTS.GENIUS`）, `iron-squad/js/unit-attributes.js`
- **スカウト出現率の厳格化**:
  - `roll < 0.0025`（0.25% / 400人に1人） → **`roll < 0.00033`（約0.033% / 3,000人に1人）**
  - 通常プレイではほぼ拝めず、スカウト自動連打で狙い続けて引けたら奇跡の超激レア枠。
- **基礎スペック＆成長率の超強化**:
  - 成長率 `TALENT_GROWTH.GENIUS`: `1.80` → **`2.40`**
  - 基礎HP倍率 `hpMult`: `1.70` → **`2.00`（2倍！）**
  - 基礎ATK倍率 `atkMult`: `1.75` → **`2.20`（2.2倍！）**
  - 移動速度ボーナス `speedBonus`: `+28` → **`+40`**
  - クリティカル率ボーナス `critBonus`: `+30%` → **`+40%`**
  - 覚醒へっぽこがどれだけ泥水をすすっても決して届かない「天賦の才という名の絶対的な壁」として君臨。

### ② へっぽこ（INFERIOR）の死線覚醒「大器晩成」
- **対象**: `iron-squad/js/unit-attributes.js`, `iron-squad/js/index.js`, `iron-squad/js/talent-labels.js`
- **覚醒条件**:
  - 才能が `INFERIOR` かつ、死線を1度でも生還するか死線スキルを所持（`s.survivedDeathlines > 0 || (s.deathlineSkills && s.deathlineSkills.length > 0)`）。
- **大器晩成の成長カーブ（着地点：1.55）**:
  - **Lv 1 〜 30**: 成長率 **`0.85`**（通常のへっぽこと同じ）。死線を越えてもすぐには強くならず、苦労人として耐え忍ぶ。
  - **Lv 31 〜 40**: 急激に才能が開花！
    - 計算式: `0.85 + (unit.level - 30) * 0.07`
    - **Lv 40到達時**: 成長率 **`1.55`**（英才 1.35 を突破し、天才の背中に手が届く！）。
- **ロマン演出（タグ昇格）**:
  - 死線を越えたへっぽこ兵士は、名簿・兵士詳細・ステータス一覧のタグ表示が
    `🍂へっぽこ` から **`🍂大器晩成`** に昇格する。

### ③ へっぽこグリット（遠征生存ボーナス）の割合化
- **対象**: `iron-squad/js/index.js`（`recalcSoldierStats`）
- **従来の固定加算（HP+10, ATK+2, DEF+1）を完全撤廃**:
- **パーセンテージ割合加算へ変更**:
  - 1スタックにつき: **HP +5% / ATK +4% / DEF +3%**
  - 最大8スタック時: **HP +40% / ATK +32% / DEF +24%**
  - 遠征を生還するたびに根性で基礎肉体がゴリゴリにビルドアップされ、終盤の超インフレ環境でも第一線で活躍可能に。
