# 武器の持ち方・攻撃モーション（2026-10-07 / v1.27.5）

## 修正した点

- 以前は手が固定されたまま武器だけが回転し、攻撃タイマーの減少に伴って振りが逆戻りしていた。武器と手・肘の位置を `weapon-motion.js` の共通ポーズから描く。
- 剣は柄を握り、鍔と刃を分離。構え→引き→横薙ぎ→振り抜き→構えへの復帰を補間する。盾は逆の手に取り付ける。
- 槍は後ろの手と前の手で柄を握り、引いてから前方へ突き出す。従来の長い残像線と二重の射程弧は撤去。
- 鎚は両手で柄を握り、頭を上げてから振り下ろす。槍・鎚を持つ間は盾を描かない。
- 武器は身体の左右反転から独立して、実際の攻撃角度へ向く。兵士は攻撃開始時の向きを保持し、移動による向きの変化で武器が跳ねない。隊長も同じポーズを使う。
- 通常の描画時間は剣0.24秒・槍0.30秒・鎚0.34秒。攻撃速度が高い場合は短縮。描画タイマーは0で止める。
- 遠距離の兵士は攻撃中だけ、腕と武器を少ない線で表示。通常の遠距離描画と兵数・敵数を保持する。

## スイートスポットの表示

隊長の近接攻撃時に限り、地面へ短い距離目印を表示する。`MELEE_SWEET_SPOT` の有効帯の両端を短線、ピークを小さな弧で示す。剣・槍・鎚それぞれの設定と、通常／昇格後のリーチを使用する。武器の絵は人物に合わせた縮尺であり、地面の距離目印が判定距離を表す。常時の射程線や全身を覆うエフェクトは追加しない。

既存のスイートスポット倍率、クリティカル、攻撃判定・ダメージの発生タイミング、攻撃クールダウンは変更しない。今回の補間は表示の動作であり、攻撃を遅延させる新しい判定処理は追加していない。
