# 技名（カタカナ英語）対応表 v4.2.22

技・魔法・覚醒技の表示名だけを変更。内部ID・キー（`DEATHLINE_SKILLS` のID、`SWORD_BEAM` など）とセーブ形式は変更なし。
セーブに保存されるのは死線覚醒のID（`deathlineSkills`）のみで、表示名は保存されないため旧名の変換は不要。
過去の戦闘ログ文字列だけは旧名のまま残ることがある（履歴表示のみ）。

## 対象外にしたもの
クラス名・兵士名・装備・地名、号令（呼集笛・突撃号令）、パッシブ効果名（回避!・手当て!・生還シールド）、魔法属性（炎・氷・雷・爆発）、忍者・獣人には名前付きの技が無い。
ひらがなモード: 技名は全てカタカナのため変換不要。辞書の旧名エントリは残置（無害）。
