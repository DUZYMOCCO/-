# 音の刷新 — v2.2.0 / SW v104

更新日：2026-10-08

## 遊び方

- ゲームを始めるとBGMと効果音を再生する。最初のタップで音声を有効にする。
- 縦画面右側の「音 ON／OFF」で切替。小さい横画面では司令部から操作する。
- **司令部 → 戦況 → 音・BGMの設定**で音量を個別に調整。標準はBGM35%・効果音65%。設定とミュートを保存する。
- アプリ切替などで止まった場合は「音を再開」。音源の通信が失敗した場合も再試行する。
- 昼は通常、夜は柔らかい音色、司令部では控えめなBGMにする。
- [12秒の音の見本](../assets/audio/preview.wav)。見本の音量はゲーム内のミキサーと異なる。

## 音源

単純なビープ中心の旧エンジンを、事前生成したWAVの再生へ置き換えた。弦・手太鼓・風を重ねた約27秒のループBGM、金属の共鳴、空振り、鈍い打撃、弓弦、クロスボウの留め金、低い火砲、属性魔法、回復、硬貨、倒れた音、報酬、敗北を用意した。

これは録音素材ではなく、物理的な響きを模したオリジナルの生成音源。外部サンプルパックや第三者の楽曲を使用していない。主観的な聴き心地は実機で確認が必要。

- 生成スクリプト：`iron-squad/tools/generate_audio.py`。Python＋NumPyで再生成可能。
- 固定乱数種：260108。22,050Hz・16bit PCM、BGMはステレオ、効果音はモノラル。
- `assets/audio/manifest.json`に長さ・ピーク・RMS・SHA256を保存。
- 19種の実再生音源＋見本は合計約3.76MiB。オフラインキャッシュには実再生19種とマニフェストを登録し、見本は含めない。
- 初回のみ取得・デコードし、ヒットのたびに波形生成／再ダウンロードしない。

## 再生と負荷

- BGMは1本。再開位置を維持し、開始時に0.25秒でフェードイン。
- 戦闘音は最大8声、効果音全体は最大14声。UIや報酬音は必要に応じて古い戦闘音を終了する。
- 同種の同時攻撃を間引き、座標付き戦闘音は隊長からの距離で減衰。850px以上は再生しない。終了した音声ノードは切断する。
- BGMと効果音を独立ミックスし、コンプレッサーで音の重なりによる急な増音を抑える。
- AudioContextは初回操作で生成。`suspended`だけでなく中断状態からの復帰、閉じたContextの再作成を扱う。復帰に失敗した場合は成功表示にしない。
- 背景では音を止め、復帰時に再開を試す。自動復帰できない場合は次のタップや専用ボタンで再開する。
- 対応環境だけ`navigator.audioSession`を設定する。[W3C Audio Session](https://www.w3.org/TR/audio-session/)と[WebKitの関連報告](https://bugs.webkit.org/show_bug.cgi?id=237322)を参照。対応状況を一律に仮定せず、機能検出と通常のWeb Audioへのフォールバックを使う。
