# v6.7.0 距離補正・魔王HP10億・遠隔三武器（2026-10-13）

ユーザー指定により実ゲームへ反映した。距離の二重掛けと境界の急増を除き、魔王のHPを10億にする。弓・クロスボウ・火砲は候補試験で議論した数値を採用し、筋力による積載と弾切れ後の短剣迎撃も実装した。ゲームキャッシュはv240。他ゲーム・ハブのファイルは編集していない。

## 距離と魔王

`campaign-scaling.js` の各能力を滑らかな1本の曲線にする。隣接点間を対数補間し、境界で倍率を掛け直さない。表は第1期の基礎距離倍率。第10期は1.225倍、作戦期の追加倍率は最大1.6倍。野外の別の軍勢適応補正は維持する。

|本陣からの表示距離|HP|攻撃|経験値|金|
|---|---:|---:|---:|---:|
|0m|1|1|1|1|
|80m|1.25|1.25|1.35|1.35|
|220m|12|10|75|60|
|480m|180|100|500|400|
|魔王城 約594m|3,000|350|1,900|1,600|
|793.6m以遠|20,000|1,000|26,000|22,000|

第10期の城内大型竜はHP約165万・攻撃20,580。魔王は距離補正を掛けず **HP1,000,000,000・攻撃85,000**。魔王が雑魚より弱かった逆転を解消する。地域の説明も実際のHP/攻撃倍率へ変更。距離のcm→m表示換算は変更しない。

旧セーブの休息中の敵・勇者隊が保持する城内敵は、一度だけ新倍率へ移行する。個体と残りHPの割合を保持し、魔王も同じ割合で10億へ換算する。本陣侵攻と固定能力の野外巨大魔獣は再倍率化しない。

## 三武器と弾切れ

|武器|基本積載|基礎間隔|装備ATK係数|特徴|
|---|---:|---:|---:|---|
|弓|120|0.60秒|1.05|単体への手数|
|クロスボウ|60|1.25秒|2.40|直進して最大3体、100%→70%→49%、小ノックバック12（上位の隊長18）|
|火砲|30|1.85秒|3.15|爆風半径62、砲弾・クラスターの追加2倍を1倍へ|

攻撃速度や武器個性による間隔補正は従来どおり。装備ATK係数は武器部分への係数であり、最終ダメージ全体への倍率ではない。クロスボウは移動区間の接触を距離順に処理し、壁で止まり、同じ相手へ再命中しない。死亡で敵配列が縮んでも後続の命中を飛ばさない。既存の通常クロスボウは個体・品質・強化値を保って一度だけ再計算する。

永久の筋力30を超えた分について、弓は1ごとに+1発、クロスボウは2ごとに+1発、火砲は4ごとに+1発。一時筋力魔法は積載に使わない。成長で上限が増えても弾そのものは増やさず、補給で満タンにする。既存セーブの残弾も勝手に満タンへしない。

投石は生成しない。兵士は弾切れ後に隊長・本隊の隊形へ戻り、90以内にいる敵だけへ短剣で迎撃する。短剣の射程65・基礎間隔0.9秒。遠隔武器の装備ATKと熟練補正を除き、剣の熟練を使う。弾切れ後も火砲の威力・爆風・押し戻しを引き継がない。隊長の通常攻撃・強攻撃、拠点攻撃にも空弾薬の処理を適用する。画面上の手持ちは短剣になり、実際の装備データは維持。補給後に通常射撃へ戻る。弾薬ゲージと詳細画面は個人の積載上限を表示する。

勇者隊にも積載・弾切れ迎撃・補給復帰は適用する。勇者の別AIに一般兵の物理2.2倍や近接4技能を追加する変更は今回含めていない。
