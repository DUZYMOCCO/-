# 防具の必要筋力と術士装備（v6.4.0 / v231）

通常の重装防具には必要筋力を設定。装備、譲渡、自動配備、自費調達、購入時の即装備、セーブ再開で共通判定する。職種では禁止しないため、実際の筋力を満たす筋肉魔術師は重装も使える。防具の条件には一時的な筋力魔法を含めない。

## 必要筋力

|素材帯の初期型|通常の胴防具|
|---|---:|
|木/布 T1|0|
|青銅/革 T5|12|
|鉄 T9|34|
|鋼鉄 T13|50|
|ミスリル T17|42|
|竜鱗/黒金 T21|68|
|神話 T25|80|

素材帯内で世代ごとに+2。盾は胴の80%、兜65%、籠手45%、脚具55%（切り上げ）。普通の装飾には筋力条件なし。ミスリルは軽い金属として鋼鉄より低い。

既存品も素材と部位から条件を計算し、古い `minStrength: 0` では条件を回避できない。不適合の防具は隊長ならバッグ、兵士なら共有箱へ戻す。強化、品質、IDは保持する。天啓の勇者専用装備は従来の専用アクセス条件と固定性能を維持する。

## 魔導・治癒・結界の3系統

各系統にローブ、頭巾、手袋、脚衣、護符盾、護符の6部位を用意（計18種、T1〜28）。全33製作レシピのうち18種が新装備。工房で購入/製作でき、通常ドロップと商人の商品でも防具抽選の35%で出る。専用のドロップ限定品の名前と能力は保持する。

術士装備の必要筋力はローブ3、護符盾3、頭巾1、手袋1、脚衣2、護符0。物理防御は同品質・同ティアの通常品の25%、HP補正は55%。盾防、籠手の物理攻撃、吸血、通常鎧の自動回復は持たず、魔法防御とバリアを持つ。

- **魔導**：魔力補正を中心に、少量のバリア。魔力補正は最終魔法攻撃の倍率を上げる（素質・鍛錬の能力値を変更しない）。
- **治癒**：回復補正を中心に、少量の魔力補正とバリア。最終 `healPower` を上げ、既存の治療・蘇生量の式へ反映。
- **結界**：魔力・回復補正を持たず、他の2系統の5倍のバリア容量。

補正率はティア、品質、部位で変わる。バリア容量と基本防御は強化で伸びる。再計算や同じ強化の適用で補正を重ねない。製作専用補正と保護は従来どおり加わる。

兵士の自動調達は魔法使い→魔導、衛生術師→治癒。戦士も重装の条件を満たせない場合は結界系を選ぶ。不適合品は購入前に除外。工房ティアの解放、本人の支払・6Gの留保、資金不足時の既存公費最低装備支給は従来どおり。

## バリア

装備の合計容量を上限として、実際の防御・軽減計算後の被ダメージの50%を容量の範囲で吸収する。物理・魔法のどちらにも効き、容量が尽きると吸収しない。命中から8秒間は再生せず、その後毎秒最大容量の6%を回復する。ダウン中・死亡中・メニューでゲームが停止中は再生しない。付け替えや再計算で即時補充しない。

残量と待ち時間を保存する。隊長の記録・兵士の個人記録に残量と最大容量を表示。工房、商店、バッグ、譲渡、装備一覧に必要筋力と補正を表示。ローブは系統の色と布の襞で見分けられる。
