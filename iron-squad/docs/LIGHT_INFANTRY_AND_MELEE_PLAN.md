# Iron Squad 次期実装仕様：軽装歩兵の高速アタッカー化＆優先救助 ＋ 遠隔兵の白兵戦（火砲の銃身殴り）

## 1. 背景と目的
- **軽装歩兵の無個性解消**: 重装歩兵のような被弾DEF成長やタンク機能がない軽装歩兵（LIGHT）を、全兵科トップの「速さ（quickness）」と「回避（evasion）」を活かした「超高速手数アタッカー」として尖らせる。
- **隊列崩壊の防止**: 味方が倒れた際、前線を支える重装歩兵（タンク）が救助に走って前線が崩壊するのを防ぐ。足の速い軽装歩兵が最優先で救助を担い、重装は前線を死守する。
- **遠隔兵のおっさん化防止**: 弾切れの弓兵が後方で棒立ちになるのを防ぎ、鎧のタフさで前線の白兵戦に参加させる。特に弾数の少ない火砲兵には「大砲の銃身でゴツンと鈍器殴り」をさせる。

## 2. 仕様詳細

### ① 救助AIの役割分担（前線死守と迅速レスキュー）
- **対象**: `js/casualty-rules.js`（救助者の選定・アサイン）
- **軽装歩兵の最優先救助**:
  - 味方がダウンした際、移動速度の速い軽装歩兵（LIGHT系統）を最優先の搬送者としてアサインする。
- **交戦中の重装歩兵の救助除外**:
  - 重装歩兵（HEAVY系統）は、周囲に敵がいる交戦中は救助行動を行わない（前線の敵を引きつけ続けることを最優先）。
  - ※周囲に敵がいない非戦闘時のみ、重装の救助を許可。

### ② 軽装歩兵の「スピード＆スキル超回転」アタッカー化
- **対象**: `js/unit-attributes.js`, `js/equipment-rules.js`, `js/soldier-melee-skills.js`
- **速さ（quickness）の戦闘反映**:
  - 軽装歩兵の高い「速さ」を、通常攻撃のクールダウン短縮、および近接4技能（剣=二連撃、槍=扇突き、鎚=重撃、斧=回転）のリロード時間短縮に直接反映する。
  - 武器種（剣・槍・ハンマー・斧）を問わず、重装兵よりも明らかに速いテンポで武器を振り、スキルを連発する。
- **回避（evasion）の維持**:
  - 重装の「被弾でDEF強化」に対し、軽装は「高回避率（dodge）で大振りを完全無効化」して生存する。

### ③ 遠隔兵の弾切れ白兵戦（火砲の銃身殴り）
- **対象**: `js/ranged-combat.js`, `js/weapon-motion.js`（または関連戦闘モジュール）
- **前線参加AI**:
  - 弾切れ時、後方に引きこもるのではなく、前衛（重装・軽装）のすぐ後ろ・横に入り、鎧の耐久を活かして通常攻撃で戦闘に参加する。
- **武器ごとの近接スタイル**:
  - **弓・クロスボウ**: 腰の「護身ダガー」で前衛の隙間から攻撃。
  - **火砲**: **「大砲の銃身で鈍器殴り」**。
    - 打撃属性の近接攻撃（重いヒット音、小ノックバック）。
    - 弾数30発を撃ち切った後の豪快な近接サポーターとして機能。
- **補給復帰**:
  - 補給エリアや補給役から弾薬を受け取った瞬間、ステップバックして即座に射撃モードへ復帰する。

## 5. Claude レビュー補足（2026-10-13・実装前に必ず読む）

### 着手の順番
- Codex が v6.7.1（cache v241：境界の壁つき倍率・弾薬上限のキャッシュ）を作業中。index.js / supply-rules.js / ranged-combat.js が重なるため、**v6.7.1 の完了後に v6.8.0 として着手**する。

### ① 救助の役割分担：既存の決定との整合
- v6.5.0 で「重装は牽引しても速度が落ちない」とした（js/heavy-tank.js）。この利点は、交戦していない時の重装の救助として残す。
- v6.4.1 の決まり（牽引先は判明済みの町だけ・衛生職がいる自部隊は隊長のそばで待つ・CT待ちの衛生職は隊長のそばにとどまる）は変えない。
- 「交戦中」の判定は、**重装の半径 TANK.hateReach（1000px）ではなく、半径240px以内に起きている敵がいるか**とする。広すぎると、重装がいつまでも救助に行かない。
- 救助役の選定は casualty-rules.js だけでなく index.js の兵士AIにもある。両方を探して、選定する1か所で優先度を付ける。
- 軽装がいない、または全員倒れているときは、重装でも救助に行く（誰も救助しないで死なせるよりよい）。

### ② 速さを攻撃テンポに反映：数値を決める
今の速さ（quickness）は移動速度だけに効いている（unit-attributes.js の movement）。次の式で通常攻撃と近接4技能の間隔を縮める。
- `tempo = clamp((15 / quickness) ** 0.35, 0.60, 1.00)` を、通常攻撃のCTと技能のCTに掛ける（15は重装の基礎の速さ）。
  - 目安：重装の初期（15）→1.00、軽装の初期（28）→約0.80、速さ60→約0.62、それ以上→0.60（下限）。
- **対象は兵士だけ**とする。隊長には掛けない（隊長の攻撃間隔は武器で決まる今の仕組みのまま）。
- 死線スキル「ファントムステップ」（攻撃速度+25%）や武器熟練の短縮と、掛け算で重ねてよい。ただし通常攻撃の最終CTは 0.12秒より短くしない。
- 回避は今の計算（速さ×0.09 が回避に加わる）のままにする。新しい回避の仕組みは作らない。

### ③ 弾切れの白兵戦：v6.7.0 の短剣迎撃を拡張する
- v6.7.0 で「弾切れ→隊形へ戻り、90px以内の敵だけ短剣で迎撃（ranged-combat.js の SIDEARM_RULES）」を実装済み。この仕組みを作り直さずに拡張する。
- 「前衛のすぐ後ろ・横に入る」は、**近くに味方の前衛（重装・軽装）がいるときだけ**。前衛がいなければ、今と同じく隊形へ戻る（弓兵だけで敵陣へ突っ込ませない）。
- 火砲の銃身殴り：sidearm と同じ経路で、威力は短剣の1.6倍、CTは1.4秒、ノックバックは小（25）、ヒット音は鎚の音を流用する。魔法の追撃・会心の武器分・重い武器の吹き飛ばしは、短剣と同じく乗せない。
- 補給で弾が戻ったら、次のフレームから射撃の位置取りに戻る（今の動作のまま。テストで確かめる）。
