# 農村の予備兵を遠征へ派遣（v6.11.6 / cache v256）

2026-10-14 ユーザー指定「予備兵を遠征に派遣できるように」。予備兵は川辺の農村で農作業して待機する設定を維持。

- メニュー→国家→軍令・遠征→小隊遠征→派遣兵士を選ぶ、で各小隊の本隊に加えて「[予備]」の候補を表示。所属小隊に関係なく予備兵を追加でき、本隊との混成/予備兵だけで3名以上を派遣できる。
- 予備兵は自動選択しない。保護中/ダウン/死亡表示/HP0/死亡者/すでに別小隊へ派遣中の予備兵を除外。選択欄を24名で切り捨てず全候補を表示。未選択の予備兵は農村に残る。
- 予備枠から本隊へ移さず、派遣・帰還中だけ共通の実戦対象へ追加。移動、通常攻撃/技能、敵の攻撃、地形衝突、衛生術師の救助、紐搬送、補給、描画に参加する。本隊48名の枠を維持。
- 出発時は農作業の畑の座標を利用し、遠征中は農作業の描画から除外。元の`platoonId`は変えず、遠征先小隊を一時フィールド`reserveExpeditionPlatoon`で持つ。旧直属フラグは`reserveExpeditionOriginalGuard`に保持して戻す。
- 遠征中は本隊の欠員補充/直属への編入に使わず、他の小隊にも二重派遣しない。遠征参加中の保護ロックは参加者や帰還報酬を変えず、次回派遣から適用。
- 本陣への帰還で従来の報酬精算を行い、健在者は農村の畑へ戻す。負傷者と運んでいる患者は本陣で通常の救護を受ける。戦死者は復帰させない。帰還完了を重複実行しても報酬は増えない。
- 名簿は農村待機/遠征・帰還中の人数を区別し、予備兵の個人記録にも遠征状態を表示。
- 通常/地点セーブで予備の所属・派遣先・座標・搬送関係を保存。ロード時の自動補充は派遣者を除外し、小隊を復元した後に搬送の整合を確認。派遣情報が孤立した旧データは待機へ戻す。
- 町へ搬送された予備兵も、保存時は部屋内の座標を野外入口側へ正規化。野外再開時に地図隅へ飛ばさない。派遣の保存失敗は小隊状態・元の座標/直属フラグへ戻す。
- 危険度/帰還条件/報酬係数、通常の本隊派遣、保護ロック、蘇生薬の優先順位を維持。保存形式の版は変更しない。
