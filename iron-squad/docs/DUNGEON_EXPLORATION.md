# ダンジョンの探索と周回（v4.2.28 / SW v178）

2026-10-11。「四角いだだっ広い内装に雰囲気と探索感を」「通路の端に宝箱、ボスを倒して財宝」の依頼に対応。

## 遊ぶ流れ

入口の部屋 → 広い主通路と2つの広間 → 南北の短い寄り道と宝箱 → ボスの広間 → 討伐で開く最奥の財宝 → 帰還。主通路は入口から奥まで直線でつながり、迷路にはしない。

対象は通常ダンジョン4箇所と廃墟4箇所。脇道の箱はその場に固定され、隊長が48内部単位以内に近づいて開ける。品は1つ、その場で受け取る。未開封の箱を地上ドロップへ混ぜず、吸い寄せ・60秒消滅の対象にはしない。開封状態と復活期限をダンジョンIDごとに保存する。

最奥の箱は従来どおりボス・番兵を倒して封印を解き、接近で開ける。中身は従来の報酬と地上ドロップを使用し、隊長への吸い寄せも働く。

部屋と通路がつながる部分には壁を引かず、床・壁・地図の物理形状を共有する。小物は通路中央と箱・ボス・出口の周囲を避ける。内装の更新で明らかになった、4種類のダンジョンボス本体の描画漏れも補う。

## 数期ごとの復活

調査前の実装では、前哨基地だけが2期後に復活し、通常のダンジョンの敵と最奥箱は再入場のたびに再生成されていた。ユーザーの確認を受け、通常ダンジョン・廃墟も**踏破から2期後**に敵・脇道箱・最奥財宝が復活するようそろえた。

- 同じ期や次の期に入り直しても、踏破済みの部屋の敵と最奥財宝は復活しない。入口には復活する期を表示する。
- 探索中に期限が来ても、突然敵や箱を戻さない。外へ出たあとで期限を適用し、次の入場で再生成する。
- ボスを倒さず寄り道の箱だけを取った場合も、最初の開封から2期が経ったあとに箱を戻す。2つ目を開けても期限を延ばさない。踏破したら全体の期限を踏破期から数え直す。
- 魔王城は周回リセットの対象外。魔王討伐と勇者の共有シーンを保持し、魔王を復活させない。
- 復活間隔は `dungeon-exploration.js` の `DUNGEON_RESET_PHASES=2`。ユーザーに提示した選択が未回答のため、前哨基地と同じ2期を採用した。

## 通行・保存

敵は歩ける広間・小部屋の中へ生成する。昔の魔王城シーンにある壁内座標は新しい床へ補正し、入口・ボス・最奥箱と勇者の中央ルートを維持する。

部屋同士の接続点を使う小さい経路補助を、直属・近接敵・射撃敵・魔法・衛生救護・搬送・勇者の移動へ接続。野外の本隊は入場させない。壁通過できる上位職とその搬送対象は従来の能力を保持する。廃墟の攻撃遮断も歩行壁と一致させた。

保存形式4と、通常のダンジョン内セーブを野外座標へ戻して再開する仕組みは維持。脇道の報酬を即受取にすることで、開封状態だけ保存して未回収品が失われる状態を作らない。スキル・敵の能力値・ボス報酬量は変更していない。

## 確認

- 8箇所で入口→南北の箱→ボス→入口の往復、主通路、120個ずつの床内スポーン、箱の壁際距離と廃墟の攻撃遮断を確認。
- 実updateで5基本職の直属追従、野外本隊の維持、近接・射撃敵の脇道追跡、衛生救護、ダウンした隊長の搬送と蘇生を確認。
- 実slotの保存→再開→再入場で開封履歴と報酬を保持し、二重受取なし。2期の境界、部分探索、探索中の延期、魔王城の除外、旧clearedWaveを確認。
- 関連8ファイル・13テスト合格。追加のボス描画検証は同描画の専用テストで確認。
- Chromeの375×667で、実移動更新による南北の寄り道、攻撃ボタンでのボス討伐、封印解除、財宝回収、直後の再入場と2期後の再入場を確認。ページ例外なし。
- 5テーマと25視点をNative Canvasで比較。描画入力・乱数・Canvas状態を保持。内装は見えている床・壁・小物だけ描き、追加の全マップCanvasを作らない。
- SW178で3新モジュールをキャッシュし、工房からオフラインで新遠征→ダンジョン入場・描画を確認。iPhone実機は未確認。
