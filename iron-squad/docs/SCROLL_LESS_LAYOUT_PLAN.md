## 3. 配置の決まり（全画面共通）
1. **スクロールする場所は1画面に1つだけ。** 入れ子のスクロール（中に小さなスクロール枠）は作らない。
2. **見出しと主な操作は画面の中に固定する。** 上：題名・戻る・閉じる・タブ。下：その画面の主な操作（購入・装備・派遣・前の兵士/次の兵士など）を固定のバーに置く。スクロールしないと押せない主ボタンをなくす。
3. **長い1枚はタブで分ける。** 縦に並べて読ませるより、横のタブで切り替える。タブは押しやすい高さ（44px以上）にする。
4. **一覧は1行に詰める。** 兵士・装備・商品・ランキングの一覧は1件1〜2行。押すと詳細が出る。その場で行を開いて下を押し下げる形（折りたたみの展開）は減らす。
5. **数値は格子に詰める。** 1行に1項目でなく、2〜3列の格子にする（今の「筋力・魔力・魔法防御」の3列のように）。
6. **横向き（844×390）は左右2列。** 左に一覧、右に選んだものの詳細。縦向きは今どおり1列。
7. 文字は今の大きさを下げない（本文は今の最小値以上）。詰めるのは余白と並べ方で行う。

## 4. 画面ごとの方針（2の測定で長い順に着手。上から優先）
- **兵士の詳細**：タブを4つにする。「能力」（HP/ATK/DEF・5能力・バリア/MP・魔力の一撃）／「装備」（7部位を1部位1〜2行・武器マスタリーは9枠を1〜2行のアイコン列に）／「記録」（戦績・作戦期履歴・死線スキル・成長）／「人物」（似顔絵・プロフィール）。名前の行と「前の兵士 / n / 次の兵士」は固定。最初は「能力」を開く。開いていたタブは兵士をめくっても保つ。
- **部隊・装備の名簿**：1人1行（兵種アイコン・名前・Lv・才能タグ・HPバー・役割）。押すと兵士の詳細を開く。
- **商人の取引・鍛冶工房・装備の譲渡**：一覧は1品1〜2行。押した品の比較（今の装備との差・必要筋力）と購入ボタンは、下の固定バー（横向きは右の列）に出す。購入先の選択はバーの上に固定。
- **ランキング・戦闘報告書**：分類のタブを上に固定し、一覧は1件1行。
- **戦況**：時刻・負傷・侵攻の状況を2列の格子にまとめる。
- 国家の13項目と小隊遠征は、序盤の写真では1画面に収まっている。中盤のセーブで測って、はみ出す項目だけ直す。
