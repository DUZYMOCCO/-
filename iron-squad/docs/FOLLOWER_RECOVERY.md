# v6.11.1 引っかかった直属兵の復帰

2026-10-14 / cache v251

## 動作

直属兵（加入前の旅の仲間・超過同行者も含む）が隊長から160内部単位（1.6m）より離れ、隊長の近くへ向かう移動を試みているのに、8秒間ほぼ同じ場所（基準位置から12内部単位未満）にいると復帰する。衝突で戻された後の実際の位置を測定する。12単位以上進めば時間をリセットするため、普通に迂回している兵は対象にならない。

復帰位置は隊長から40/60/80/100内部単位（0.4〜1m）の近傍を順に探索。野外の崖・工事障害・本陣の建物、町/ダンジョンの壁・床、地図の外側を検査し、兵士の足元に余白を取る。本陣/町の壁について隊長と同じ側に配置し、他の生存兵のすぐ上には置かない。ダンジョンでは隊長からつながる床だけを使う。候補がない時は0.5秒後に再探索する。壁の中や隊長の座標への強制配置はしない。

HP/MP/弾薬/装備/強化/経験値/攻撃CT/バフは変更しない。復帰は歩行鍛錬の集計後に行うため、ワープ距離で速さが育たない。旧座標の衝突記録と敵キャッシュだけを更新して、元の場所へ戻されるのを防ぐ。追加の常設UIや仕様説明は設けない。

## 誤判定の除外

- 本隊・遠征本隊・勇者隊・予備兵・門番は隊長追従の対象外。
- 兵士または隊長がダウン/死亡/死亡処理中、兵士が運ばれている場合は復帰しない。
- 救助へ向かう兵、負傷者/民間人を搬送中の兵、衛生職に救助対象が割り当てられている間は対象外。
- 瞑想、宿営、農作業、移動速度0、隊長近くの待機、遠くの敵へ向かう等で追従の移動指示がない場合は時間を破棄する。
- メニュー/商人中はゲーム更新が止まり、経過時間に加算しない。再開後はゲーム内で実際に進んだ時間だけを数える。
- 地図の出入り・ロードで隊長オブジェクトが入れ替わると時間をリセット。追従中断/救助/瞑想/実移動でもリセットする。

## 実装箇所

- `js/follower-recovery.js`：追従意図/実移動の検出と復帰先探索。計測はゲーム単位のWeakMapに持ち、セーブ項目や兵士オブジェクトにタイマーを追加しない。着地点の壁検査は既存の `wallBlocksAttack` を実ゲームから渡し、兵種モジュールとダンジョン定義の循環依存を避ける。
- `js/index.js`：更新開始/実際の地形確定と鍛錬集計後、移動目標を迂回経路へ変換する前に接続。救助処理を採用したフレームは除外。
- `js/limited-allies.js`：独自移動をする忍者にも追従意図の記録を追加。
- `js/dungeon.js`、`gate-rules.js`、`hero-party.js`、`navigation-map.js`：ゲーム内の変更モジュール参照をv251へ更新。戦闘・床・壁・通常経路の計算は変更なし。
- 本陣の本隊をファストトラベルに巻き込む別件の計画書は今回編集していない。
