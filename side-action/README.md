# ガンキック ヒーローズ（side-action）

よこスクロールの ガン＆キック アクション（こども むけ、iPhone SE2 よこむき 667×375 を きじゅん）。

- バージョン: 0.1.0（キャッシュ `v1`）
- いどう・ジャンプ（2だん）・うつ・キック・パンチ・ぶきかえ。タッチ（ひだり パッド ＋ みぎ ボタン）と キーボード。
- わざ: パンチ→パンチ→アッパー、まえげり→かいてんげり→まわしげり、くうちゅう とびげり、はしりながら（または した＋）キックで スライディング。
- ぶき: ハンドガン（むげん）／サブマシンガン／アサルトライフル／ショットガン／バズーカ。
- なかま: アオ（ライフル）と モモ（サブマシンガン）。タイトルで オン／オフ。
- ステージ 1「くらい けんきゅうじょ」ボス くろよろい エージェント、ステージ 2「やみの おやしき」ボス ねじれ ばけもの。
- ひょうげん: てきは すこし こわい デザイン。ちしぶきは みどり／むらさき だけ（あかは つかわない）、からだが ちぎれる ひょうげんは なし。たおすと けむりで きえる。
- キャラクターは すべて オリジナル。じつざいの はた・ブランドは なし。

## こうせい
- `js/rules.js` … すうち・ぶき・わざ・てき・ステージ（DOM なし）
- `js/game.js` … ゲームの なかみ（DOM なし。`botInput` で じどう プレイ できる）
- `js/render.js` … Canvas 2D の えがき
- `js/input.js` … タッチ／キーボード
- `js/sfx.js` … WebAudio の こうかおん
- `js/index.js` … がめん（タイトル・ポーズ・ゲームオーバー・クリア）とループ
- セーブ: `storage` の `side_action_save`
