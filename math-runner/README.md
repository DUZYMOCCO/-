# 🎯 さんすうシューター（Math Runner）

> **「けいさんして たまを ふやせ！」**  
> スマホの広告でおなじみの、ゲートを通って足し算・かけ算しながら弾を大量に増やし、前方のブロックや倍率ウォールをババババッと粉砕する爽快ランナーゲーム！

---

## 🆕 v1.1.0（ゆっくり モード・けしきを きれいに）

- **すすむ はやさ**：ロビーで ゆっくり／ふつう／はやい を えらべる（はじめは **ゆっくり**。セーブに のこる）。
  | | すすむ | ゲートの かんかく | つぎの ゲートまで |
  |---|---|---|---|
  | むかし（いまの「はやい」） | 260px/びょう | 400px | 1.5びょう |
  | ふつう | 170px/びょう | 460px | 2.7びょう |
  | **ゆっくり** | **120px/びょう** | **520px** | **4.3びょう** |
- ゆっくり でも むずかしさが かわらないよう、コースを ながく（ゲートの かず おなじ）して ブロック・かべの HP を ふやした（×2／×1.5。コインは HP ぶんで わる）。はじまって 1.2びょうは すすまない（ゲートを よむ じかん）。
- けしき：ステージごとに 3しゅるい（くさはら／さばく／うちゅう）が ぐるぐる。じめんの しましま・みちの タイル・ながれる ふち（あか×しろ など）・かざり（き・くさ・はな・いわ／サボテン・すな／わくせい・クリスタル）・くもの かげ・ほし・とおくの かすみ。かざりは ハッシュで きまるので ちらつかない。
- セーブ：`speed` を ついか（ない ときは ゆっくり）。コイン・ステージ・アップグレードは そのまま。

## 🎮 遊び方

1. **ゆびで左右にスライド**:
   - 画面を指で左右にスライドすると、銃がなめらかに移動します。
2. **ゲートを通って弾を増殖**:
   - 🟦 **青いゲート（+5、×2など）**: 弾の数が一気に増殖！
   - 🟥 **赤いゲート（-3、÷2など）**: 弾が減ってしまうのでうまく回避！
3. **ブロックを粉砕**:
   - コース上に立ちはだかる数字ブロックを弾幕で破壊してコインを獲得！
4. **ゴール＆倍率ボーナスウォール**:
   - ゴール後に並ぶ巨大な倍率壁（×1.5, ×2, ×3... ×20！）を弾幕でどこまで破壊できるかチャレンジ！
5. **アップグレード**:
   - 🔫 **スタートだんすう**: 初期弾数UP
   - ⚡ **れんしゃスピード**: 連射間隔短縮
   - 💥 **たまの いりょく**: 1発あたりの破壊力UP
