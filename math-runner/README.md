# 🎯 さんすうシューター（Math Runner）

> **「けいさんして たまを ふやせ！」**  
> スマホの広告でおなじみの、ゲートを通って足し算・かけ算しながら弾を大量に増やし、前方のブロックや倍率ウォールをババババッと粉砕する爽快ランナーゲーム！

## 🆕 v1.2.0（ほそい たま・うてる ゲート・まとを さいしょから・むずかしさの かいだん）

- **ほそい ながれ**：がめんに でる たまは 5ほんまで（よこ 3px・たて 16px、はば 0.035 ずつ）。ふえた ぶんは 1ぽんの いりょくに たすので ごうけいは おなじ。ゲートの かずが たまで かくれない。
- **うつ まと**：オレンジ〜むらさきの おこった かおの ブロック（ふとい ふち・HPの かずを おおきく・HPバー）。あたると ひかって ぷるんと ゆれ、HPが へる。**はじまった ときから がめんに みえる**（ブロック y=230、ゲート y=ブロック+0.4×かんかく）。1〜2かいめの ブロックは HPが ひくい（×0.45／×0.75）。
- **ゲートを うつと かずが かわる**（たまは ゲートを とおりぬける。1かいの はっしゃ = 1かい）：＋は 4かいで +1（+8まで）、−は 4かいで 1へって 0に なると ＋に かわる、×は 16かいで +1（×5まで）、÷は 8かいで 1へる。ゲートの もじは 34px・ふち つき・あたると ぷるん。
- **むずかしさの かいだん**（`gateSpec`）：ステージ1〜2は **+1〜+5 と −1〜−3 だけ**。3〜4は ＋−の かずが すこし おおきく。5〜は ×2、7〜は ×3 も、9〜は ÷2、12〜は ×4・÷3 まで。ブロックの HPも ステージで ふえる。
- ボーナスの かべは ×1.8 かたく（ゲートで ふえる ぶん コインが ふえすぎない ように）。ゆっくり／ふつう／はやい と セーブは そのまま。

- **v1.2.1 まちがえても すぐ おわらない**：わるい ゲートは かずが へるだけ（1こ いじょうは のこる）。ブロックに ぶつかっても ×0.7 だけ。しっぱいは「さいごの かべを 1まいも こわせなかった とき」だけ：かべの まえで 5びょう（`WALL_GRACE`）うちつづけて だめなら「もうすこし！ もういちど ちょうせん」（ステージは すすまない・ボーナス なし・ブロックの コインは もらえる）。ステージ1〜3は さいしょの かべが やわらかい（×0.4／×0.6／×0.8）。
  - かくにん（20〜150かい）：いつも わるい ゲートを えらんでも ゆっくりで ステージ1は 95%クリア・ステージ2は 55%。ふつうに えらべば ぜんぶ 100%。

- **れんだ（タップ・ゆびを いそがしく うごかす）は とくに ならない**：ゆびの そうさは 「よこの いち（`setTargetX`）」を きめるだけ。たまは エンジンの タイマー（`fireInterval`、アップグレードだけで かわる）で じどうで でる。ゲートの かずは 「1かいの はっしゃ = 1かい」（ひだりと みぎに わけても ごうけい 1）で ふえ、うえにも じょうげん（＋8・×5）が ある。テスト `mashing/shaking...` と ブラウザの じっけん（3びょうで しずか 18かい／れんだ 19かい）で かくにん。

## 🎮 遊び方

1. **ゆびで左右にスライド**:
   - 画面を指で左右にスライドすると、銃がなめらかに移動します。
2. **ゲートを通って弾を増殖**:
   - 🟦 **青いゲート（+5、×2など）**: 弾の数が一気に増殖！
   - 🟥 **赤いゲート（-3、÷2など）**: 弾が減ってしまうのでうまく回避！
3. **ブロックを粉砕**:
   - コース上に立ちはだかる数字ブロックを弾幕で破壊してコインを獲得！
4. **ゴール＆倍率ボーナスウォール**:
   - ゴール後に並ぶ巨大な倍率壁（×1.5, ×2, ×3... ×20！）を弾幕でどこまで破壊できるかチャレンジ！
5. **アップグレード**:
   - 🔫 **スタートだんすう**: 初期弾数UP
   - ⚡ **れんしゃスピード**: 連射間隔短縮
   - 💥 **たまの いりょく**: 1発あたりの破壊力UP
