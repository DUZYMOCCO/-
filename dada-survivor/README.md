# 🐱 ダダサバイバーもどき

子ども（7歳）のリクエストで作った、オートアタック・サバイバル。外部公開・販売の予定なし。

## 遊び方
- 画面のどこでも指でなぞるとキャラが動く（PCでは WASD / 矢印キー）。こうげきは自動。
- 敵を倒すと宝石 → 集めるとレベルアップ → 3枚のカードから1つ選んで強くなる。
- 2:30 に中ボス「おに」、5:00 に大ボス「ドラゴン」。ドラゴンを倒せばクリア。
- コインはタイトルの「おみせ」で永続強化に使える。
- 文字は漢字なしのひらがな・カタカナ。工房の「ひらがなモード」もそのまま効く。

## 技術メモ（canvas不使用の描画テスト）
| ファイル | 役割 |
|---|---|
| `js/rules.js` | 数値・湧き方・レベルアップ候補など描画に依存しないルール（テスト対象） |
| `js/art.js` | トゥーン調SVGをコードで描画。起動時に1回だけ data URI 化 |
| `js/stage.js` | DOMステージ。1体=1 `<div>`、毎フレーム `transform` だけ更新、要素はプールで再利用、一時エフェクトは Web Animations API |
| `js/index.js` | ゲーム進行・入力・画面（タイトル/おみせ/レベルアップ/結果） |
| `css/dada-survivor.css` | トゥーンUI。iPhone SE2（375×667）基準 |

- 同時数の上限：敵 150 / 宝石 150（超えた分は既存の宝石に経験値を合算）。
- ブラウザでの早送りシミュレーション（敵150体時）で `draw()` は1フレーム約0.1ms（PC版Chrome）。
