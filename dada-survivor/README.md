# 🐱 ダダサバイバーもどき

子ども（7歳）のリクエストで作った、オートアタック・サバイバル。外部公開・販売の予定なし。遊ぶ端末は iPhone SE2。絵は絵本調ではなく、暗い地面・細い目・金属の銃、というシリアス寄りのセル塗り。血しぶきは入れない。

## 遊び方
- 画面のどこでも指でなぞるとキャラが動く（PCでは WASD / 矢印キー）。攻撃は自動。
- **2ほんゆびで ピンチ＝かくだい・しゅくしょう**（0.6〜1.4ばい。PCは マウスホイール／＋−キー）。ピンチの あいだは キャラは とまる。ズームは セーブに のこる。HUD の おおきさは かわらない。
- 敵を倒すと宝石 → 集めるとレベルアップ → 3枚のカードから1つ選ぶ。**レベルと武器は毎回1から**。
- 最初のレベルアップは **じゅう・ショットガン・バズーカ** の3択。その後はいつものカードに混ざる（まだ持っていない武器は出やすい）。
- じゅうかショットガンをLv5にして「つよいたま」があると、次のレベルアップで **にちょう** か **ガトリング** に進化。バズーカLv5＋「ばくやく」で **でかロケット**。進化できるときは、そのカードが3択に必ず入る。
- 2:30 に中ボス、5:00 に大ボス。大ボスを倒せばステージクリア。
- **ステージ1（けんきゅうじょ）は みかたの きれいな じっけんしつ**（v1.6.1〜。しろい ゆかパネル `#e8eef3`〈まぶしすぎない オフホワイト〉・うすい みずいろの ライン・しろい つくえ／きかい・かみ。わるものぐんだんに おそわれた あとは すこしだけ＝ひび・はへん・うすい こげ 1つ）。**みかたの はた**（あおい たてに アトムと ほし、しろい つばさ。オリジナル）が スタートの そばに 1ぽん、ほかは ときどき（だいたい 12マスに 1ぽん）。ところどころに **みどりの えきが はいった ガラスの ボトル**（1〜3ぼんの れつ）。**6ぽんに 1ぽん くらい なかに うちゅうじんが ゆらゆら**、わられた ボトルも ある。はたと ボトルは かざりだけ（ぶつからない・バランス そのまま）。しろい ゆかでは ジョイスティック・ポンの わ・バリアを こい あおに、HPバーの わくは くろの まま。てき・ほうせき・じぶんは くろい りんかくで よく みえる。むかしの くさはらの 絵は `art.js` に のこして ある（`ground-grass`）。
- **1:30 に けんきゅうしゃ（しろい はくい・あたまに ！）が がめんの なかに でる**。さわると「けんきゅうしゃから スーパーミサイルを もらった！」。スーパーミサイルは いちばん つよい 1ぱつ（ダメージ380・ばくはつ はんけい155・3.2びょうに 1ぱつ・ホーミング）。レベルアップの カードには でない。はなれすぎると すぐ ちかくに でなおす。いまは ステージ1だけ（`STAGES[n].researcher = { at, gift }` を たせば ほかの ステージにも だせる）
- 文字は漢字なしのひらがな・カタカナ。工房の「ひらがなモード」もそのまま効く。

## 技術メモ（canvas不使用の描画テスト）
| ファイル | 役割 |
|---|---|
| `js/rules.js` | 数値・ステージ・そうび・セーブ移行など描画に依存しないルール（テスト対象） |
| `js/art.js` | 暗めのセル塗りSVGをコードで描画。起動時に1回だけ data URI 化。絵本調のほほ紅・笑顔は使わない |
| `js/decor.js` | ゆかの かざり（けんきゅうじょの ボトル）の ばしょを たね から きめる（DOM なし・テストあり） |
| `js/grid.js` | あたり判定の グリッド（`EnemyGrid`、64px マス）と `nearestN`（いちばん近い n 体）。DOM なし・テストあり |
| `js/stage.js` | DOMステージ。1体=1 `<div>`、毎フレーム `transform` だけ更新、要素はプールで再利用、一時エフェクトは Web Animations API |
| `js/bgm.js` | ダダサバイバー せんようの ポップ BGM（Web Audio で その場で つくる・音声ファイルなし）。工房きょうつうの `sound` の AudioContext／リミッターに つなぐので ミュート・BGM音量・ページかくし を そのまま まもる |
| `js/menus.js` | タイトル・キャラ・そうび・おみせ・たからばこ・結果の画面 |
| `js/index.js` | ゲーム進行・入力・HUD |
| `css/dada-survivor.css` | トゥーンUI。iPhone SE2（375×667）基準 |
| `tools/balance-sim.js` | ブラウザのコンソールで使う早送りバランス確認（本体からは読み込まない） |

- じめんの タイルは ふつう 160px、けんきゅうじょだけ 320px（`art.js` の `groundTile`。くりかえしが めだたないように）。
- けんきゅうじょの ボトルは タイルに かかず、`js/decor.js` が 360px マスごとに ランの たね から ばしょを きめる（だいたい 4マスに 1れつ・おなじ マスは いつも おなじ・ランごとに ちがう ならび）。がめんに みえる マスの ぶんだけ プールの `<div>` で かく（ふつう 0〜3こ、がめんの そとは かかない）。いちばん したの レイヤーなので てき・ほうせきの うしろ。
- けんきゅうしゃは `run.npc`（1にんだけ）。`index.js` の `spawnResearcher` と `updatePickups`、おくりものは `rules.js` の `receiveGift`。ぶきの `gift: true` は レベルアップ候補から のぞく。
- **ズーム**：`ds-view` の なかの `ds-cam` に `scale()` を 1かい かけるだけ（じめん・せかいは その なか）。`index.js` の `this.w/this.h` は「がめん ÷ ズーム」＝せかいで みえる はば で、てきの でばしょ・とおすぎる てきの だしなおし・けんきゅうしゃ・じめんタイルの おおきさは これで けいさん。ピンチは pointer の 2ほんめ で はじまり、のこりの ゆびを ぜんぶ はなすまで ジョイスティックに しない。iOS は `touch-action: none` ＋ `gesturestart/change/end` と 2ほんゆびの `touchmove` を preventDefault。
- **ズームで つよく／よわく ならないように**：ねらえる きょりは `battleR`（ズーム1の がめんの はんたいかく÷2＋50）まで、`battleR` より そとの ザコは 2.5ばいの はやさで ちかづく（ズーム1 では どちらも なにも かわらない）。clamp などは `rules.js` の `clampZoom / pinchZoom / wheelZoom`。
- **BGM**（v1.5.0〜）：ふつう 132 BPM・C の I–V–vi–IV（C G Am F）、8しょうせつで メロディ1しゅう（うしろ4しょうせつは アルペジオ つき）。ボスが いる あいだは 140 BPM・vi–IV–I–V（Am F C G）、16ぶ ハイハット・アルペジオ・4しょうせつめに スネアの フィル（4しょうせつの くぎりで きりかえ）。4つうち キック・2/4拍 クラップ・うらの ハイハット・オクターブで はねる ベース・うらはくの コードスタブ・スクエアの リード。50ms ごとに さきよみ よやく。おおきさは `BGM_LEVEL`（むかしの きょうつう BGM より 4dB くらい おおきめ、こうかおんの ピークと おなじ くらい）。工房きょうつうの サンプル BGM（`sound.startBGM`）は ダダサバイバーでは つかわない（`common/` は さわっていない）。
- 同時数の上限：敵 150 / 宝石 150（超えた分は既存の宝石に経験値を合算）。
- **かるさ対策**（v1.5.1〜、iPhone SE2 で 弾が多いと カクつく 対策）：
  - がめんの外（+130px）の 敵・宝石・アイテム・弾は `display:none`（スタイル計算・CSSアニメ・ペイントを しない）。外の エフェクト・ダメージ数字は つくらない。
  - 弾・爆発・オービットの あたりは毎フレーム1回つくる `EnemyGrid` で 近くの敵だけ しらべる（返す順番は 元の配列順なので、全部しらべた時と 結果が まったく同じ）。`nearestEnemies` は 配列を作らない 上位 n 選び。shots/enemies/gems/items は その場で つめる（毎フレームの `filter` なし）。描画も shots を 1回で 種類わけ。
  - 自動の「かるいモード」（`adaptQuality`）：フレーム時間の平均が 24ms を こえると `ds-lite`（ザコの ぴょこぴょこ・宝石/アイテムの ゆれ を止める、エフェクト 40→16・大爆発 12→6・数字 30→10、こまかい ポンを まびく）。19ms 未満が 3秒 つづくと もどる（また重くなったら 待ち時間を 2倍、最大 24秒）。**見た目だけで ゲームの動きは変わらない**。
  - 大爆発（boom）は ふだんも 同時 12 こまで。画面ゆれは 120ms に 1回まで（`getAnimations` を 呼ばない）。
  - 数字・エフェクトの ばらつきは カウンタで出す（stage.js は `Math.random` を使わない＝ゲームの乱数と まざらない）。`reset()` の あとに 届いた アニメ終了は むし（プールに 2回 もどる バグを 修正）。
  - 敵の おしあいグリッドの キーを ぶつからない 形に（まれに 同じ敵を 2回 おしていた）。
  - 計測（ヘッドレス Chrome・375×667・CPU 6倍／4倍 おそく、敵150・宝石150・進化武器＋スーパーミサイル）：6倍で 1フレーム 平均 約100ms → 約38ms、4倍で 約65ms → 約20ms（JS の update+draw は 約12ms → 約6.5ms／6倍）。
- **SVGの注意**：輪郭の太さを変えるときは `${S} stroke-width="5"` ではなく `${SW(5)}` を使う。同じ属性が2つあると SVG 全体が読めずに絵が消える（`tests/art.test.mjs` で検出）。
- **CSSの注意**：位置を `transform` で動かす要素に `transform` のCSSアニメを付けない（位置が上書きされる）。回転などは子要素か `::before` に付ける。
- 弾は `shots` の `kind`（`kunai` / `bullet` / `rocket` / `bomb`）。じゅう系の絵はショットの `art`。爆発の半径はパッシブ「ばくやく」の `stats.boom` 倍。進化は `EVOLUTIONS`（最大Lv＋対応パッシブで、次の3択に必ず入る）。
- セーブは工房の `storage`（キーに `game_studio_` が付く）の `dada_survivor_save`。旧バージョン（ステージ1だけ）のクリア回数は、ステージ1クリアとして引き継ぐ。
