# 🌊 ABYSS DIVE — 深淵潜航

深海を潜水艇で進む横スクロール・シューティング。巨大な深海魚と、沈んだ古代都市。
暗闇の向こうから迫る「なにか」に魚雷とミサイルを撃ちまくる。

- 入口: `js/index.js`（`prepare()` で CSS、`init(container, onBackToHub)` で起動）
- 本体: `js/game.js`（`createAbyssDive({ canvas, onGameOver })` が描画・更新・入力・音を内包）
- バージョン: `sw-assets.js` の `version` と `gameVersion`（更新時は必ず両方上げる）

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印 | 画面左側をドラッグ（バーチャルスティック） |
| 照準 | マウス | 自動ロックオン |
| 魚雷 | 左クリック / J（セミオート・1発ずつ） | 「撃つ」ボタン / 画面タップ（セミオート） |
| ミサイル | 右クリック / K | 右の「ミサイル」ボタン |
| 緊急回避 | SPACE | 右の「回避」ボタン |
| ソナー | SHIFT | 右の「ソナー」ボタン |
| 一時停止 | P / ESC | 右上の ❚❚ |
| 消音 | M | — |

## 中身

- **魚雷（セミオート）**: 押した瞬間に1発。押しっぱなしでは連射しない。撃ちすぎると過熱する。着弾で小爆発＋範囲ダメージ。
- **ミサイル**: 弾数制（初期8発）。敵を自動追尾して大爆発。敵が落とすこともある。
- **ソナー**: 周囲の敵にダメージ＋スタン。暗闇を探るのに必須。
- **緊急回避**: 無敵時間つきの加速。
- **深度**: 表層 / 中深層 / 漸深層 / 深海層 / 超深海 と景観が変わる。深いほど真っ暗。
- **沈んだ古代都市**: 崩れた柱・アーチ・神殿が背景を流れる。
- **巨大な影**: 画面より大きい生物のシルエットが横切る（当たり判定なし）。
- **ボス**: リヴァイアサン（巨大魚）とコロッサル・スクイッド（巨大イカ）が交互に出現。倒すごとに強化。
  当たり判定は頭だけでなく体の芯に沿って並べてあるので、胴体を撃っても通る。
- **背景の遠近**: 背景層と手前のあいだに遮蔽を1枚入れている。背景を泳ぐ巨大な影は的ではないと分かるようにしてある。

## 敵

| 敵 | 特徴 |
|---|---|
| 小魚の群れ | 弱い。巻き込むと気持ちいい |
| ハンター | 赤い輪が前兆。突進してくる |
| クラゲ | 触るとダメージ、倒すと電撃を撒く |
| チョウチンアンコウ | 発光するルアー。大口で噛みつく |
| 機雷 | 漂う爆弾。誘爆する |
| リヴァイアサン | ボス。背棘・縦スリット瞳・顎の発光ライン |
| コロッサル・スクイッド | ボス。吸盤つき触腕の薙ぎ払い／墨／突進 |
