# 🌊 ABYSS DIVE — 深淵潜航

深海を潜水艇で進む横スクロール・シューティング。巨大な深海魚と、沈んだ古代都市。
暗闇の向こうから迫る「なにか」に魚雷とミサイルを撃ちまくる。

- 入口: `js/index.js`（`prepare()` で CSS、`init(container, onBackToHub)` で起動）
- 本体: `js/game.js`（`createAbyssDive({ canvas, onGameOver })` が描画・更新・入力・音を内包）
- 徒歩探索: `js/explore.js`（遺跡の描画・入力）と `js/explore-rules.js`（歩く／調べる／戻るの純粋ルール、テスト対象）
- バージョン: `sw-assets.js` の `version` と `gameVersion`（更新時は必ず両方上げる）

## 中身

- **パイロット**: タイトルに立ち絵、潜航中は船体ゲージの隣に顔が表示される。被弾時は表情が変わる。
- **魚雷（セミオート）**: 押した瞬間に1発。押しっぱなしでは連射しない。撃ちすぎると過熱する。着弾で小爆発＋範囲ダメージ。敵への直撃時は着弾点に × が出る。前方近傍の生きた敵にだけごく弱く寄る（マウス・タッチの射出方向は尊重し、背後や射線外へは旋回しない）。
- **照準**: 船体とライトは移動で傾き、照準は弾の向きだけに反映する。緊急回避は移動入力の方向へ行う。
- **ミサイル**: 弾数制（初期8発）。敵を自動追尾して大爆発。着弾では白熱した小さい核＋橙の火花＋水中の膨張衝撃波（＋泡）が広がり、画面全体が明るくなる長いフラッシュは使わない。周囲の敵を爆心から距離減衰つきで放射状に吹き飛ばす（ボスと海底固定の戦車ヤドカリはダメージのみで動かない）。敵が落とすこともある。
- **ソナー**: 周囲の敵にダメージ＋スタン。暗闇を探るのに必須。
- **拾得物（v1.9.0 でアイコンを刷新）**: 敵が落とす／修理の 2 種。**ミサイル補給＝ミサイルの形そのもの**（弾頭・胴・尾翼が読めるシルエット）、**船体修理＝明るい緑十字**（回復とすぐ分かる形）。暗い海でも形で識別できるよう縁取りと控えめな発光を付け、深海の絵を白飛びさせない。補給量（+3）・回復量（+24）・ドロップ・当たり判定は従来どおり。
- **緊急回避**: 無敵時間つきの加速。
- **深度**: 表層 / 中深層 / 漸深層 / 深海層 / 超深海 と景観が変わる。深いほど真っ暗。
- **沈んだ古代都市**: 崩れた柱・アーチ・神殿が背景を流れる。
- **徒歩探索（遺跡）**: 序盤 x=1450 の浅い位置に光る「沈没都市 遺跡エアロック」がある。入口の近くで `E`／パッドA／「降艇」ボタンで潜水艇から降り、装甲の探索者で遺跡を歩く。**歩行は8コマ**（接地→踏み込み→すれ違い→蹴り出し × 左右。アセット倉庫 `bot-commander/assets/suit` の待機・射撃から `tools/gen_suit_walk.py` で生成）。歩調は**歩いている時間**で進み（0.9秒で左右1周期）、**移動速度や距離とは連動しない**ので、速く歩いても歩みは一定（歩く速さは v1.8.2 で **310 論理px/s**。v1.9.0 でストライドを 1.5 倍）。脚は もも/すね/ブーツの3ピースで、**接地中はブーツ底が床に水平**（踵で着いて足裏に体重、蹴り出しでだけ踵上げ）。**手前の脚＝画像左・奥＝画像右で、常に同じ手前の脚が上**（左右反転でも維持）。**ストライド中心は体の軸（`CENTER_X=180`）**。壁に押し付けても足踏みせず停止する。歩き出し・停止の姿勢があり、奥の2つの遺物を「調べる」と一度だけ報酬（+250点）。**`J`／`Z`／右下の「撃つ」ボタンでその場で撃てる**（構え→発射→短い反動。閃光と曳光弾が出て、歩きながらでも撃てる。**タップ=1発、押しっぱなしでサイクルごとに連射**）。入口に戻って「潜航へ戻る」で潜航を再開する（徒歩中は潜航のシミュレーションが止まり、周囲の敵の時間も止まる）。
- **遺跡の脅威（v1.9.0 試作 / v1.10.1 で銃を下へ・撃破演出）**: 通路の `x=900` に**地上敵 G06 を 1 体だけ**置いた。降艇地点（x=430）では**休眠で静か**、近づく（距離 340 以内）と**予兆**（頭上に「!」・地面の輪・コアが脈打つ・活動絵へ）に入り、**0.9 秒は動かない**（撃つ／引く猶予）。このとき**銃は前方の G06 の胴/甲殻の高さへ自然に下を向く**（頭・脚は傾けず、腕と銃だけが肩を支点に回る。**背後の敵へは向かない**）。そのあと近づいて短く**踏み込み**、当たると **HP −25**。**撃つ**（届いた弾だけ・見える銃口と曳光と同じ向きの弾道）か**引く**（距離 560 超で引き返す）で対処できる。**HP 3 発**で撃破。撃破の瞬間から**無害・撃てなくなり**、**少しのけぞって崩れ・コアが消灯して地面に沈み、少量の砂と気泡を残して消える**（唐突に消えず、画面を白飛びさせるフラッシュも使わない）。探索者の HP は潜航の船体とは別で、**0 になると短い演出で潜水艇へ撤退**（ソフトロックしない）。**撃破済みは入口を出入りしても復活せず、撃破演出も再生しない**（リスタート＝新しい潜航で戻る）。
- **探索者の絵**: `tools/gen_suit_walk.py`（+ `tools/suitrig.py`）で、上半身は元絵のまま、脚を「もも／すね／ブーツ」の3ピースに切り、2ボーンIK＋足首の独立回転で 8 コマ＋歩き出し＋調査 を作り `assets/suit_walk.webp` に出力する。**射撃の腕＋銃は `tools/gen_suit_shoot.py`** が `suit_shoot_upper.webp` から腕の画素を抜いて肩の下地 `suit_shoot_body.webp` を作り、実行時に腕だけを肩で回す（v1.10.1）。同条件で再生成すると一致する。
- **資源（v1.10.0 でスコアに代えて導入）**: ゲーム内の累積スコア表示をやめ、**資源残高**を表示する。資源は戦闘の撃破と遺跡の調査で得る。`localStorage` の**独自キー**（`game_studio_abyss_resources`）に保存し、**ハブへ戻る・リロード・やり直しでも維持**する。**同じ潜航内で同じ源からは二重付与しない**（新しい潜航では再取得可）。過去のハイスコアからは移行しない。魚雷・ミサイル補給と船体修理は従来どおりその場で効く（資源とは別系統）。**資源残高はハブのカードの BEST SCORE には渡さない**（別保存）。
- **海底基地（v1.10.0・最初のボスの先）**: 初回リヴァイアサン撃破で入港ルートが開く。**遠くの進入灯 → 鋼鉄の外壁 → 暖色に照らされた入港ドック**と、近づくほど段階的に見える（外観は室内とは別素材・別描画）。**自分で艇を進めてドックの近くまで行き、E／「入港」で明示的に入港**する（勝手にワープしない）。室内は**有限の安全区画**で敵もダメージも無く、**スーツなしのエリー**（倉庫 `GIRL` の idle/walk）が待機・歩行できる。船（潜水艇09）は左に接岸しており、**船のそばで E／「出港」で出港**。出港時に射撃入力を持ち越さず、やり直し（新しい潜航）でも進行は壊れない。室内候補は倉庫 `bot-commander/assets/dialog/bg/hangar.webp`（縦長）から横持ちに必要な帯を切り出す。
- **遠景の魚**: 青灰色の小魚の群れとエイが泳ぐ。敵魚には背棘、牙、発光する目がある。
- **海溝の 3D 背景（v1.14.0）**: 海溝（上の「海底基地」節の先の下り口から下へ潜る区間）の**背景と照明だけ**を **Three.js（WebGL2・正射影）で 1 回だけ描き**、従来の潜航パイプラインへ 1 枚の画像として合成する。**衝突する岩は `trench-rules.js` の solids（矩形）そのもの**で、同じ世界座標に同じ大きさで描くので**当たり＝見た目**（値を変えない）。奥の（触れない）岩壁は暗く沈めて背景として読ませる。**three r170 を同梱**（`vendor/three.module.min.js`、MIT、**CDN なし**）。**WebGL2 非対応・読み込み失敗・コンテキストロス時はその場で従来の Canvas 2D へ戻る**（進行は止まらない）。**遅延初期化**（海溝が近づくまでレンダラも three 本体も作らない）・**内部解像度は論理の約 0.62 倍に抑制**・**影なし/光源4/メッシュ約10枚**・**ハブ帰還で WebGL 資源を破棄**（再入場で二重初期化しない）。ON/OFF は**右上の「3D」ボタン**（PC は `T`）。OFF で GPU 資源を手放し、ON で遅延再初期化。**操作・シミュレーション・敵・地形の当たり・弾・バリア・HUD・入出港・BGM はすべて従来のまま**（自艇も既存の 2D 描画を重ねるので、射撃向き・4 艇の見分け・視認性は崩れない）。
- **ボス**: リヴァイアサン（巨大魚）とコロッサル・スクイッド（巨大イカ）が交互に出現。倒すごとに強化。
  当たり判定は**描いたシルエット寄り**（頭は頭の形に沿った円、胴は背骨に沿った円）で、胴体を撃っても通る。何も描いていない空間には当たらない。ロック表示は頭そばの小さな淡色ブラケット。巨大イカの触腕は**攻撃中だけ**、描いている長い触腕の位置で当たる。
- **背景の遠近**: 背景層と手前のあいだに遮蔽を1枚入れている。背景を泳ぐ巨大な影は的ではないと分かるようにしてある。
