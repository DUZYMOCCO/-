# 🌊 ABYSS DIVE — 深淵潜航

深海を潜水艇で進む横スクロール・シューティング。巨大な深海魚と、沈んだ古代都市。
暗闇の向こうから迫る「なにか」に魚雷とミサイルを撃ちまくる。

- 入口: `js/index.js`（`prepare()` で CSS、`init(container, onBackToHub)` で起動）
- 本体: `js/game.js`（`createAbyssDive({ canvas, onGameOver })` が描画・更新・入力・音を内包）
- 徒歩探索: `js/explore.js`（遺跡の描画・入力）と `js/explore-rules.js`（歩く／調べる／戻るの純粋ルール、テスト対象）
- バージョン: `sw-assets.js` の `version` と `gameVersion`（更新時は必ず両方上げる）

## 中身

- **パイロット**: タイトルに立ち絵、潜航中は船体ゲージの隣に顔が表示される。被弾時は表情が変わる。
- **魚雷（セミオート）**: 押した瞬間に1発。押しっぱなしでは連射しない。撃ちすぎると過熱する。着弾で小爆発＋範囲ダメージ。敵への直撃時は着弾点に × が出る。
- **照準**: 船体とライトは移動で傾き、照準は弾の向きだけに反映する。緊急回避は移動入力の方向へ行う。
- **ミサイル**: 弾数制（初期8発）。敵を自動追尾して大爆発。敵が落とすこともある。
- **ソナー**: 周囲の敵にダメージ＋スタン。暗闇を探るのに必須。
- **緊急回避**: 無敵時間つきの加速。
- **深度**: 表層 / 中深層 / 漸深層 / 深海層 / 超深海 と景観が変わる。深いほど真っ暗。
- **沈んだ古代都市**: 崩れた柱・アーチ・神殿が背景を流れる。
- **徒歩探索（遺跡）**: 序盤 x=1450 の浅い位置に光る「沈没都市 遺跡エアロック」がある。入口の近くで `E`／パッドA／「降艇」ボタンで潜水艇から降り、装甲の探索者（アセット倉庫 `bot-commander/assets/suit` の待機・歩行2コマ）で遺跡を歩く。奥の2つの遺物を「調べる」と一度だけ報酬（+250点）。同じ入口に戻って「潜航へ戻る」で潜航を再開する（徒歩中は潜航のシミュレーションが止まり、周囲の敵の時間も止まる）。
- **遠景の魚**: 青灰色の小魚の群れとエイが泳ぐ。敵魚には背棘、牙、発光する目がある。
- **ボス**: リヴァイアサン（巨大魚）とコロッサル・スクイッド（巨大イカ）が交互に出現。倒すごとに強化。
  当たり判定は頭だけでなく体の芯に沿って並べてあるので、胴体を撃っても通る。
- **背景の遠近**: 背景層と手前のあいだに遮蔽を1枚入れている。背景を泳ぐ巨大な影は的ではないと分かるようにしてある。

## 敵

| 敵 | 特徴 |
|---|---|
| 牙魚の群れ | 弱いが接触するとダメージ。まとめて倒せる |
| ハンター | 赤い輪が前兆。突進してくる |
| クラゲ | 触るとダメージ、倒すと電撃を撒く |
| チョウチンアンコウ | 発光するルアー。大口で噛みつく |
| 機雷 | 漂う爆弾。誘爆する |
| 戦車ヤドカリ | 海底で沈没戦車に擬態。接近すると起き上がり、砲口を光らせてから撃つ |
| 砲撃イカ | 深い区間を泳ぐ中型敵。砲口を光らせ、潜水艇を狙って撃つ |
| リヴァイアサン | ボス。背棘・縦スリット瞳・顎の発光ライン |
| コロッサル・スクイッド | ボス。吸盤つき触腕の薙ぎ払い／墨／突進 |

## 版の履歴

- 1.6.0 — 遺跡の徒歩探索を追加（序盤の入口から降りて歩き、遺物を調べて同じ入口で戻る）。連続で出てしまう回避入力と、撃破済みの敵が画面に残る不具合を修正。
- 1.5.0 — 遠景に小魚の群れを追加。敵魚の背棘・牙・目を強調し、倉庫の砲撃イカを実装。
- 1.4.0 — 背景魚をエイに変更。敵魚の胴体に射撃判定を合わせ、弾の経路で着弾を判定する。直撃マーカーを追加し、船体の向きと照準を分離。
- 1.3.0 — 倉庫の既存素材を再利用し、パイロット、機雷のスプライト、海底の戦車ヤドカリを実装。
- 1.2.0 — コンセプト動画の石造都市、潜水艇09、リヴァイアサンを写実寄りの背景・スプライトに更新。暖色のライトと上昇する泡を加え、iPhone 17 横持ち向けに暗幕の描画を軽量化。
- 1.1.0 — 魚雷を自動連射からセミオートに変更（PC＝クリック / スマホ＝「撃つ」ボタンとタップ）。ボスの当たり判定を胴体まで拡張。背景と手前の敵を分ける遮蔽レイヤーを追加。
- 1.0.0 — 工房に初追加。ツインヘッドライトの潜水艇、沈んだ古代都市、リヴァイアサンとコロッサル・スクイッドの2ボス。
