## v1.18.0 — ミサイル迎撃：ボス突進の停止（＋生き残った敵のノックバック）
- **ミサイルでボス（リヴァイアサン）の突進を止める**（`game.js`）。`lunge`／`sweep`（＋予備動作 `lungeWind`/`sweepWind`）の**リヴァイアサンだけ**を、**直撃または十分近い爆風**で一度止める。中断＝**プレイヤーから離れる向きへ短く押し戻し（560px/s・減衰）→ `stagger`→`recover`→`stalk`**。`lvx`/`lvy` は 0、押し戻し中は**接触ダメージを無効**。
- **「十分近い」は描画と共通の幾何（`enemyHit`）**で判定＝**中心座標が爆風半径の外でも実ボディが触れていれば止まる**。
- **イカ（突進なし）は対象外**。**遠い爆風・待機/回復中の追撃・魚雷では中断しない**（永久ハメ防止）。既存の爆発・ダメージ・体表発光の抑止は不変（二重加算なし）。
- **生き残った通常敵の押し流しは従来どおり**（`knockEnemy`：`vx/vy`＋短い `stun`＝次フレームも流れる）。固定ヤドカリは動かさない。

## v1.8.1 の確認状況
- **徒歩の歩調を移動から分離した**。v1.8.0 は位相を「動いた距離」で進めていたが、**「歩いている時間」**で進める（`WALK_CYCLE_T = 0.90s`／左右1周期）。**移動速度・移動距離・スティックの倒し込み量はアニメ位相に使わない**。`WALK_SPEED` は 140 → **250** 論理px/s に戻した（アナログ量は移動距離だけに反映）。→ 速さが変わっても歩みは一定のゆったりした歩調。
- **押しても壁で動けないときは足踏みしない**（実際に x が動いたときだけ歩行。動けなければ停止→待機）。
- **つま先立ちの原因を直した**。v1.8.0 は「すね＋ブーツ」を1ピースにして接地点を**最下点**へ合わせていたため、脚が傾くと爪先だけが接地していた。脚を**もも／すね／ブーツの3ピース**に分け、**足首を独立に回せる**ようにして、**接地中はブーツ底を水平**・**踵で着いて足裏に体重、蹴り出しでだけ踵上げ**にした（爪先上げ/踵上げ量は足首角度）。ブーツは細い所 y=334 で切り、**全15コマで最下点＝床 y=360（はみ出し0）**。
- **ボスの当たり判定から巨大な透明円を外した**。`enemyHit` のボス分岐は頭の1点中心の旧円 (r=150/190) をやめ、**頭は描いた頭に沿った円・胴は背骨に沿った円**（描画と同じ式）。空洞では当たらず、胴体への命中は維持。

- `node --test abyss-dive/tests/*.test.mjs` は **38 件すべて通過**（assets 5 / combat 5 / explore 20 / weapons 8）。JS 5 本の構文チェック通過、`git diff --check` クリーン。

## 徒歩探索（v1.6.0 で追加 / v1.8.0 で歩行と射撃 / v1.9.0 で G06 との戦闘試作）
- 潜航側の入口: `x=1450, y=430`（半径78）。入口の近く（距離 ≤ 入口半径+46）でのみ「降艇」を受け付ける。E / Enter / パッドA / 入口近くの「降艇」ボタン。
- 降りると探索マップへ切り替わり、**潜航のシミュレーションは止まる**（敵・弾・時間が進まない）。描画も探索側へ委譲する。
- 探索マップは 1 枚（全長 2600）。歩けるのは x=130〜2470。床は `GROUND_Y=566` の水平 1 本。
- 遺物（調査地点）は 2 つ: `x=1200`「崩れた祭壇」、`x=2010`「沈んだ石碑」。近づいて「調べる」で **1 度だけ** 報酬（1 つ +250 点）。2 度目は「調査済み」表示に変わり報酬は出ない。
- 進捗（`relics` / `surveyed`）は**1 潜航のあいだ保持**される（入口を出入りしても消えない）。`startGame()` でリセット。
- 帰還は入口と同じ場所（`EXIT_X=250`）。近づいて「戻る／潜航へ戻る」で潜航再開。**帰還時は予約入力をすべて捨てる**（`clearInputLatch`。射撃予約 `wantShoot` も含む）。
- **歩行アニメ（v1.8.1 / v1.8.2）**: 8 コマ（`walk`）。位相は**歩いている時間**で進む（`WALK_CYCLE_T = 0.90s` で左右 1 周期。**移動速度・距離・スティック量は位相に使わない**）。脚は もも/すね/ブーツの 3 ピースで、**接地中はブーツ底が水平**（踵で着いて足裏に体重、蹴り出しでだけ踵上げ）。床より下へのはみ出しは無し。押しても壁で動けないときは足踏みせず停止へ。停止モーション → 待機、歩き始めは「歩き出し」2 コマ。**前後は手前=画像左・奥=画像右で、常に同じ手前の脚が上**（左右反転時も維持）。**ストライド中心＝体の軸（`CENTER_X=180`）**で両足が対称に振れる（v1.8.2）。
- **調査の姿勢変化**: 専用 4 コマ。非ループで、終わると待機へ。歩き出すとキャンセル。
- **射撃**: 上半身に射撃ポーズを重ねる（脚は止めない）。**前方の交戦可能な G06 がいる間は、腕＋銃だけを肩で回して銃口を下げる**（頭・胴・脚は動かさない。体は腕を抜いた `suit_shoot_body.webp`、腕は `suit_shoot_upper.webp` の切り抜き）。曳光弾・火花は見た目のみ。弾（当たり判定つき）は `explore-rules.js` の `aimVector()` が銃口から出し、`explore.js` は同じ計算で閃光・曳光を描くだけ（見た目と判定が同じ銃口・弾道・向き）。
- **地上敵 G06（v1.9.0 試作・1 体 / v1.10.1 で銃を下へ・撃破演出）**: `x=900` に配置。休眠（`idle`）→ 距離 340 以内で予兆（`alert`・0.9s 停止）→ 追跡（`chase`・172/s）→ 間合い 112 で溜め（`wind` 0.34s）→ 踏み込み（`lunge` 620/s・0.22s）→ 硬直（`recover` 0.9s）。踏み込みの接触で HP −25、無敵 0.8s。距離 560 超で引き返す（`return`）。弾 HP 3。**前方の交戦可能な間は銃口を胴/甲殻の高さへ下げる（θ=0〜17°）**。撃破で `alive=false` になり**直ちに無害・撃てない**まま、**0.85s の演出（のけぞり→休眠差分へ崩れ・コア消灯→沈む→砂/気泡を残して消える）**。HP / 撃破 / `deathT` は state に残り、降艇のたびに位置と行動だけ休眠へ戻す（**再入場で復活も演出再生もしない**）。

## 探索者の絵の作り方（v1.8.1 / 射撃の腕は v1.10.1）
- 元絵は `アセット倉庫 bot-commander/assets/suit` の `suit_idle` / `suit_shoot`（384×384、足元 y=360）。
- `tools/gen_suit_walk.py`（内部で `tools/suitrig.py`）が、上半身をマスクで切り出し、脚を**「もも」「すね」「ブーツ」の3ピース**に分けて 2 ボーン IK ＋**足首の独立回転**で 8 コマ ＋ 歩き出し2＋調査4 を作り、`assets/suit_walk.webp` を書き出す。接地中はブーツ底を水平にし、蹴り出しでだけ踵を上げる。ブーツは細い所 y=334 で切る（すねが床下へはみ出さない）。
- **射撃の腕＋銃（v1.10.1）**: `tools/gen_suit_shoot.py` が `assets/suit_shoot_upper.webp` から `ARM_POLY` の腕＋銃の画素を抜き、肩の下地で埋めた `assets/suit_shoot_body.webp` を作る。実行時は body を描き、`suit_shoot_upper.webp` を `ARM_POLY` で切り抜いて**肩 (122,88) を支点に回して**重ねる（頭・胴・脚は動かさない）。再現: `cd abyss-dive && python tools/gen_suit_shoot.py`。
- **前後と軸（v1.8.2）**: `XSPLIT=186` で左右を切り、**手前(near)=画像左（x<186）／奥(far)=画像右**。`render_pose` が `far→near` の順に重ねるので常に手前の脚が上（左右反転時も維持）。**ストライド中心 `CENTER_X=180`＝胴体/骨盤の縦軸**（股関節 `HIP` も 180）。両足はこの軸に対称に振れる。画像中央 192・ニュートラル時の足首座標 181.5・184（旧）は使わない。接地する足首の高さ（床 y=360）と踵/足裏の接地は原画のまま。
- 再現: `cd abyss-dive && python tools/gen_suit_walk.py`。同条件で再生成すると md5 一致。倉庫の場所は環境変数 `SUIT_SRC` で変更可。
- コマ順（アトラス）: 0=待機 / 1..8=歩行 / 9,10=歩き出し / 11..14=調査。セル 200×280、アンカーは元絵 (192,363) = セル内 (96,275)。

## 触ると壊れやすいところ
- **当たり判定は `enemyHit()` に集約**。魚の射撃判定は描画寸法に基づく胴体の楕円。弾は `projectileImpact()` が前の座標から現在位置まで調べる。ボスの形を変えたら、描画側（`drawLeviathan` / `drawSquid`）と同じ `prof` / `wig` の式を揃えること。
- **ミサイルの着弾は `missileBlast()` に集約**（`collide()` が `b.kind === 'missile'` で分岐）。直撃の敵は `directEnemy` として周囲ループから外すので**二重加算しない**。`knockEnemy` はボス（`isBoss`）と `hermit` を `stun` ごと弾く。`dead` には触らないので撃破済みは復活しない。演出は `missileBurst()`（`G.flash` は焚かない）。
- **魚雷の誘導は発射時に `pickTorpedoTarget()` で1体だけ決め、`update()` の torp 分岐で `b.target` にだけ弱く寄る**。`lockTarget()` を毎フレーム呼ぶと全弾×全敵の負荷になるので使わない。`a` を動かしたら `vx/vy` を必ず現在速度から作り直して揃える。
- **戦車ヤドカリは海底の高さに固定**。休眠と起動後でスプライトの足元を揃え、当たり判定の中心と半径を変える。砲口の発光と弾の発射位置は同じ基準で調整する。
- **背景と実体のあいだに `drawDepthScrim()` を挟む前提**。背景レイヤーは scrim より先に描く。ヘッドライトは暗幕側と散乱光側で同じ座標を使う。
- **入力は `Input.fireQueued` のラッチ方式**。`Input.wantDash` は `playerUpdate` が**毎フレーム消費する**。`Input.wantDock` は潜航側の `checkDiveEntrance()` が消費し、探索側の `stepExplore` の action とは `explore.update()` が橋渡しする。
- **探索中の射撃は `Input.wantShoot`**（v1.8.0）。`explore.update()` が読んで消費し、`clearInputLatch()` が降艇・帰還で必ず捨てる。keydown は `G.exploreOn` で `wantShoot` と `fireQueued` を切り替えるので、**どちらのモードでも「撃つ」キーが潜航の魚雷を誤発射しない**。
- **撃破した敵は `cull()` で描画前に取り除く**。`update()` の冒頭で必ず呼ぶこと。
- **スマホのボタン座標は `buildUI()`（潜航）と `explore.js` の `actionButton()` / `fireButton()`（探索）**。探索の「撃つ」は `(VW-120, VH-286)`、「調べる／戻る」は `(VW-140, VH-140)` で非重複。増やすときは左66%（移動スティック）と HUD に重ならないか確認。
- **探索の歩行は時間ベース**（v1.8.1）。`explore-rules.js` の `stepExplore` が `dt / WALK_CYCLE_T` で位相を進める。**移動速度・移動距離・スティック量を位相に混ぜないこと**（v1.8.0 の距離ベースに戻すと、速さで歩調が変わってしまう）。接地足が滑るのは承知の上（歩調の安定を優先）。歩幅・踵上げ量は `tools/gen_suit_walk.py`、脚の長さ・足首位置・前後（near=左/far=右）・ストライド中心（CENTER_X=180）は `tools/suitrig.py`。**手前/奥を入れ替えないこと**（入れ替えると交差が逆になる）。
- **ホールド射撃（v1.8.2）**。`Input.fireHeld`（潜航の魚雷）と `Input.shootHeld`（徒歩射撃）が押しっぱなしの保持。**短押しの1発はラッチ（`fireQueued` / `wantShoot`）側**で担保し、ホールドは既存の発射間隔・射撃サイクル・熱/過熱をそのまま使う（間隔や熱を無視する実装にしない）。タッチは押した指ID（`btnTouch[id]==='fire'`）だけが release で解除する（他の指の解放で止めない）。**ミサイルはエッジ（`wantMissile`）のまま**押しっぱなしでも連発しない。解除は `keyup`／`window mouseup`／`touchend・cancel`／`blur`／ポーズ／`clearInputLatch`／`startGame` に漏れなく入れる。
