- **演出**: 深度で暗転（表層〜超深海）、遮蔽レイヤーで背景と手前を分離、爆発・ソナー・コンボ・ボス警告

## 描画と機種目標
- 動画の暗い青緑の水、暖色の2灯、摩耗した鋼板、石造都市、黄色い目と鱗を基準にした。リヴァイアサンは頭と下顎を描き分け、既存の `e.jaw` で開口を動かす。
- iPhone 17 横持ち Safari での 60 fps を目標とする。Canvas は最大 1.5 倍、暗幕は 640×360、光芒と泡は事前描画を再利用。10枚の WebP は計約 877 KiB。
- v1.2.0 は 874×402 CSS px / DPR 3 の Chromium タッチエミュレーションで通常時とボス戦を確認済み。v1.3.0 以降の描画・挙動のプレイ確認と iPhone 17 実機の FPS・発熱の計測はこれから。

## 触ると壊れやすいところ
- **当たり判定は `enemyHit()` に集約**。魚の射撃判定は描画寸法に基づく胴体の楕円。弾は `projectileImpact()` が前の座標から現在位置まで調べる。ボスの形を変えたら、描画側（`drawLeviathan` / `drawSquid`）と同じ `prof` / `wig` の式を揃えること。
- **戦車ヤドカリは海底の高さに固定**。休眠と起動後でスプライトの足元を揃え、当たり判定の中心と半径を変える。砲口の発光と弾の発射位置は同じ基準で調整する。
- **背景と実体のあいだに `drawDepthScrim()` を挟む前提**。背景レイヤーは scrim より先に描く。ヘッドライトは暗幕側と散乱光側で同じ座標を使う
- **入力は `Input.fireQueued` のラッチ方式**。押しっぱなし検知は無い。「押しっぱなしで連射」を足すなら別フラグを用意する
- **スマホのボタン座標は `buildUI()`**。増やすときは左66%（移動スティック）と HUD に重ならないか確認
- **`destroy()` が AudioContext を閉じている**。閉じないと起動のたびに増えて枯渇する
- ハブ側で読み込むのは `js/index.js` のみ。`game.js` は `?v=` を index.js 内で管理
