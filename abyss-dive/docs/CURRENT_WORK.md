# ABYSS DIVE — 現在地

最終更新: 2026-11-21 / v1.2.0（`sw-assets.js` の `version: v4`）

## ひとことで
深海を潜水艇で進む横スクロール・シューティング。ツインヘッドライトの潜水艇で、沈んだ古代都市を抜けながら
巨大深海魚（リヴァイアサン）と巨大イカ（コロッサル・スクイッド）に魚雷とミサイルを撃ちまくる。

## いま入っているもの
- **潜水艇**: 錆びた機体番号09の船体、コックピット、暖色の2灯、青白い排気と浮上する泡
- **武器**: 魚雷（セミオート・熱管理）、ミサイル（弾数制・自動追尾）、ソナー（ダメージ+スタン）、緊急回避（無敵つき加速）
- **敵**: 小魚の群れ / ハンター（突進・赤い輪が予兆） / クラゲ / チョウチンアンコウ（ルアー発光・噛みつき） / 機雷（誘爆） / リヴァイアサン / コロッサル・スクイッド
- **背景**: 沈んだ古代都市（写実寄りの視差背景・倍率0.40）、青い靄の巨大魚（当たり判定なしの演出）、海雪、光条、背景尖塔
- **演出**: 深度で暗転（表層〜超深海）、遮蔽レイヤーで背景と手前を分離、爆発・ソナー・コンボ・ボス警告
- **音**: WebAudioのその場合成（ノイズ+フィルタ、低音ドローン、ボスの地響き、ソナー残響）

## 描画と機種目標
- 動画の暗い青緑の水、暖色の2灯、摩耗した鋼板、石造都市、黄色い目と鱗を基準にした。リヴァイアサンは頭と下顎を描き分け、既存の `e.jaw` で開口を動かす。
- iPhone 17 横持ち Safari での 60 fps を目標とする。Canvas は最大 1.5 倍、暗幕は 640×360、光芒と泡は事前描画を再利用。3枚の WebP は計約 246 KiB。
- 874×402 CSS px / DPR 3 の Chromium タッチエミュレーションで通常時とボス戦を確認。iPhone 17 実機の FPS・発熱は未計測。

## 触ると壊れやすいところ
- **当たり判定は `enemyHit()` に集約**。ボスの形を変えたら、描画側（`drawLeviathan` / `drawSquid`）と同じ `prof` / `wig` の式を揃えること。ずれると「当たらない」「見えないところに当たる」になる
- **背景と実体のあいだに `drawDepthScrim()` を挟む前提**。背景レイヤーは scrim より先に描く。ヘッドライトは暗幕側と散乱光側で同じ座標を使う
- **入力は `Input.fireQueued` のラッチ方式**。押しっぱなし検知は無い。「押しっぱなしで連射」を足すなら別フラグを用意する
- **スマホのボタン座標は `buildUI()`**。増やすときは左66%（移動スティック）と HUD に重ならないか確認
- **`destroy()` が AudioContext を閉じている**。閉じないと起動のたびに増えて枯渇する
- ハブ側で読み込むのは `js/index.js` のみ。`game.js` は `?v=` を index.js 内で管理

## 動作確認の手順
1. リポジトリのルートで `python common/tools/serve.py`（または `python -m http.server 8000`）
2. ブラウザでハブ → ABYSS DIVE カード
3. 確認ポイント: カードが出る（版表示）/ 起動する / 魚雷が押した分だけ飛ぶ / 「撃つ」ボタンで撃てる /
   ボスの胴体に当たる / 背景の靄と手前の敵が見分けられる / 「← もどる」でハブへ戻り、再入場できる
4. `node --test abyss-dive/tests/assets.test.mjs`
5. デバッグ: `window.__abyss`（`state()` / `G` / `Input` / `startGame()` / `errors`）
