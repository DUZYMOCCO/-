## v1.7.0 の確認状況
- **ミサイルの着弾を爽快に強化**（`missileBurst`）。着弾で「白熱した小さい核（短命の光）＋橙の火花＋水中の膨張衝撃波（リング2枚）＋泡」を出し、**画面全体を明るく塗る長いフラッシュは使わない**。画面揺れは +12（上限24）、音は既存 `AU.boom(1.8)` の重い低音。
- **爆心から周囲の普通の敵を距離減衰つきで放射状に吹き飛ばす**（`knockEnemy` / `missileBlast`）。直撃は満額（威力11）、周囲は距離減衰（爆心 1.0〜外周 0.3）。放射速度は 640px/s（距離減衰 0.5〜1.0）、短い `stun`（0.42s）を借りて `vx/vy` で飛ばす。**直撃した敵は周囲ループから外して二重加算を防ぐ**。
- **ボスと海底固定の戦車ヤドカリは吹き飛ばさずダメージのみ**。撃破済みの敵は復活しない（`dead` は触らない）。
- **弾が敵ではなく地形に当たって爆発した場合も周囲効果は一貫**（`missileBlast` は直撃/地形で共通処理、引数 `enemy` が null でも放射ループは同じ）。
- **魚雷に弱い誘導**（`pickTorpedoTarget`）。発射時に前方コーン（±0.42 rad ＝約24°）・射程1000以内の生きた標的を1つだけ選び、角速度 1.1 rad/s（ミサイル 4.2 の約1/4）で寄る。射出方向（PCマウス・タッチ）は尊重し、**背後や射線外へは旋回しない**。`a` と `vx/vy` は常に揃え、標的死亡時は直進。
- **毎フレームの全弾×全敵走査は追加していない**（候補決定は発射時の1回のみ・継続は選択済みの1体だけ）。
- `node --test abyss-dive/tests/*.test.mjs` は **24 件すべて通過**（assets 5 / combat 2 / explore 9 / weapons 8）。変更した JavaScript の構文チェックも通過。
- ブラウザ（Chromium, 横持ち）で魚雷の弱い誘導とミサイルの着弾・吹き飛ばしを実走確認（詳細とスクショは下記「動作確認の手順」の節の実績、および `WORK_REPORT.md`）。iPhone 17 Safari 実機の確認はこれから。

## ひとことで
深海を潜水艇で進む横スクロール・シューティング。ツインヘッドライトの潜水艇で、沈んだ古代都市を抜けながら
巨大深海魚（リヴァイアサン）と巨大イカ（コロッサル・スクイッド）に魚雷とミサイルを撃ちまくる。
序盤に見つかる遺跡の入口では、潜水艇を降りて人間（装甲の探索者）で歩く探索に入れる。

## 徒歩探索（v1.6.0）
- 潜航側の入口: `x=1450, y=430`（半径78）。序盤 x の浅い位置なので、深く潜らず触れられる（ダメージ前提にしない）。
- 入口の近く（距離 ≤ 入口半径+46）でのみ「降艇」を受け付ける。E / Enter / パッドA / 入口近くの「降艇」ボタン。
- 降りると探索マップへ切り替わり、**潜航のシミュレーションは止まる**（敵・弾・時間が進まない）。描画も探索側へ委譲する。
- 探索マップは 1 枚（全長 2600）。歩けるのは x=130〜2470。床は `GROUND_Y=566` の水平 1 本。
- 遺物（調査地点）は 2 つ: `x=1200`「崩れた祭壇」、`x=2010`「沈んだ石碑」。近づいて「調べる」で **1 度だけ** 報酬（1 つ +250 点）。2 度目は「調査済み」表示に変わり報酬は出ない。
- 進捗（`relics` / `surveyed`）は**1 潜航のあいだ保持**される（入口を出入りしても消えない）。`startGame()` でリセット。
- 帰還は入口と同じ場所（`EXIT_X=250`）。近づいて「戻る／潜航へ戻る」で潜航再開。
- **帰還時は予約入力をすべて捨てる**（`clearInputLatch`）。潜水艇は入口の外側 `入口x+168` に置き、その場で再突入しない。
- 歩行アニメは 2 コマ（`suit_walk_0` ↔ `suit_walk_1`、0.18 秒ごと）、停止で `suit_idle`。足元は床に固定。

## 触ると壊れやすいところ
- **当たり判定は `enemyHit()` に集約**。魚の射撃判定は描画寸法に基づく胴体の楕円。弾は `projectileImpact()` が前の座標から現在位置まで調べる。ボスの形を変えたら、描画側（`drawLeviathan` / `drawSquid`）と同じ `prof` / `wig` の式を揃えること。
- **ミサイルの着弾は `missileBlast()` に集約**（`collide()` が `b.kind === 'missile'` で分岐）。直撃の敵は `directEnemy` として周囲ループから外すので**二重加算しない**。周囲は `knockEnemy()` で放射（距離減衰）。**`knockEnemy` はボス（`isBoss`）と `hermit` を `stun` ごと弾く**——ガードを外すとボスや海底固定が飛ぶ。`dead` には触らないので撃破済みは復活しない。演出は `missileBurst()`（`G.flash` は焚かない）。
- **魚雷の誘導は発射時に `pickTorpedoTarget()` で1体だけ決め、`update()` の torp 分岐で `b.target` にだけ弱く寄る**。`lockTarget()` を毎フレーム呼ぶと全弾×全敵の負荷になるので使わない。標的死亡／偏角が `TORP_MAX_OFF` 超なら補正しない。`a` を動かしたら `vx/vy` を必ず現在速度から作り直して揃える。
- **戦車ヤドカリは海底の高さに固定**。休眠と起動後でスプライトの足元を揃え、当たり判定の中心と半径を変える。砲口の発光と弾の発射位置は同じ基準で調整する。
- **背景と実体のあいだに `drawDepthScrim()` を挟む前提**。背景レイヤーは scrim より先に描く。ヘッドライトは暗幕側と散乱光側で同じ座標を使う
- **入力は `Input.fireQueued` のラッチ方式**。押しっぱなし検知は無い。`Input.wantDash` は `playerUpdate` が**毎フレーム消費する**（消費しないとクールダウンごとに連続発動する）。
- **撃破した敵は `cull()` で描画前に取り除く**。`update()` の冒頭で必ず呼ぶこと（呼ばないと撃破済みが残って見分けられない）。
- **スマホのボタン座標は `buildUI()`**。増やすときは左66%（移動スティック）と HUD に重ならないか確認。入口の「降艇」ボタンは `DOCK_BTN`（右中央、潜航のボタンとは非重複）。
- **`destroy()` が AudioContext を閉じている**。閉じないと起動のたびに増えて枯渇する
- ハブ側で読み込むのは `js/index.js` のみ。`game.js` は `?v=` を index.js 内で管理
- **探索は潜航と別モジュール**。潜航の `update()`/`render()` には探索の分岐を 1 つ入れただけ。探索中は潜航を描かないため、潜航側の描画関数を触らずに済む。共通なのは `Input`（スティック・キー）と `ctx`/`view` だけ。
- **`Input.stick` は潜航と探索で共用**。`touchStart` は探索中 `explore.touchStart` に分岐。`touchMove`/`touchEnd` は共通のまま使う。
