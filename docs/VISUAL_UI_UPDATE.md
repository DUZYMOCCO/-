# IRON SQUAD ビジュアル・UI更新

2026-10-06 / v1.10.0 / Service Worker: mobile-game-studio-v29

## 変更

- IRON SQUAD専用構成に変更。NEON BOUNCE / CYBER SLASHの現行ソース、登録、キャッシュを撤去。旧ソースはGit履歴から復元可能。
- 兵士8職種の描画を `js/games/iron-squad/visuals.js` へ分離。顔、兜、布、装甲、盾、弓、杖、上位職の外形と装備色を表現。名簿にも肖像を追加。
- 通常モブ5種の描画を更新。大ボスと通常ボスは従来の描画を使用。
- 本陣の石畳と街道の轍を地形キャッシュに追加。景観オブジェクトと兵士・敵を同じY座標順で描画し、木に隠れる味方の周囲は樹冠を透過。
- 通常兵の名前は戦場で常時表示せず、叙勲兵・上位職・直属兵・天才の名前と、負傷兵のHPを優先表示。パーティクル追加なし。兵士の多重発光リングを撤去。
- 会議を「状況」「兵士・援助」「装備・強化」に分割。見出し・タブ・閉じる・戦場復帰は固定、本文だけスクロール。名簿とバッグの内側にあったスクロール枠を撤去。
- 会議を `touch-action: none` の戦場Canvas領域から外へ移動。会議中は背景の操作を無効化し、戦場入力も停止。Escapeとキーボードのフォーカス循環に対応。
- 軍令を左、ミニマップを右へ分離。会議はHUDより上、討死画面は会議より上。開いた会議を討死時に閉じる。
- 専用スタイルを `css/iron-squad.css` に追加。ヘッダーを狭い画面でも読める2段配置に変更。ボタンの発光や色を抑制。
- ゲーム終了時にジョイスティックのグローバルイベントを解除し、再入場時に古い入力処理が残る問題を修正。

## 原因を確認したUI問題

1. 軍令とミニマップが右上で重なる配置。
2. 軍令・作戦通知のz-indexが会議のz-indexより高い。
3. 会議がスクロール禁止のCanvasコンテナ内にあるため、子要素だけpan-yにしてもスマホのスクロールが妨げられる。
4. 固定高の名簿・バッグと会議全体のスクロールが入れ子になり、狭い画面で操作しにくい。

## 検証

- JavaScript構文チェック成功（メインモジュール・描画モジュール）。
- Service Workerの全事前キャッシュ対象が実在することを確認。
- ローカルHTTPサーバー上でIRON SQUADのみが一覧に表示され、ゲームを起動できることを確認。

- 長い兵士名簿を最下部までスクロール（scrollTopと最大値が一致）。その状態で閉じる・戦場復帰が前面にあり、装備タブへ切り替え可能。
- 会議の閉じる、再度開く、選択タブの保持、戦場復帰を確認。討死画面と再入隊も確認。
- 8職種、通常敵5種、大ボス3種を描画検証ページで確認。ブラウザの警告・エラーなし。
