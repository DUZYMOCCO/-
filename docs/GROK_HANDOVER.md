## 1. プロジェクト概要 & 技術スタック

### 1.1 プロジェクト方針
- **「自分のiPhoneで快適・爽快に遊ぶことだけを追求した個人専用ゲーム工房」**
- PWA（Progressive Web App）仕様。iPhone Safariの「ホーム画面に追加」でアドレスバーや下部タブなしの全画面ネイティブアプリ同等で稼働。
- 外部ライブラリ（React, Vue, Phaser, Pixi等）を一切使わず、**Vanilla HTML5 / Modern ES Modules / Canvas 2D / Web Audio API** のピュアWeb技術のみで構築（超軽量・高速60fps・完全制御可能）。

## 2. 直近の完了作業報告（現在地までの到達点）

### ① クールタイム制パワーアタック（渾身強撃 💥 / 覇王烈風絶神斬 ⚡）[v1.20.4]
- **操作系**: バーチャルゲームパッド右側アクションゾーンに中型ボタン `#btn-pad-power`（強撃 💥）を新設。
  - 左から「📢呼集」「💥強撃」「🗡️攻撃」と並び、親指の円弧軌道で直感タップ可能。
- **クールタイム（8.0秒）**: ボタン上に暗転オーバーレイとリアルタイム秒数（`7.5s`）のカウントダウン表示。完了時は黄金パルス発光で通知。
- **スキル性能**:
  - 通常職: 『💥【渾身剛力波】』周囲165px全方位へATK 3.8倍ダメージ（確定クリティカル）＋65pxノックバック＋1.0秒スタン＋砦大打撃。
  - 覇王ウォーロード時: 『⚡【覇王烈風絶神斬】』周囲230px超広範囲へATK 5.2倍ダメージ＋95pxノックバック＋1.6秒スタン。ボタン表示も「⚡絶神斬」に進化。
- **演出**: Canvas上に急速拡大する二重ショックウェーブリング（波紋描画）、40個の爆風パーティクル、画面強シェイク、重低音効果音。
- **PC操作**: キーボードの `Space` / `E` / `K` キーでも発動可能（`J` / `F` で手動攻撃）。

### ② 本陣強襲防衛戦イベント（Base Camp Raid Event）[v1.20.3]
- **発生**: 第2期以降、作戦中盤（残り時間55%以下）に魔境の強襲軍団14体（ブラッドオーク司令官、凶狼、飛竜）が本陣へ一斉侵攻。

- **勝敗**: 45秒以内に防衛失敗（またはフェーズ終了）すると本隊兵士の約35%が負傷ダウン。防衛成功時は大金（+650〜1000G+）、大量EXP、本陣中央に「防衛の至宝箱（Bossドロップ2個）」が出現し、本隊HP全快。

### ③ 100ウェーブ出世曲線 ＆ 装備の無限強化 [v1.20.3]
- **出世曲線**: 最高階級「救国の英雄神将」到達を約100作戦期（150,000 EXP）へスケーリング。
- **無限強化**: +30上限および祠制限を完全撤廃（`Infinity`）。二次曲線コスト（`20 + up * 18 + up^1.4 * 6`）により、+50（約1,600G）、+100（約3,500G）、+200（約13,000G）と現実的にどこまでも鍛錬可能。

### ④ 出撃リミット72名体制 ＆ 直属小隊12名 / 本隊迷い込み防止AI [v1.20.2]
- **大軍勢リアリズム**: 最大出撃枠72名。主人公の直属小隊（常時随行）は階級に応じて最大12名、背後に約60名の大軍団（本隊）。

## 4. grokが開発・編集する際の最重要開発ルール

grokが作業を引き継いでコードを編集する際は、以下の約束事を厳格に遵守してください：

### ⚠️ ルール1: スタック・ブラケット整合性の絶対遵守
- `js/games/iron-squad/index.js` は約 7,880行 の単一巨大モジュールです。
- メソッド追加・編集時に閉じ括弧 `}` の過不足が発生するとゲーム全体がロード不能になります。
- 編集後は必ず括弧の一致（スタック検証）を確認すること。

### ⚠️ ルール2: キャッシュバスターの同時更新（PWA対応）
- JS / CSS を更新した際は、iPhone Safariで即座に反映されるよう、以下を必ずセットで更新すること：
  1. `sw.js`: `CACHE_NAME = 'mobile-game-studio-vXX'`（数値を+1）
  2. `index.html`: `iron-squad.css?v=XX`, `game-ui.css?v=XX`, `app.js?v=XX`, フッター表記 `v1.20.X`

### ⚠️ ルール3: 画面遮蔽を避ける（iPhone縦画面の視界保護）
- 戦場Canvas上に巨大な固定UIや常時重なるピルバッジを配置しないこと。
- 通知テロップは画面中央を避け、下部の `battle-log-window` またはスマートなヘッダー統合を活用すること。

### ⚠️ ルール4: 60fps負荷管理（オブジェクト・メモリ）
- 毎フレームの `render()` や `update(dt)` 内で新しいオブジェクト（`{}`）や配列（`[]`）を大量に生成しないこと（GC詰まり防止）。
