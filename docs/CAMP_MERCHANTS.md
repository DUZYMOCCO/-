# キャンプの商人と護衛（2026-10-07 / v1.27.14）

## 民間人の姿・救出の永続報酬

- 子供・女性・老人も人物として描画。子供は小さな体格、女性は旅装と髪型、老人は白髪・ひげ・杖・少し前傾した姿で区別。顔と服はIDから決まり、搬送中も保持する。[見本](previews/civilians.png)。
- 5種のNPC（子供・女性・老人・商人・護衛）の救出報酬を、隊長の永続ステータス強化へ変更。NPC救出の旧ゴールド・経験値・士気報酬は置き換える。軍の兵士の救助報酬は既存どおり。
- 抽選は最大HP+5が35%、攻撃+1が30%、防御+1が20%、移動+1が10%、大当たりの攻撃速度+1%が5%。攻撃速度は装備・クラス分を含む基準値へ累計割合を乗算し、再計算で重複加算しない。
- 同じ人物から1回だけ受領。受領IDを保存し、NPCの再ダウン・再生成・死亡後の再入隊でも重複報酬を防ぐ。別の人物は新たな抽選対象。
- 永続強化は選択したセーブに属し、装備変更・再開・そのセーブの再入隊でも維持。新しい別の遠征は初期値から始める。司令部の隊長成長欄に累計を表示する。

## 商人本人と救助後の本陣滞在

- 露店の横に商人本人を描画。個別の顔・帽子・旅装・肩掛け鞄を使用。露店にも幌の縞・荷物・木組み・車輪を追加。
- 商人・護衛ともHP0で即死せず、45秒の救助猶予を持つダウン状態にする。本陣での猶予減少や衛生兵の処置は既存の負傷者と同じ。
- 近づくと紐で搬送できる。兵士・民間人・商人・護衛で既存の搬送定員を共有し、搬送中は現地の死亡猶予が止まる。紐・残り秒数・画面端の救助方向・ミニマップの負傷マーカーにも反映。
- 商人・護衛の搬送先は本陣。一般兵の自動搬送も、本陣まで運ぶ。制圧拠点にNPCを運んで立ち止まり続けることを防ぐ。
- 本陣に到着すると復活して、そのまま滞在。商人は営業を再開し、護衛は本陣周辺を守る。元のキャンプへは戻らない。
- 本陣内では救助した順に別々の待機場所へ落ち着く。商人が同じ座標に重なり、後から救助した店を開けなくなることを防ぐ。待機場所も保存する。
- 衛生兵が現地で復活させたNPCは自分で本陣へ避難し、その後本陣に留まる。
- 負傷・残り猶予・搬送者・救助後の滞在位置・避難中の状態・護衛のHPも保存。救助した商人の商品の距離帯は元の土地のまま維持する。回復サービスの利用済み状態も維持。
- 救助のお礼は上記の永続強化を使用する。救助猶予を過ぎれば死亡し、商人の再訪は既存仕様を使用する。
- 搬送状態の点検で定員ちょうどの最後の1人が外れていた比較を修正し、1人・2人の定員まで保持する。

## 護衛の外見

- 行商護衛の円を人物に変更。兵士と共通の兜・甲冑・顔・腕・足・歩行・攻撃を使用。
- 2名を槍兵と斧兵として描き分ける。斧は両手で柄を持ち、振り下ろす。外見は商人と護衛のIDに基づき、再開しても同じ人物。
- 表示装備 `displayEquipment` は描画用。戦闘武器は槍／鎚（斧の見た目）として設定し、攻撃熟練と撃破経験を獲得する。レベル・撃破武勲・被弾HP鍛錬・戦闘参加したウェーブの経験で成長する。
- 護衛の基礎能力は元の土地の強さを保持し、一般兵の計算式へ置き換えて弱くならないようにする。護衛の成長・基礎値・熟練・HPを保存。足元にレベルも表示する。
- 商人と護衛を地形・敵・味方と同じ奥行き順で描画。商人本体が画面外でも、追撃中の護衛が画面内なら表示する。
- 足元の小さな「護衛・槍」「護衛・斧」表示にして、露店の名前と重なりにくくする。
- [描画見本](previews/merchant-guards.png)。`node tools/preview-merchant-guards.mjs` で生成。実機のスクリーンショットではない。

## 各地のキャンプへの配置

- `WorldTerrain` が元々生成していた野営テントの場所をキャンプとして使う。景観の位置や生成乱数は変えない。
- 各キャンプの55%に商人を配置。本陣と宿場の既存商人も保持。
- 新しい遠征ごとに配置用の乱数種 `merchantCampSeed` を作り、キャンプのIDから配置を判定。同じセーブでは出入り・地形キャッシュの削除・再開で配置を引き直さない。
- 表示された周辺キャンプを発見して配置する。巨大な世界全体のキャンプや商人を最初に生成しない。
- 発見した商人の場所・死亡状態・回復利用済み状態を保存。未発見のキャンプも保存した乱数種で同じ配置になる。
- 遠い商人は、近くに隊長・カメラ・敵がいない間、護衛AIを休止。死亡した商人の再訪時間は既存どおり進める。

## 回復サービス

- 商人の「品定め」画面の先頭に、**隊長のHPを全回復／150G** のボタンを表示。
- 使用したウェーブから2ウェーブ進むと再利用可能。第N期に使えば第N+2期で再開する。別の商人は別枠。販売欄に「あと2ウェーブ／あと1ウェーブ」を表示し、開いたままでも期終了後に更新する。
- HP満タン・150G未満・商人死亡・隊長死亡・離れすぎの場合は利用不可。料金と回数は消費しない。
- 宿場に入っている間はその宿場の商人を利用可能。それ以外は会話できる距離内で使用する。
- 兵士の回復や復活は含まない。成功時にHP・軍資金・再開期をまとめて更新し、その場で保存。商品更新・救助・商人の再訪で待ち時間を短縮しない。
- 旧版の使用済みサービスは読み込んだ期+2から利用可能にする。元々未使用ならすぐ利用可能。
