# 石造りの壁と町の救護受付／出口（v2.6.1 / SW v109）

## 城壁

従来は12pxの灰色の線だけで、地面の境界・道と見分けにくかった。本陣と町の壁に石積み・目地・明暗の異なる石・上面・胸壁・影・隅塔を追加。門には門柱と旗を置き、敷石の通路と双方向印、門名と「通路／外へ」を表示した。町の北門表示は内側に配置。

衝突線・160mの開口幅・AI迂回・防衛能力は変更していない。国家の発展Lv3以上は明るい石材。石柄は座標から固定生成し、ゲーム用乱数を消費しない。画面外を省略し、追加の描画キャッシュや派手な効果は設けていない。

描画見本：[本陣](previews/stone-headquarters.png)、[町の北門](previews/stone-town-north.png)。これらはNative Canvasの建造物見本で、スマホ実機のスクリーンショットではない。

## 民間人が町の救護受付で受け入れられなかった原因と修正

1. 民間人の届け先一覧が野外の本陣・町入口・救護所だけで、町内の受付を参照していなかった。
2. 町入口の受付は半径70m。町の入場ボタンが使える位置から38m後方に引かれる対象は、入場直前の受付範囲から外れることがあった。
3. 町入場後に対象が隊長について町内座標へ動いても、野外の施設を検索し続けていた。

町入場時には隊長の搬送対象を受け入れ、町内では搬送者の座標空間を使って受付を判定。すでに町内にいる搬送対象も受付まで運ぶと完了する。町内で紐を外した民間人は所属空間を保持し、再接続できる。町内のセーブは対象も野外入口の座標へコピーして記録し、ライブ状態は変更しない。町を出る場合も対象を野外へ移す。

兵士の復活、NPCの本陣への安全移送、個人ごとの永続報酬の一度だけの付与、町の門番の2ウェーブ後補充を維持。

## 出口の視界とHUD

- 商人の案内を上部中央から、操作ボタン上の一行へ移動。ボタンは横に確保し、長い名前は省略表示。ボタンの文言は「取引と回復」。詳細はその画面で確認する。
- 町では上部の野外・昼夜・魔力・弾薬情報を非表示にし、門と周辺地形を見えるようにする。隊長HP・作戦残り時間・部隊人数・ミニマップは表示を維持。
- 従来は通常戦闘ループの静かな移動中にHUDの定期更新がなく、町でも野外情報が残っていた。既存の450ms間隔で更新し、町への入退場では即時更新する。
