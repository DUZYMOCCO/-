# 広域フィールド・ニューゲーム・セーブ選択（v1.11履歴）

2026-10-06 / v1.11.0 / Service Worker: mobile-game-studio-v30

現行v1.12の経験ルール・120秒サイクル・予備兵・旧セーブ整理は [PHASE_AND_COMMANDER_UPDATE.md](PHASE_AND_COMMANDER_UPDATE.md) を参照。以下はv1.11時点の記録。

## フィールド

- 1,800×1,800から10,800×10,800へ拡大。縦横6倍、面積36倍。
- 本陣は新マップ中央の(5,400, 5,400)。危険度の境界は本陣から1,200 / 2,700 / 4,400。
- 草原、深い森、遺跡と枯れ野、最果ての岩山を配置。街道、池、遺跡、野営設備、樹木、岩を地形ごとに生成。
- 全体を巨大なCanvasに描かず、512px単位の地形を可視範囲で生成。キャッシュは最大48枚。破棄した地形も同じ座標なら同じ景観に復元。
- 拠点は4種類×3層の12か所へ拡張。軍令は個々の拠点IDに紐付け、近い未制圧拠点を優先。
- 敵は遠征隊周辺に補充。離れた地域の敵は行動を休止し、広域化で画面外の大ボス演出が常時発生することを防止。
- HUDの「地図」で本陣・現在地・拠点・大ボス・現在の表示範囲を確認。地図表示中はゲームを停止。

## 開始と保存

- 起動時は自動出撃せず、「遠征を選ぶ」画面を表示。
- 「ニューゲーム」は新しいセーブを作成し、第1期・4職種の新兵20名・50Gから開始。既存セーブの兵士や先輩は持ち込まない。
- 遠征名を付けられる。既存セーブは名前、作戦期、レベル、軍資金、生存人数、保存日時を表示して選択。
- 自動保存はプレイ中10秒ごと、作戦期完了、会議を開く際、装備等の変更、工房へ戻る際、ブラウザが非表示になる際。
- 選んだ遠征だけを更新。主人公の位置、兵士、所持品、進行、期内の損耗数、拠点の制圧状況を保存。
- 会議の「ニューゲーム・セーブ選択」で現在の遠征を保存して選択画面へ戻れる。
- 討死はその遠征だけの状態として記録。再入隊時に、その遠征の生存兵士を先輩として引き継ぐ。別のニューゲームや他のセーブには混ぜない。
- 保存容量不足等の失敗は画面で通知。失敗した書き込みで以前の記録を消さない。

## 旧セーブの移行

- 保存キー `game_studio_ironsquad_save_slots_v1` に複数遠征を保存。
- 初回に旧 `game_studio_ironsquad_save_data_v3` を「これまでの遠征」として取り込む。旧キー自体は変更・削除しない。
- 旧中断セーブがなく先輩バックアップだけがある場合は「これまでの生存部隊」として取り込む。
- 小さいマップの兵士座標は新本陣からの相対位置へ一度だけ移行。主人公は新本陣から再開し、旧4拠点の制圧状態は対応する内側の拠点へ移行。
- 広域版で保存した記録は、そのままの位置と12拠点を復元。
- 保存先は遊んでいるブラウザ内。PC・iPhone間の同期や、異なるURL間の自動移行は実装していない。

## 検証

`node tests/state-world.test.mjs` 成功。ユーザーの保存領域を使わないテストで以下を確認：

- 旧セーブの一度だけの移行と旧キーの保持。
- 複数遠征の分離、読み出したオブジェクトによる保存内容の意図しない変更防止。
- 書き込み失敗時の既存データ保持。
- 旧兵士座標・制圧状況の移行、ゼロGの復元。
- ニューゲームの作戦期・タイマー・兵士・制圧状況のリセット。新兵が4職種揃うこと（旧処理の番号二重加算も修正）。
- 広域版の位置・期・残時間・損耗数の復元。
- 12拠点がマップ内に収まること。
- 地形キャッシュの上限と、破棄後の再生成が同一であること。

ブラウザでは旧遠征の再開、新規遠征2件の作成、セーブ一覧の共存、プレイ中の選択画面への復帰、地図の開閉を確認。
390×844、320×568、844×390で表示を確認し、横のはみ出しなし。
実際のCanvasで4地域を描画し、多数の地域を巡回してもキャッシュが48枚に収まることを確認。警告・エラーなし。
