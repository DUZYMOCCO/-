## 2026-10-06 72名大軍勢・直属小隊12名制・本隊迷い込み防止テリトリーAI・境界敵10倍スケーリング (v1.20.2)

ユーザーからの要望「ペナルティはいらない。境界超えると敵の強さが10倍くらいにしとけば大丈夫。ただ本隊が迷い込むと全滅しそう。あと主人公のレベルが上がると小隊が本隊を超えててなんか変かな。主人公の小隊は12名くらいまで。本体は50くらいいてもいい。72くらいが出撃リミットかな」に対応。

1. **出撃リミット72名体制 ＆ 直属小隊最大12名 / 本隊約60名 (`DEPLOYMENT_CAPACITY = 72`)**:
   - 最大出撃枠を30名から **72名** へ大幅拡張。
   - 主人公の直属小隊（`personalGuards`）は階級に応じて最大 **12名**（救国の英雄神将）。
   - 本隊（軍団残存兵）は常に **約60名（50〜72名）** の大軍勢として機能。
   - これにより「主人公の小隊が本隊を超えてしまう不自然さ」が完全解消され、「背後に約60名の大軍団を従えつつ、自身は直属精鋭小隊12名を率いて遠征する」という壮大な軍団リアリズムが成立。
   - 既存セーブ再開時も `loadGame` で即座に72名まで新兵が自動補充。

2. **本隊迷い込み防止テリトリーAI (`BASE_TERRITORY_RADIUS = 2200`)**:
   - 本隊（第1小隊・第2小隊・第3小隊）の自律作戦エリアを **「本陣防衛圏（安全エリア: 半径2,200m以内）」** に厳格限定。
   - 第1小隊（突撃）および第2小隊（遊撃）が索敵・進軍する砦、宝箱、敵モンスターを「本陣から2,200m以内のもの」のみにフィルタ。
   - 小隊重心および本隊兵士が安全圏から外へ飛び出さないようクランプ。
   - これにより、主人公が遠くの魔境や最果て、ダンジョンへ遠征していても、本隊約60名は安全な本拠地を盤石に防衛・哨戒し続け、奥地の凶悪モンスター群に迷い込んで全滅する心配が完全に解消。

3. **境界を越えると敵の強さが10倍にジャンプ (`KNOTS`, `spawnMonster`)**:
   - DEF無効化や被ダメ4.5倍などの不自然なペナルティシステム（`deadlyPenetration`）を完全撤廃。
   - 代わりに、ゾーン境界（2,400m, 5,500m, 9,200m）を跨いだ瞬間に敵の強さ（HP/ATK）が約7〜10倍ずつ跳ね上がる階段状スケーリングを実装:
     - **本陣防衛圏 (0〜2,400m)**: 敵HP 45〜75, ATK 10〜17（初心者・本隊防衛用）
     - **警戒辺境 (2,400〜5,500m)**: 敵HP 450〜1,000, ATK 90〜180（前ゾーンの約8〜10倍）
     - **魔境深部 (5,500〜9,200m)**: 敵HP 3,500〜12,000, ATK 500〜1,100（前ゾーンの約7〜10倍）
     - **最果ての死地 (9,200m〜)**: 敵HP 28,000〜67,000, ATK 2,200〜4,300（前ゾーンの約6〜10倍）
     - **四隅の超巨大古竜・巨獣王ボス**: HP 58,000〜75,000, ATK 1,250〜1,450（神話決戦）
   - これにより、ペナルティではなく純粋な敵の圧倒的破壊力によって、適正防具のない状態で境界を越えた瞬間に消し飛ぶ本物の死の緊張感を実現。

4. **UI・ダメージ計算の健全化**:
   - `damageTarget` を通常アーマー減衰計算に一本化（不要な赤警告文字を撤廃）。
   - ゾーンバッジをすっきりとした洗練されたデザイン（`[アイコン] [ゾーン名] (推奨DEF XX+)`）に戻す。

## 2026-10-06 HPインフレ是正 ＆ 推奨DEF即死貫通の超強化 (v1.20.1)

ユーザーのフィードバック「HPが5000とか余裕で超えてるのがいたから、今の推奨DEFの領域だとあっというまに端まで行けちゃう」に対応。

1. **HP過剰インフレの抑制 (`equipment-rules.js`, `index.js`)**:
   - 防具強化ステータス計算（`applyUpgradeStats`）において、HP倍率がTier補正乗算により数千〜1万以上に爆発していた問題を是正。
   - `Math.pow(tier, 1.3)` カーブへ引き締め、全身最高峰防具でもHP増加を現実的な範囲（+800〜1,500程度）に制御。
   - 既存セーブデータ再開時にも `recalcSoldierStats`, `recalcPlayerStats` により安全に適正ステータスへと自動再計算。

2. **敵攻撃力の急激な上昇 (`spawnMonster`, `KNOTS`)**:
   - 奥地・最果てにおける敵モンスターの基礎ATKを大幅引き上げ:
     - 近郊平原: ATK 10〜14 (HP 45〜60)
     - 警戒森林: ATK 22〜34 (HP 90〜150)
     - 魔境深部: ATK 48〜95 (HP 220〜680)
     - 最果ての死地: ATK 130〜180 (HP 520〜780)
   - `KNOTS` の距離スケーリング係数を奥地で最大 24.0倍 まで強化。最果てのドラゴンやワイバーンの攻撃力は数千ATKに到達。

3. **推奨DEF不足時の即死ペナルティ強化 (`damageTarget`)**:
   - 各ゾーンの推奨DEF引き上げ:
     - 警戒辺境: 25 ➔ 45
     - 魔境深部: 75 ➔ 140
     - 最果ての死地: 150 ➔ 320
   - ダンジョン推奨DEF引き上げ:
     - 廃坑: 30 ➔ 60 (ボスATK: 48 ➔ 75)
     - カタコンベ: 85 ➔ 180 (ボスATK: 92 ➔ 160)
     - 竜巌窟: 160 ➔ 380 (ボスATK: 175 ➔ 360)
   - **ペナルティのダブル化**:
     - 推奨DEF不足時は、不足度に応じて **DEFを最大90%無効化（素通り）**。
     - さらに被ダメージが **1.6〜4.5倍（💀致命貫通即死!）** へ激増。
     - これにより、防具を鍛えずに上位ゾーンへ足を踏み入れた場合、HPが5,000あろうが一撃で消し飛ぶ本物の死の緊張感を実現。
   - **HUD警告表示の強化 (`updateStatsUI`)**:
     - 現在地が推奨DEF不足の場合、画面上部のゾーンバッジが赤く点滅し「💀 [ゾーン名] (⚠️DEF不足即死！ DEF XX/YY+)」と明瞭に警告。

### 1.1 プロジェクト方針
- **「自分のiPhoneで快適・爽快に遊ぶことだけを追求した個人専用ゲーム工房」**

## 2. IRON SQUAD（雑兵立身出世録）ゲームデザイン & コアシステム

### 2.1 ゲームコンセプト
> **「兵士はカジュアルに使い捨てられ、過酷な死線を越えた者だけが英雄覚醒する。」**  
> **「本陣から外へ出るほど世界は地獄と化し、最果てには神話の超巨大ボスが君臨する。」**  
> **「戦闘はノンストップでシームレスに進行し、プレイヤーは指揮官として部隊を率いて戦火を生き抜く。」**

---

### 2.2 兵士の能力値・才能システム (Talent System)
すべての兵士は生成時にランダムな才能素質が決定される。才能格差は激しく、大半は凡庸だが稀に天才が混ざる。

| 才能ランク | 確率 | 初期ステータス補正 | レベルアップ成長率補正 | 特徴 |
| :--- | :--- | :--- | :--- | :--- |
| **天才 (GENIUS)** | 約 2% | +35% 〜 +50% | +50% (1.5倍成長) | 黄金のオーラ。生き残らせる価値が極めて高い |
| **秀才 (GIFTED)** | 約 12% | +15% 〜 +25% | +25% (1.25倍成長) | 紫色のオーラ。部隊の主力を担う逸材 |
| **凡庸 (AVERAGE)**| 約 68% | ±0% | 1.0倍 (標準) | 一般兵。戦死と補充を繰り返す |
| **劣等 (POOR)**   | 約 18% | -10% 〜 -20% | 0.8倍 (低成長) | 才能のない兵士。しかし死線を越えれば化ける |

---

### 2.3 死線覚醒スキルシステム (Deathline Awakening)
部隊が全滅の危機（部隊損耗率30%以上）に瀕した極限の死線を潜り抜けた時、生き残った兵士は「死線覚醒スキル」に目覚める。
**【重要設計ルール】**:
後半インフレで腐らないよう、**すべての補正はパーセンテージ（％）または特殊挙動で付与**される。

| スキルID | スキル名 | 効果内容（すべて％スケーリング） |
| :--- | :--- | :--- |
| `undying_will` | **不屈の生存本能** | 最大HP **+30%**、致死ダメージを受けた際にHP1で耐える（クールダウン制） |
| `bloody_berserk` | **血戦の狂熱** | 自身の残りHPが減るほどATK最大 **+45%** 上昇 |
| `vampire_touch` | **死線吸血** | 与えた全ダメージの **15%** を自身のHPとして吸収 |
| `iron_aegis` | **死線防壁** | 被ダメージ常時 **-25%** 軽減、ノックバック無効 |
| `deadly_eye` | **死線看破** | クリティカル率 **+20%**、クリティカルダメージ倍率 **+50%** |
| `phantom_step` | **疾風の身のこなし** | 回避率 **+20%**、移動速度 **+25%** |
| `divine_grace` | **奇跡の生還** | 3秒ごとに自身の最大HPの **5%** を自動継続回復 |

---

### 2.4 クラスアップ（上位職への覚醒）
各下位基本職は、ボス討伐ドロップの希少アイテム**「覚醒の英雄宝珠（AWAKENING ORB）」**を消費して世界が変わるレベルの上位職へクラスアップできる。主人公も同様に【覇王（WARLORD）】へ覚醒可能。

| 基本職 | ➔ | 上位職 | 上位職の固有能力・特徴 |
| :--- | :--- | :--- | :--- |
| **戦士 (WARRIOR)** | ➔ | **剣聖 (BLADEMASTER)** | 通常攻撃時に前方を薙ぎ払う貫通衝撃波「疾風真空刃」を射出。25%で敵攻撃を完全パリィ |
| **重装兵 (HEAVY)** | ➔ | **聖騎士 (PALADIN)** | 自身と周囲兵士に常時「神聖防壁（被ダメ-35%）」を展開。周囲の味方への攻撃を身代わりブロック |
| **弓兵 (ARCHER)** | ➔ | **神射手 (SNIPER)** | 超長射程（340px）から着弾時に周囲の敵を巻き込む「天星光矢」を連射。クリティカル率激高 |

| **主人公 (COMMANDER)** | ➔ | **覇王 (WARLORD)** | 自身を中心とした全兵士に常時「覇王の軍威（ATK+25% オーラ）」付与。自身の攻撃が特大回転斬撃化 |

### 2.5 資金援助 & 装備譲渡システム (Support & Transfer)
プレイヤー指揮官が保有するゴールドや強力なハクスラ装備を、任意の兵士に手渡しできる。
- **まとめ渡しUI**:
  - `+1万G` / `+10万G` / `全額(MAX)` ボタンで瞬時に軍資金を供給可能。
  - 兵士に「部隊全員に均等分配」する一括援助機能も完備。
- **兵士の自律装備強化（AI投資）**:
  - 資金援助された兵士は、所持ゴールドを使って自らの装備品（武器・防具・装飾品）を自動で限界までカンカン叩いて強化（+1, +2...）する。
- **装備譲渡**:
  - プレイヤーのインベントリ内の任意の装備（または身に付けている神器）を兵士に渡すと、兵士は旧装備の強化値を自動継承しつつ即座に換装。

### 2.8 シームレス作戦期（Phase制）
旧ウェーブ制の「全滅による強制中断・リザルトモーダル」を完全撤廃。
- **75秒カウントダウン**: 戦闘がノンストップでシームレスに流れる。
- **期末判定（75秒経過時）**:
  1. 部隊損耗率をチェック。30%以上の過酷な死線を潜り抜けた場合、生存兵士全員に「死線覚醒スキル」を付与。
  2. 生存兵士が手持ち資金で負傷を自費治療し、装備を自費強化。
  3. 本陣に新兵補充隊が合流（自動で最大隊員数まで補充）。
  4. プレイヤーへ作戦給与を支給。
- **戦略会議**: 画面上部バナーまたは本陣内で、プレイヤーが任意の安全なタイミングで開閉可能。
