## 依頼

世界を広げる。細長い地形や崖を、3D ではなく読める形で置く。ダンジョン、廃墟、町を足し、必要なら別インスタンスにする。造形も上げる。細かいところは任され、通しで終える。

追加の舵取り: 21,600px の拡大前でも端まで約30秒、2倍でも約1分。だから広げる方向に取る。

戦闘の数値とルールは、場所を置くために必要な出現位置以外はいじらない。生きた装備色と、埃を被った生存の色は残す。明るい色は武器、敵の目、倒れた者の出来事に置く。

全体地図は道、崖、宿場、廃墟、ダンジョンを描く。158,720px を小さいキャンバスに縮めると近場は潰れる。タップは近い印を選び、実用の移動はリスト。

## 確認したこと

Node はこの機械の PATH にない。`tests/state-world.test.mjs` の広さ・版・ゾーン・宿場数・崖の唇と壁・タイル再生成の断言は書き換えたが、Node では実行していない。同じ断言を headless Edge でモジュールとして実行した。

通ったもの:

- サイズ 158,720、WORLD_VERSION 4
- 中心が本陣、+6,000 が魔境、+10,000 が死地
- 南断崖の唇 `#6e7264`、壁 `#1a1e1c`
- 宿場 4、廃墟 4、宿場にボスなし
- 廃坑のボス名は「採掘暴君・ゴブリンキング」のまま
- 入口はすべて地図の内側
- 地形キャッシュ 48、タイル (2,3) の再生成は同一
- 十字路のタイルに家と井戸がある
- 端までの秒数 481.0

落ち影の色を、断崖の南 80px で読もうとして `null` になった。落ち影の帯は 46–64px なので、80px は帯の外で、`null` が正しい。唇と壁は同じ断崖でブラウザが色を返した。影はその次の分岐で `#0e100e` を返す。

括弧の対応は、今回コードを足す前の検査で `index.js`、`world.js`、`dungeon.js`、`visuals.js`、`casualty-rules.js` が一致していた。今回の出荷前に変えたゲームコードは、北関の宿場の説明文だけ（「灰の長征路」は距離 14,000 の岩山なので、「北の街道」に直した）。キャッシュ名は v53 のまま。この版はまだ端末へ反映していない。
