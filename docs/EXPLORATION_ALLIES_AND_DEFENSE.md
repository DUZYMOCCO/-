# 敵の射撃・防御展開・探索加入 — v4.1.0 / SW138

## 敵と重装兵

通常の野外・ダンジョンの敵に約28%の割合で射撃役を混ぜる。ボス、巨頭、昼夜限定の固有敵は元の仕様を使う。HP・攻撃・戦利品は既存の距離・期・地域の計算を保持。

|敵|攻撃|
|---|---|
|ゴブリン弓兵|物理の矢|
|山賊石弓兵|物理の石弓弾|
|火炎小鬼|炎属性・小範囲|
|氷霊|氷属性|
|雷精|雷属性|
|黒衣の魔術師|魔法・小範囲|

射程で足を止め、実際に飛ぶ弾を撃つ。物理弾は物理防御、属性・魔法弾は魔法防御で軽減する。受けた属性・魔法攻撃は魔法防御の練習になる。商隊や門衛も攻撃対象になり、町の門衛のローカル座標を野外へ混ぜない。新しい敵弾は同時64発まで、寿命は2.3秒。

盾を装備した重装歩兵と昇格系列、熊獣人は接近する射撃に反応して前方へ防御展開する。3秒間、再使用9秒。耐久は最大HPの50%＋防御×2。前方の幅116内部単位の線で矢・属性弾・魔法弾を遮断する。ボスの火炎ブレスと古代光線も同じ判定を使う。

耐久に収まる弾は完全に止まり、破る弾は残りの威力で通る。側面・背後、ダウン中、盾なし、別のマップの兵士は遮断しない。毒床などの環境ダメージや近接攻撃をこの盾で止めない。速い弾も移動区間で判定し、フレームの間に盾を飛び越えない。遮断した量と戦闘参加を本人へ記録。

`enemy-ranged.js` の `RANGED_ENEMIES`、`DEFENSE_RULES` が追加・調整の入口。弾の生成、移動、盾の交差、描画はそれぞれ別関数。

## 主人公の経験値20%を直属兵へ

- 現在出撃している生存の直属兵1人ずつへ、主人公が得た経験値の20%を追加。主人公の獲得量は減らさない。
- 主人公自身の討伐、依頼・探索などの主人公への報奨、個人の救助経験値を対象にする。兵士自身の討伐・救護に伴う「部隊全体の昇進EXP」を主人公の個人獲得として重ねて配らない。
- 本隊、予備、討死、同じ人物の重複は除外。ダウン中の直属兵にもボーナスは入るが、レベルが上がってもダウンとHP0を保持する。
- 1EXPでも20%の端数を人物ごとに蓄積。5回なら合計1EXPになる。保存後も端数を保持。ボーナスからさらにボーナスを生まない。
- 既存のレベル・能力再計算を使い、個人詳細へ累計を表示。`experience-rules.js` の `COMMANDER_EXP_SHARE` と `shareCommanderExp` が入口。

## 雇用に出ない仲間

|職種|特徴|集落|
|---|---|---|
|忍者|刀で近接、手裏剣で遠距離。手裏剣に弾薬不要|魔王城の近くの隠れ忍者村|
|狼獣人|近接と追跡|本陣西方の小集落|
|熊獣人|高いHPと盾による防御展開|南西の小集落|
|猫獣人|速さと近接|北東の小集落|
|狐獣人|魔法|東南の小集落|
|鳥獣人|弓|北西の小集落|

入口は小屋と村名を描き、地形で塞がれていない場所へ置く。忍者村は魔王城から約18m。探索霧と既存の入場・退場の操作を使う。村内の志願者へ近づいて話しかけると無料で加入。

村は1期に1人。未加入の志願者は期が変わっても保持し、名前・才能・能力・顔を引き直さない。加入済みなら次期から新しい志願者が出る。ダンジョンと廃墟には一族の獣人を閉じ込めたケージを配置し、周囲の敵を排除して近づくと救助できる。ダンジョンのケージは同じ遠征で一度だけ。野外の既存の捕虜ケージにも1人の獣人を含める。

階級の直属定員と出撃枠の両方に空きがあれば直属へ、満員なら予備へ入る。誰かを自動で追い出さない。同行者は退場時に主人公の野外帰還地点へ戻る。加入ボタンは44px以上、司令部を開いている間は操作対象から外す。

通常の無料候補・自動募集・新兵補充は従来の5職種だけ。限定職の才能と個体能力にも既存の抽選を使い、5基礎能力255上限、装備の無限強化、筋力型術者の条件を保持する。忍者・獣人は人物画像、近景、遠景、ダウンで同じ外見を使う。

`limited-allies.js` に職種、集落、個体生成、志願者・捕虜、加入、忍者AI、描画、保存をまとめた。兵種名と通常の戦闘系列を `soldierClass` / `combatClass` で分け、既存の回復・弓・魔法・装備・能力を使う。限定職の上位職は今回追加していない。後から `LIMITED_CLASSES` の職種定義と能力処理を拡張できる。

## 保存と検証

保存形式4を保持し、`limitedAllies` と兵士の `combatClass`・`species`・加入元、経験値の累計・端数、遮断の累計を追加。出会った直後と加入時に保存する。同じ遠征での再入隊へ救助履歴と限定兵を引き継ぐ。加入済みの遭遇記録はIDと職だけへ縮め、兵士の完全な育成履歴は名簿の兵士データへ保存する。
