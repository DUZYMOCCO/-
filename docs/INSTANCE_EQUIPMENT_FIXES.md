# インスタンス同行・装備配布・装備一覧の修正

2026-10-08 / v2.7.1 / Service Worker v111

## 修正した原因と動作

### インスタンスへの同行

町だけに「直属のみ同行」の分岐があり、戦闘ダンジョンでは全兵士を転送し、本隊小隊の重心もボスへ移動させていた。

- ダンジョン・廃墟・町をすべて隊長＋直属の同行へ統一。本隊と新兵は野外座標を維持し、インスタンス滞在中は野外待機する。
- 戦闘対象、部隊空間検索、拾得、衛生兵の対象、描画、負傷表示も同行者に限定。座標が偶然重なっても別の空間の兵士を扱わない。
- 隊長／直属が牽引中の負傷者は同行可能。町の救護受付、野外の救護先、セーブ時の座標変換を維持。
- 退出は同行者だけを隊長の帰還点へ戻す。本隊の位置・小隊重心を保持。入口と出口で矢・魔法の残像と同行者の敵キャッシュを消去。
- 直属への編入・本隊への返却は野外で行う。インスタンス中に遠方の兵士が所属変更で混ざるのを防ぐ。本隊への雇用は可能。

### 装備の配布と不足部位の補給

初期装備は武器と鎧だけ。共有装備の配布はあったが、兵士は自分に不要な拾得品をその場で換金しており、国庫による不足部位の調達も存在しなかった。

- 兵士が拾った不要な装備は共有箱へ送る。未強化の交換元も共有箱へ戻し、他の兵士が必要とする品を即売却しない。従来の強化引継で使用する交換元は消費される。
- 共有品は、部位ごとの空きスロットを優先して配る。既に装備されているIDを再配布しない。負傷兵にも支給できるが、支給で蘇生はしない。
- ウェーブ終了時、新兵補充→共有品配布・真の余剰の外販→不足部位調達→国家開発の順で実施。
- 調達品は品質×1、未強化の標準T1。空き部位だけを1部位52Gで補う。装備済みの品を買い替えたり弱体化させたりしない。
- 出撃兵を優先し、1名ずつ配る巡回で一部の兵士だけが揃うのを防ぐ。余力があれば予備兵にも補給。
- 1ウェーブの予算は最大`1,500＋国家Lv×250G`。給与2回分または6,000Gを残す範囲で調達。資金不足では翌ウェーブ以降に持ち越す。
- 国家タブに出撃兵／予備兵の空き部位数、直近の支給数・費用を表示。「不足部位の装備補給」を収支表へ追加し、残高差と内訳が一致する。
- 既存セーブでも次のウェーブ終了から適用する。ドロップなしの検証で、初期48名の全7部位が9ウェーブで揃うことを確認。

### 商人の購入と装備一覧

- 装備を買うと即座に隊長の該当部位へ装備。外した装備はバッグに保持。通常購入で強化引継・装備消費はしない。
- 商人とバッグを「武器」「防具・装飾」の表示パネルへ分けた。各分類を強い順（実際の能力ボーナスを重みづけした総合性能）で並べる。強化された低Tier品も能力に応じた順序になる。
- 一長一短は従来の比較欄で確認できる。並べ替えは在庫を変更せず、購入ボタンは元の商品インデックスを保持。
- 目玉は分類内のカードに表示。商品は強い順であり、目玉を無条件に最上段へは置かない。
- 売却選択は分類を切り替えても保持。回復・補給・セーブと一括売却は開閉でき、装備一覧を広く見せる。回復サービスの待ちウェーブ数は閉じた見出しにも表示。
