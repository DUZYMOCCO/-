## 実装の所在

### 商店

- `merchant-catalog.js`：最高入手Tierを記録。バッグ・隊長・本隊・予備兵・共有箱から補完し、売却後もランクを維持。商店在庫自身は数えない。
- 販売Tierは `min(6, 最高入手Tier+1)`。武具6品（部位は商人ID／ウェーブで回転）、1点は目玉。通常品質×1.15〜1.30／+0〜1、目玉×1.35〜1.50／+2〜3。
- 商人ID／キャンプseed／ウェーブ／ランクの専用乱数で生成。通常戦闘のMath.randomは使わない。90秒での再抽選は撤廃。
- 最新ランクが上がれば同ウェーブでも通常在庫を更新できるが、購入済みの目玉は再入荷しない。全売切れでも同ランク／同ウェーブなら補充しない。
- 価格は基準売値×3.2×品質、目玉はさらに×1.15。
- `merchant-rules.js`：全在庫、stockPhase／stockTier／catalogVersion／featuredSoldPhaseを保存・再開。旧セーブは新カタログを補完。回復サービスの2ウェーブ待ちとNPC救護を維持。
- `index.js` の `openMerchantShop`：現装備比較・強化引継後の比較・現在の品名・品質・価格・目玉・次ウェーブ案内を表示。金不足でも比較を暗くしない。購入品は `collectDrop(...,{purchased:true})` で国庫自動買取を避ける。

### ドロップ

- `rollItemQuality`：神鍛0.3%／異質0.7%を維持。通常帯は粗悪17%（×.65〜.85）、標準60%（×.88〜1.12）、良品17%（×1.12〜1.30）、極上5%（×1.30〜1.55）。
- `drop-exclusives.js`：全7部位に固有名・専用補正。生成率は通常0.6%、精鋭2.5%、ボス5%、箱3%、超巨頭／最奥宝箱8%。商店生成では抽選しない。最高T7の従来の最奥宝箱ルールは維持。
- `dropOnly`／`dropOnlyKey` を保存し `applyUpgradeStats` で毎回専用補正を再計算。補正が強化ごとに二重加算されないテストあり。
- `isGodRollProtected` に限定品を追加し、自動売却／国庫自動買取の対象外。手動売却は可能。バッグに「ドロップ限定・非売品」と補正説明を表示。

### 通常敵

- `field-scaling.js`：本隊の永久戦力65%点、隊長の永久戦力、国家Lvから追加補正。仮の負傷HPで敵を弱くしない。
- 本陣近くで追加HP最大8倍／攻撃最大3倍。追加量を距離で線形に減らし48,000mで0。敵生成時に固定。追加難易度に応じ経験値／金も最大5倍。
- `spawnMonster` にのみ反映。定期侵攻・本格侵攻・著作ダンジョン／超巨頭の既存設定は直接変更していない。

### 武器の個体別性能

- `equipment-rules.js`：`rollWeaponTraits`、`weaponCombatProfile`、`meleeSweetSpotFor`、`weaponAxisValues`。長さ、攻撃間隔、振り抜き、攻撃幅、スイート幅／ピーク移動／威力、追加会心0〜8%をアイテムに保持。
- 古い武器は未抽選のまま従来の既定値を使用。新武器は生成時に1回抽選し、装備・強化・ロードで再抽選しない。
- `compareEquipment` が長さ／射程、攻撃幅、振り抜き、攻撃速度（回/秒）、スイート幅／芯の威力補正、会心などを比較。商店・バッグ・譲渡の既存比較にも反映。
- `weapon-motion.js`：振り抜き速度をアニメ速度へ、長さを武器の描画へ、個体スイートを地面の静かな目印へ反映。
- `index.js`：近接射程・クールダウン・スイート・新武器の兵士会心を反映。正面スイングは追加1体に35%ダメージ、角度／射程／壁判定あり。槍の貫通／火砲の爆風は個体幅から計算。
- 兵士の旧武器の従来クールダウンと会心は維持。新武器の兵士は攻速・個体tempo・装備会心を使用。

### 変更内容

- **武器ATK二重加算の修正**（index.js 兵士のオート攻撃）：`soldier.atk` は `recalcSoldierStats` で武器ATKを既に含むため、`(atk + 武器ATK)` をやめて `atk` のみ使用。隊長は `recalcPlayerStats` の `equipAtk` を1回だけ加算しており、魔導兵は `mage.atk` を使うため二重加算なし。いずれも変更なし。これで非魔導兵のダメージは約35〜50%低下。
- **補填**：`SOLDIER_PHYS_DMG_MULT = 2.2` を兵士の通常攻撃（`totalAtk`、弓・近接・上位職の各スキル・拠点攻撃）へ乗算。修正で減った分の補填＋底上げ。魔導兵・衛生兵の治癒は対象外。
- **重装**：槍×1.15／鎚×1.35（`SOLDIER_SPEAR_DMG_MULT`／`SOLDIER_HAMMER_DMG_MULT`）を近接通常攻撃の `meleeAtk` に適用。旧武器・新武器（weaponTraits）が同じ経路を通るため両方に有効。`bonusHp 65→120`、`bonusDef 22→60`。
- **軽装の会心**（`performAttack`）：兵士は `s.crit`（基礎10＋兵種bonusCrit＋才能＋死線）で会心判定、倍率は他と同じ2.2倍。新武器の装備会心（`stats.crit`）とスイート補正は加算のみ（`s.crit` は装備会心を含まないので二重にならない）。魔導兵の魔法は会心なし。
- **基本衛生術師の護身攻撃**：治癒対象がいない時のみ、敵へ単体弾（SMITE、ATK×1.0、splashなし、魔力10消費）。魔力残量40未満では撃たず治癒用に温存。治癒・蘇生が最優先。大司教以上は従来どおり（ATK×1.6、範囲）。
- **魔導兵のHQ魔力回復**（magic-rules.js `updateMagic`）：**平時は従来どおり0.25秒ごとに全回復**。防衛戦中（`invasions.stage==='battle'`＝定期侵攻・本格侵攻の戦闘中、または `baseRaidActive`＝ランダム強襲）に限り、本陣（supplyLocation.kind==='base'）の魔導兵のみ全回復をやめて毎秒 `HQ_DEFENSE_MANA_REGEN=3` 回復。行軍中は戦闘扱いにしない。衛生術師・町／救護所／野営／商人での補給・弾薬補給は不変。
  - 8/秒は魔法の消費（約8.6〜9.6/秒）とほぼ釣り合い、100の貯蔵もあって40秒計測で効果がほぼ出なかったため、計測して3/秒にした。
- **本格侵攻の調整**（invasion-rules.js）：`MAJOR_HP_SCALE 1.5→2.0`、`MAJOR_ATK_SCALE 1.4→1.6`。兵士強化で隊長滞在ケースが勝つようになったため（方針維持）。
