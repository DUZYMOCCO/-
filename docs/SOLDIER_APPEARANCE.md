# 兵士の外見バリエーション

2026-10-07 / v1.27.2 / Service Worker v85

## 外見

| 要素 | バリエーション |
| --- | --- |
| 通常の男性兵士 | バーコード、丸ハゲ、モヒカン、サイドハゲ、落ち武者ハゲ、うっすら坊主 |
| 少数の男性兵士 | 流し髪と端正な顔立ち（外見抽選の約6%） |
| 顔 | 丸顔・角張った顔・面長、肌5色、眉・目・ひげ・傷跡・口元の差 |
| 衛生兵 | 可愛い女性風の顔。ボブ、ポニーテール、編み髪、ショート。髪色と小さな髪飾りにも差 |
| メガネ | 約35%で丸・角・ハーフリム。男性・衛生兵とも対象 |

衛生兵の昇格先 `HIGH_PRIEST / SAINT / ARCHANGEL` でも同じ女性風の外見を表示する。イケメンやメガネは才能・強さ・成長率と無関係。

見本は [previews/soldier-faces.png](previews/soldier-faces.png)。ゲームと同じ描画関数で生成したイラスト集で、実機のスクリーンショットではない。

フィールド側の装備・距離・負傷に応じた見本は [previews/field-soldiers.png](previews/field-soldiers.png)。v1.27.2の追加変更は [FIELD_SOLDIER_LOOK.md](FIELD_SOLDIER_LOOK.md)。

## 表示する場所

- 兵士名簿の全身アイコンを顔のサムネイルへ変更。
- 個人詳細に大きいポートレートと外見の短い説明を追加。兜を外した素顔を表示する。能力や装備の変更は行わない。
- 個人詳細は既存の1つのウィンドウを使い回す。別の兵士を選ぶと、そのウィンドウの内容を置き換える。
- 予備兵の一覧にも個人詳細ボタンを追加。
- 戦場は同じ髪型・肌・メガネを簡略化して描く。装備した兜は戦場で表示し、素顔との違いを維持する。遠い兵士は従来の描画簡略化を継続する。
- 見た目の個性を付けても、兵士・敵の人数や戦闘ルールは変更しない。

## 永続化・実装

`js/games/iron-squad/soldier-appearance.js` で外見を生成する。兵士IDを入力にした専用の決定的な乱数を使用し、戦闘の `Math.random()` は消費しない。

兵士の `appearance` フィールドを、既存の保存処理 `persistentUnit()` を通して保存する。新兵作成・兵士能力の再計算・旧セーブの読み込みで外見がない兵士を補完する。保存した顔が有効なら、名前・階級・才能・レベル・装備・昇格に応じて再抽選しない。

メガネの補完は別のIDシードで行う。古い顔データにメガネ項目がなくても、既に決まった髪型や顔を作り直さない。

個人詳細を置き換える・閉じる際は、古いポートレートのCanvas画像領域を解放する。戦場の毎フレーム描画ではポートレートを生成しない。新しい画像ファイルや外部フォントをゲーム実行時に読み込む必要はない。

## 検証

- `tests/soldier-appearance.test.mjs`：同一IDの再現、旧データの補完、保存・読み戻し、昇格・改名後の保持、メガネ補完による元の顔の保持、全髪型・全メガネ形状・全医療職の描画、乱数・能力からの分離、Canvas保存状態の復元。
- 固定した10,000 IDでは端正な顔が634人（6.34%）。髪型全7種類、肌全5色、輪郭全4種類、メガネの有無と全3形状を確認。
- `tests/interface.test.mjs`：個人詳細に顔Canvasと読み上げ説明があること、別兵士を開いてもウィンドウが1つであること、顔が変わらないこと、予備兵の個人詳細、実際のセーブに外見が含まれること。
- `tests/field-form.test.mjs`、`tests/performance-regression.test.mjs`、Canvasを使用する既存回帰検証も確認。
- 見本PNGを生成して目視確認。戦場の顔を簡略化し、48兵士・40敵の描画確認も実行。PCのソフトウェアCanvas計測はiPhoneのFPSを示すものではない。

実機とブラウザでの表示確認は未実施。キャッシュの更新は入口と描画モジュールをv85へ揃えている。

```powershell
node tests/soldier-appearance.test.mjs
node tests/interface.test.mjs
node tests/field-form.test.mjs
node tests/performance-regression.test.mjs
node tools/preview-soldiers.mjs <@napi-rs/canvasを含むnode_modules> <出力PNGパス>
```
