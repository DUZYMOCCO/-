# 📱 スマホゲーム工房 (Mobile Game Studio)

> **目的**: 自分のiPhoneで快適・爽快に遊ぶことだけを追求した、個人専用のゲーム制作工房。

---

## 🚀 遊び方（iPhoneでの起動手順）

### 1. サーバーの起動
- フォルダ内の **`start.bat`** をダブルクリック  
  （またはターミナルで `python serve.py` を実行）

### 2. iPhoneで開く
- 画面に **QRコード** と **URL**（例: `http://192.168.0.21:8000`）が表示されます。
- **PCとiPhoneが同じWi-Fiに繋がっている状態** で、iPhoneの標準カメラをPC画面のQRコードにかざしてください。
- 画面上部に出る通知をタップすると、Safariでゲーム工房が開きます！

### 3. 【超おすすめ】ホーム画面に追加（全画面アプリ化）
Safariで開いた後：
1. 画面下の **共有ボタン（四角から上矢印が出ているアイコン）** をタップ
2. メニューを少しスクロールして **「ホーム画面に追加 ＋」** をタップ
3. 右上の **「追加」** をタップ

👉 iPhoneのホーム画面に専用のネオンアイコンが並び、タップすると**URLバーや下部メニューの無いネイティブアプリ同等の全画面**で快適に遊べます！

## 🎮 IRON SQUAD

### 🛡️ IRON SQUAD (アイアン・スクワッド: 雑兵立身出世録)
- **ジャンル**: ローグライク・小隊育成アクションRPG (v1.17.0)
- **操作**: 画面ドラッグで部隊移動、敵が近づくとオート交戦！
- **特徴**:
  - **淘汰と生存（才能＆死線覚醒）**: 兵士はカジュアルに戦死するが、稀に「天才」が紛れ込む。部隊損耗率30%以上の過酷な死線を越えて生還した兵士は、後半も腐らないパーセンテージ制の「死線覚醒スキル」を獲得！
  - **クラスアップ（上位職への覚醒）**: 大ボスからドロップする「覚醒の英雄宝珠」で、剣聖・聖騎士・神射手・大司教・覇王へクラスアップ！
  - **資金援助 & 装備譲渡**: 指揮官の手持ちゴールド（1万/10万/MAXまとめ渡し）や神話装備を兵士に直接授与。兵士は自律的に装備をカンカン強化！
  - **危険度ゾーン制**: 本陣（安全圏）から離れるほど敵が凶暴化（最大3.8倍）。
  - **超ド級大ボス**: マップの四隅に通常モンスターの4倍サイズの超巨大ボス（エンシェントドラゴン、ベヒーモスキング、コロッサスタイタン）が君臨。画面揺れ必殺技＆神話ドロップ確定。
  - **シームレス作戦期（Phase制）**: 戦闘を強制中断しないノンストップ75秒サイクル制。戦略会議はプレイヤーの好きなタイミングで安全に開閉可能。
  - **詳細仕様書・他AI引き継ぎ書**: [docs/SPEC_AND_HANDOVER.md](docs/SPEC_AND_HANDOVER.md) を参照。

## 過去更新記録（2026-10-06 / v1.17.2）

以下の人数・世界寸法等は各更新時点の履歴。現行の値は上記とコードを参照。

- **負傷兵の画面端・方向インジケーター**: 仲間兵士が倒れた際、画面外にいる場合は画面端に「▲ ✚ 距離m」の方向矢印バッジがリアルタイム表示され、放置されている仲間へ一直線に救助・搬送へ向かえるようになりました（ミニマップにも救護十字が点滅）。
- **遠征セーブ削除機能**: 遠征選択画面の各セーブカードに「🗑️ 削除」ボタンを追加。「本当に削除しますか？」の安全確認ダイアログ付きで、不要になった遠征記録を整理可能に。
- **出動枠は全階級30名**。ニューゲームも30名から開始。昇進時の直属人数・能力ボーナスは維持し、30名を超える兵士は予備へ待機。
- **敵の増員**: 初期70体（近郊10 / 辺境24 / 深部24 / 最果て12）、維持上限72体。補充間隔0.45秒。休息中は従来どおり敵が出ない。
- **UI字体を更新**: 明朝系の見出し・ゴシック系の操作と本文・桁幅を揃えた数値。端末の字体を使い、オフラインでも表示する。
- 詳細・検証: [docs/POPULATION_TYPOGRAPHY_UPDATE.md](docs/POPULATION_TYPOGRAPHY_UPDATE.md)。


- **負傷者の搬送**: 通常1名、聖騎士だけ2名まで紐で引いて搬送。本陣・制圧済み拠点に入ると全快で復活。
- **現地復活は衛生兵・大司教のみ**。一般兵は近くの負傷者を自動搬送。隊長は接近で搬送し、紐を外す操作も可能。
- **搬送中は死亡猶予停止**。未搬送は従来の14秒、搬送役が倒れると紐が外れ猶予再開。搬送時は速度低下。
- **秘宝を希少化**: 遠方エリート2% / 通常ボス12% / 巨大ボス45%、1体につき最大1個。本陣近郊では出ない。
- 詳細・検証: [docs/CASUALTY_TRANSPORT_UPDATE.md](docs/CASUALTY_TRANSPORT_UPDATE.md)。既存セーブと所持秘宝は保持。


- **昼4分・夜4分の周期**。夕暮れと夜明けは滑らかに色調が変わり、時刻と切替までの残秒をHUDに表示。
- **昼限定**: 野猪 / 日中の山賊 / 遺跡の昼番。**夜限定**: 夜コウモリ / 影狼 / 骸骨兵。地域の難易度と距離による戦利品制限を適用。
- **昼夜も保存**。会議・地図・セーブ選択中は停止、戦闘と10秒休息中は進行。限定敵は時間帯が変わると退去し、共通敵・ボスは残る。
- 詳細・検証: [docs/DAY_NIGHT_UPDATE.md](docs/DAY_NIGHT_UPDATE.md)。


- **120秒の戦闘→10秒の安全な休息**。休息中は敵・戦闘・移動を停止し、次期の120秒を消費しません。
- **兵士の自動自己強化**: 既存兵士に各20Gの定期給与、治療後に予算内で1秒ごとに低強化の部位から整備（上限+30、維持費6Gを確保）。予備兵も対象。
- **整備結果が見えるUI**: 全体の強化回数・消費金額、個別の実績と資金不足等の理由。手動強化も継続利用可能。
- **休息のセーブ対応**: 時計・整備実績・休止した敵の状態を保持。会議中は休息時計も停止。
- 詳細と検証: [docs/REST_AND_MAINTENANCE_UPDATE.md](docs/REST_AND_MAINTENANCE_UPDATE.md)。


- **兵士の全7部位**を表示。空き部位を選び、対応する装備を譲渡可能。
- **装備比較**: 強くなる / 弱くなる / 一長一短 / 同等と、能力値の増減を表示。隊長のバッグと兵士の譲渡候補に対応。
- **一括売却**: 手動選択・弱い余剰選択・保護機能。装備中は売却不可、売却前に個数と金額を表示。
- **距離による難易度・戦利品**: 本陣1200未満はT1〜T2。最上位T7は6000以上の巨大ボスのみ。敵能力・報酬・拠点耐久・祭壇の無料強化も距離に対応。
- 詳細・検証結果: [docs/EQUIPMENT_AND_SCALING_UPDATE.md](docs/EQUIPMENT_AND_SCALING_UPDATE.md)。現行セーブを保持。


- **戦線サイクルは120秒**。待機だけの兵士には戦線経験を加算せず、交戦・実回復・救助した戦線だけを経験として記録。
- **毎サイクル最低5名の新兵を受領**。定員超過分は予備兵として待機し、欠員へ自動合流。
- **主人公の描画を強化**。兵士と共通の装備・顔・甲冑の表現、階級と覇王の描き分け、会議の肖像を追加。
