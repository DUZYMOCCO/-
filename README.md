# 📱 スマホゲーム工房 (Mobile Game Studio)

> **目的**: 自分のiPhoneで快適・爽快に遊ぶことだけを追求した、個人専用のゲーム制作工房。

---

## 🚀 遊び方（iPhoneでの起動手順）

### 1. サーバーの起動
- フォルダ内の **`start.bat`** をダブルクリック  
  （またはターミナルで `python serve.py` を実行）

### 2. iPhoneで開く
- 画面に **QRコード** と **URL**（例: `http://192.168.0.21:8000`）が表示されます。
- **PCとiPhoneが同じWi-Fiに繋がっている状態** で、iPhoneの標準カメラをPC画面のQRコードにかざしてください。
- 画面上部に出る通知をタップすると、Safariでゲーム工房が開きます！

### 3. 【超おすすめ】ホーム画面に追加（全画面アプリ化）
Safariで開いた後：
1. 画面下の **共有ボタン（四角から上矢印が出ているアイコン）** をタップ
2. メニューを少しスクロールして **「ホーム画面に追加 ＋」** をタップ
3. 右上の **「追加」** をタップ

👉 iPhoneのホーム画面に専用のネオンアイコンが並び、タップすると**URLバーや下部メニューの無いネイティブアプリ同等の全画面**で快適に遊べます！

## 🎮 IRON SQUAD

### 🛡️ IRON SQUAD (アイアン・スクワッド: 雑兵立身出世録)
- **ジャンル**: ローグライク・小隊育成アクションRPG (v4.2.0)
- **操作**: 画面ドラッグで部隊移動、敵が近づくとオート交戦！
- **特徴**:
  - **淘汰と生存（才能＆死線覚醒）**: 兵士はカジュアルに戦死するが、稀に「天才」が紛れ込む。同じ兵士が1ウェーブで10回以上ダウンし生還した場合、その本人は、後半も腐らないパーセンテージ制の「死線覚醒スキル」を獲得！
  - **クラスアップ（上位職への覚醒）**: 大ボスからドロップする「覚醒の英雄宝珠」で、剣聖・聖騎士・神射手・大司教・覇王へクラスアップ！
  - **資金援助 & 装備譲渡**: 指揮官の手持ちゴールド（1万/10万/MAXまとめ渡し）や神話装備を兵士に直接授与。兵士は自律的に装備をカンカン強化！
  - **危険度ゾーン制**: 本陣（安全圏）から離れるほど敵が凶暴化（最大3.8倍）。
  - **超ド級大ボス**: マップの四隅に通常モンスターの4倍サイズの超巨大ボス（エンシェントドラゴン、ベヒーモスキング、コロッサスタイタン）が君臨。画面揺れ必殺技＆神話ドロップ確定。
  - **シームレス作戦期（Phase制）**: 120秒の戦闘と8秒の安全休息を繰り返すサイクル制。戦略会議はプレイヤーの好きなタイミングで安全に開閉可能。
  - **詳細仕様書・他AI引き継ぎ書**: [docs/SPEC_AND_HANDOVER.md](docs/SPEC_AND_HANDOVER.md) を参照。

## 現在の版（v4.2.0 / SW v146）

何も起きていない本陣では、兵士が席に座って酒を飲んだり食事をしたりします。本陣と村の周囲には普通の敵が湧きません。敵が近づけば立ち上がります。予備兵は川辺の農村で農作業をします。自動の新兵は予備48名で止まり、すでにいる予備兵はそのまま残ります。戦場の上端には HP・MP・軍資金だけを小さく出し、地図は左上で半透明です。ファストトラベルはメニューの「地図」から使います。画面の戦闘ログは、弾薬・MP・HPが半分以下、ダウンから15秒、兵士の死亡、ドロップだけです。レベルアップはログに出さず、キャラの頭上に短い印を出します。

射撃・属性・魔法を使う敵6種類と、重装兵の盾による防御展開を追加。主人公の獲得経験値の20%を直属兵へボーナス支給。忍者村・獣人の集落・ダンジョンのケージを探索すると、通常の雇用に出ない仲間と出会えます。[仕様と見本](docs/EXPLORATION_ALLIES_AND_DEFENSE.md)。

主人公の全能力は「司令部 → 戦況 → 隊長ステータス」で確認。ワンド・杖を持てば炎・氷・雷・爆発の範囲魔法を選んで使えます。通常攻撃と強撃が魔法になり、MPと属性と魔力の練習を保存します。

人口・産業・治安・技術から国家の税収が生まれ、探索済みで通行できる道が街や村を本陣につなぐと交易が始まります。商人・旅人・護衛が実際に往来し、到着した積荷から交易税を受け取ります。襲撃で商人が死亡すると積荷を失います。

11地域の復興、生産・輸送・都市の技術革新、8箇所の橋・埋め立て・街道へ投資できます。建物・工房・市場・石畳が育ち、完成した工事で実際の通行も変わります。国庫の重点事業を選ぶか、隊長の軍資金で発展を早められます。

給与と栄誉手当は国の収入から配分。国が停滞する間は兵士が貯金して装備を強化します。未回収のドロップはゲーム進行時間60秒で消え、一時停止中は時間を止めます。[v4の国家経済・領土・交易](docs/V4_NATIONAL_ECONOMY.md) / [発展と架橋の実描画](docs/previews/economy-v4.png)。

筋力・魔力・魔法防御・速さ・回避で兵士の個性が育ちます。基礎能力は255上限で限界ほど育ちにくく、装備込みの性能に倍率で効きます。装備の強化は上限なし。職種を選んで候補を1人ずつ確認する雇用、自動募集の天才停止、杖・ワンドと近接武器の必要筋力、13部門のランキングを追加。[能力と雇用の仕様](docs/UNIT_ATTRIBUTES.md) / [武具の見本](docs/previews/caster-weapons.png)。

近接武器の成長補正を解禁できる筋力型の術者だけ、肩幅・胴・腕がたくましくなります。人物画像と戦場で個体の違いを観察できます。[通常個体との体格比較](docs/previews/caster-physiques.png)。

衛生術師は**実回復5HPにつき1個人EXP**、蘇生では**対象の最大HPの300%を個人EXP**として獲得します（最大HP1,000→3,000EXP）。回復・救命でレベルが上がり、継続回復と小さな回復の積み立てにも対応。兵士詳細で累計回復量・回復EXP・蘇生EXPを確認できます。

装備を**素材7系列×製造4世代の28Tier**へ拡張。国家が製造技術を研究し、国庫で不足補給・換装・公費強化を進めます。「均衡／軍備優先／発展優先」を選び、技術・配備率・整備費を国家タブで確認できます。初期は小さく粗い装備から始まり、部位ごとに保護範囲・細工・素材の見た目が成長します。

**現行のv3遠征は能力を補完して保持します。** 保存形式は4のまま。以前に廃止した旧ルールの遠征は一覧へ引き継がず、音量等の設定を保持します。比較・お下がり・研究・費用・将来の拡張箇所は [docs/ARMAMENT_V3.md](docs/ARMAMENT_V3.md)。[実描画の見本](docs/previews/armament-v3.png)。現在地は [docs/CURRENT_WORK.md](docs/CURRENT_WORK.md)。

- **音を刷新**：弦・手太鼓・風を重ねた落ち着いたBGMを追加。剣・金属・鈍器・弓・クロスボウ・火砲・魔法などを素材感のあるオリジナル音源へ変更。昼夜・司令部でBGMの音量や音色を調整。
- **ゲーム内の音設定**：縦画面の「音」ボタン、司令部→戦況→「音・BGMの設定」。BGMと効果音を個別調整・保存、音が止まった場合は「音を再開」。標準はBGM35%／効果音65%。小さい横画面は司令部内から操作。
- **音の負荷対策**：音源は一度読み込んで再利用。戦闘音8声／全効果音14声まで、同時連打を間引き、遠い戦闘は減衰。バックアップ・生成方法・検証：[docs/AUDIO_UPDATE.md](docs/AUDIO_UPDATE.md)。[音の見本](assets/audio/preview.wav)。iPhone実機での試聴は未確認。
- **ログとボタンの重なりを修正**：戦闘ログを操作パネルの独立した上段へ配置。回復薬・号令・搬送表示の高さに追従し、縦横どちらも重ならない構造へ変更。
- **装備表記を明確化**：「個体×」を「ドロップランダム補正×」へ変更。元の倍率・装備性能は維持し、長い表記を折り返して表示。
- **衛生術師の魔力**：回復・蘇生・上位職の術でMPを消費。自然回復は0.6MP/秒。本陣・町・キャンプ・利用可能な商人で全補給。クラスアップ後は周囲の味方へ攻撃力・被ダメージ軽減バフを自動使用。
- **魔法石**：敵が弾薬・装備と別に落とす。隊長・兵士の誰が拾っても術者へ自動配分し、余剰は共通予備へ保存。部隊ポーションでも魔力を全回復。
- **新兵種・魔法使い**：高威力の範囲攻撃と低いHP・防御。炎・氷・雷・爆発の得意属性を個別に保存し、ローブ・杖・属性色・MPバーで人物として表示。氷は減速、雷は通常敵を短く止める。魔力不足で移動・攻撃を停止、4MP/秒の瞑想で40MPまで回復すると復帰する。
- **魔法使いの昇格**：大魔導士→元素賢者→秘術王。既存の宝珠・宝玉ルールを使い、魔力上限・攻撃力・範囲・射程を強化。
- **危険なダメージ地形**：灼熱・腐毒・帯電。境界と警告を表示。隊長・兵士・護衛に継続ダメージを与え、既存の被弾修練にも反映。敵も傷つくが、未交戦の敵の自然死では放置経験値を得られない。町・休息中は停止。
- 仕様・バックアップ・検証：[docs/MAGIC_AND_HAZARDS.md](docs/MAGIC_AND_HAZARDS.md)。本隊48名／直属12名／敵上限40体を維持。既存セーブを補完して保持。編集前バックアップ済み、git pushなし。


- **格上討伐の経験値を大幅増**: 最大HP・攻撃・防御・軽減から相対戦力を比較。格上は2倍以上、自分の2倍の戦力なら5倍、3倍なら8倍、上限25倍。隊長・兵士・護衛の討伐経験と部隊の昇進経験へ反映。最大HPで比較するので長時間削っても報酬が減らない。追加EXPと直近の格上戦果を表示。
- **共通の弾薬**: 弓・クロスボウ・火砲は1射ごとに弾薬を消費（各30発）。弾切れでは石投げへ切替、威力・射程・弾速・射撃頻度は通常の75%。石は爆発せず、火砲の範囲／熟練の範囲ボーナスも適用しない。弾切れはHUD・兵士詳細・頭上に表示。
- **補給と弾薬拾得**: 本陣・町入口／町内・生存商人の近くで無料の自動補給。敵から装備とは別に少量の弾薬が落ち、誰が拾っても射手へ配分。余りは共通の予備弾薬へ。
- **遠隔武器の調整**: 通常射撃と遠隔強撃の威力を20%増加。クロスボウ／火砲の基礎クールダウンを1.25秒／1.85秒へ短縮。熟練の上限は維持。
- **部隊回復ポーション**: 携帯1個。コントローラの「回復薬」で隊長と行動可能な直属兵のHP・弾薬・魔力を全回復。本隊・予備兵は対象外。ダウン中は従来どおり搬送・衛生兵が必要。本陣で無料補給、商人から300Gで購入。
- **隊長の即死対策**: 防御後の致死ダメージが最大HPの80%以上ならHP1で生還し、2秒無敵。再使用120秒。「危険なので撤退すべきだ」と再発動までの秒数を表示。回復・保存・再開で待ち時間をリセットしない。
- **地点セーブ／ロード**: 本陣・町・商人で司令部「戦況」の「補給・地点セーブ」から記録／読込。商人の販売欄からも操作可能。オートセーブとは独立して遠征ごとに1件保持。町内で記録した場合は町入口で再開する。遠征選択の「地点セーブから再開」で、討死した遠征も記録時点へ戻れる。
- **方角で分かる景観**: v1.28.0の東西街道・南北山道・川・橋を維持。
- 仕様・バックアップ・検証: [docs/SUPPLY_V2.md](docs/SUPPLY_V2.md)。編集前バックアップ済み。git pushなし。iPhone実機の新UI表示は未確認。
