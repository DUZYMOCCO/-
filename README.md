# 📱 スマホゲーム工房 (Mobile Game Studio)

> **目的**: 自分のiPhoneで快適・爽快に遊ぶことだけを追求した、個人専用のゲーム制作工房。

---

## 🚀 遊び方（iPhoneでの起動手順）

### 1. サーバーの起動
- フォルダ内の **`start.bat`** をダブルクリック  
  （またはターミナルで `python serve.py` を実行）

### 2. iPhoneで開く
- 画面に **QRコード** と **URL**（例: `http://192.168.0.21:8000`）が表示されます。
- **PCとiPhoneが同じWi-Fiに繋がっている状態** で、iPhoneの標準カメラをPC画面のQRコードにかざしてください。
- 画面上部に出る通知をタップすると、Safariでゲーム工房が開きます！

### 3. 【超おすすめ】ホーム画面に追加（全画面アプリ化）
Safariで開いた後：
1. 画面下の **共有ボタン（四角から上矢印が出ているアイコン）** をタップ
2. メニューを少しスクロールして **「ホーム画面に追加 ＋」** をタップ
3. 右上の **「追加」** をタップ

👉 iPhoneのホーム画面に専用のネオンアイコンが並び、タップすると**URLバーや下部メニューの無いネイティブアプリ同等の全画面**で快適に遊べます！

## 🎮 収録ゲーム一覧

### 1. ⚡ NEON BOUNCE (ネオン・バウンス)
- **ジャンル**: 爽快ブロックバスターパズル
- **操作**: 指でドラッグして狙いを定め、指を離して発射！
- **特徴**: 壁やブロックを乱反射！ボール数アップアイテム（+1）やレーザー（⚡）、爆弾（💥）を巻き込んで大量破壊する爽快感。コンボ音の音階が心地よく上がります。

### 2. ⚔️ CYBER SLASH (サイバー・スラッシュ)
- **ジャンル**: 光速スライサーアクション
- **操作**: 指先で画面をスワイプ！
- **特徴**: 下から飛び出すネオンコアを一刀両断。鮮やかな光の刀（ブレードトレイル）と鋭い斬撃音。複数同時切りでコンボスコア！⚠️ 爆弾コアに注意。

---

## 🛠️ 工房の拡張（新しいゲームを追加したい時）

「こんなゲームを作りたい！」とAIにリクエストするだけで、この工房に3作目、4作目を追加できます。
- すべてのゲームは `js/games/` 配下に独立したモジュールとして追加されます。
- `js/games-registry.js` に登録するだけで、ポータル画面に自動反映されます。
- iPhoneの画面比率（Retinaディスプレイ高解像度）、タッチ・スワイプ操作、Web Audio合成サウンドが最初から完備されています。
